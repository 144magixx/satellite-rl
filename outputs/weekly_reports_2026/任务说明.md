## 2. 写法（最重要）

参照已确认的两份示例，口吻和详略照它们来：

- 周报示例：`docs/Claude维护/周报/build_weekly_template.py` 中的 `EXAMPLE`（第 18 周，渲染成品 `docs/Claude维护/周报/周报示例_第18周_v2.docx`）
- 月报示例：`docs/Claude维护/周报/build_monthly_template.py` 中的 `EXAMPLE`（8 月，成品 `docs/Claude维护/周报/月报示例_8月.docx`）

要求：
- 研二学生自己写给导师看的口吻，平实、口语化一点，不要 AI 味。不用“赋能、闭环、显著提升、充分验证、标志着、不仅……更……”，不用破折号“——”，不堆排比，不每条都加粗小标题。
- 代号尽量换成人话（例：“从贪心解出发、让SAC只调整频率槽”，而不是“I0”）；必须用代号时第一次顺带解释。
- 数字只保留到能看出大小（91.9%、0.60、高3个百分点），并给出和谁比。所有数字必须来自第 4 节列出的原始报告，不能编；拿不准就不写数字，写定性结论。
- 结论说得收敛：“比贪心好一些”“还没追上”“暂时先不往下做”。不写防御性的长串免责。
- 存在问题写成自己踩到的情况（只训了一个种子、某个场景变差、服务器出问题导致耗时不能比等），每份 1～3 条。
- 周报篇幅一页到一页半；月报两页左右。
- “本周完成工作”3～5 条；“下周计划”写下一周（第 3 节表格的下一行）的内容，2～3 条，用计划的语气。第 26 周的下周计划写：根据导师批注继续修改中期报告、准备中期汇报。
- 没有对比实验的周（纯调研、写文档）可以不放表格。

## 5. 图

“可以适当放一些实验直接跑出来的图，不用太详细，关键的就可以”。
- 图的数量不设上限（用户后来取消了每周1张、月报2张的限制）：实验过程中产出的数据、报告里已有的现成图，凡是能说明问题的都放，周报一般3～10张，月报从各周图里每周挑1～2张。调研、写文档的周可以不放。
- 只用真实数据做的图，不用示意图或网页截图。三种来源：（1）原始记录（csv、jsonl 等）用 matplotlib 重画；（2）原始记录本机没有时，按报告表格里的数字重画；（3）报告里已有的现成图，只改图里带代号或英文的文字（绘图区不动），转存成真 PNG。每张图的脚本和出处在 `figure_scripts/`（同名 .py，说明见各 `W*_说明.md`），图在 `figures/`。
- 图题用中文、一句话、学生口吻，例“图1 三种方法在880个场景上的需求满足率”。图题里不出现实验代号和日期。
- 周报 JSON 用 `figures` 列表，月报同名。月报的图用 `figure_scripts/_set_month_figures.py` 从各周图里挑（改里面的 SELECT 再运行）。

## 6. 数据文件格式

每份报告写一个 JSON（UTF-8，`ensure_ascii=False`），放在 `outputs/weekly_reports_2026/data/`：周报 `W01.json`…`W26.json`，月报 `M05.json`…`M10.json`。

周报：
```json
{
  "week": 18,
  "dates": "2026年8月31日—9月4日",
  "days": "5 天",
  "summary": "一段话",
  "work": ["条目1", "条目2"],
  "result_lead": "一段话",
  "table": {"header": ["方法", "细调前满足率"], "rows": [["贪心", "90.8%"]], "widths_cm": [4.4, 3.2]},
  "table_note": "注：……",
  "figures": [{"path": "outputs/.../xxx.png", "caption": "图1 ……", "width_cm": 14}],
  "issues": ["……"],
  "plan": ["……"]
}
```
`table`、`table_note` 没有就写 `null`；没有图就不写 `figures`。`widths_cm` 合计 16。`figures[].path` 相对项目根目录，`width_cm` 可省（默认 14，字很小的现成图可放到 16）。

```json

  "month": 8,

  "figures": [{"path": "...", "caption": "图1 ……"}],
  "plan_check": [["计划", "完成", "说明"]],
  "issues": ["……"],

```

## 7. 生成器（只由 1 号代理编写，其他代理等它可用后直接调用）

`outputs/weekly_reports_2026/generate_reports.py`，用 `/Users/minyuwei.6666/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/bin/python3` 运行（自带 python-docx）。版式完全复用 `docs/Claude维护/周报/build_weekly_template.py` 与 `build_monthly_template.py`（可 import 其中函数，`sys.path` 加该目录），只增加：
