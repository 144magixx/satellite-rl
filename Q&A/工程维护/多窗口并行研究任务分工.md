# 多窗口并行研究任务分工

## 2026-10-13：第一阶段探索和第二阶段公平对照之外还能做什么

**问题：** 当前桌面窗口正在推进第一阶段AI方案探索与第二阶段SAC/PPO/DQN对照，此外适合并行开展哪些工作？

**结论：** 优先补齐最终主线的第二阶段适配设计、第三阶段求解器接入审查、物理假设依据和论文证据整理。可以先做不依赖新训练结果的设计、源码核查和材料整理。以下均为建议任务，本次没有启动它们的实现或实验。

### 已有任务边界

本次依据用户截图及[本地实验状态](../../EXPERIMENT_STATUS.md)截至2026-10-13 23:12的记录定位任务范围，没有连接远端或刷新实时API，不能据此报告此刻进度。S1-AI17-R7负责统一21.6 Mbps/机的数据、可变束数与逐束宽度学习，以及共享接口基础核验；S2-T24负责原T0历史任务下三算法从头训练和Direct比较，第三阶段预算为0。

[R7方案23](../../docs/第一阶段/方案/23_统一单机请求与三阶段接口下的学习构造.md)第4节和第6节明确：共享读写与理想化物理接口已纳入本轮，而第二阶段完整训练状态尚未消费新的宽度/增益等变量，后续第二阶段适配及第三阶段连续功率比较仍需单独方案。因此不另开窗口重复实现同一共享合同，也不把T24直接视为最终统一请求模型。

### 可独立分工的工作

| 优先方向 | 建议任务与交付 | 与现有窗口的边界 |
| --- | --- | --- |
| 最终主线第二阶段适配设计 | 依据已发布的共享布局，核对实际N、稳定beam IDs、逐束宽度/增益、全N统计和掩码如何进入状态与动作；给出兼容性表、模型改动与有限重训方案 | 复用R7共享合同；保留学习离散结构、连续功率交第三阶段的最终主线分工；T24的历史任务功率学习例外不自动外推 |
| 第三阶段求解器接入审查 | 检查已有优化器如何消费共享链路系数与第二阶段实际槽/功率，列出固定维数/宽度等假设；结合已有迭代日志分析收益、停止原因和耗时，交付接入清单及有限验证建议 | 新入口可读取并核对容量不代表实际优化器已全程适配；复用P02/P03已完成结果，不重做七路线大比较 |
| 可变束宽物理依据 | 查原始文献与载荷依据，核对束宽、峰值增益、旁瓣、扫描损失和接收点抽象，交付假设依据表与后续敏感性方案 | R7图是理想化球面Gaussian；软件一致性不证明真实载荷能力，不修改其冻结物理版本，不将SI/SGM加入第一阶段目标 |
| 论文与中期报告更新 | 从原开题正文及现有正式版出发，整理研究问题、方法、已证结果与待证内容；更新AI/混合路线、统一请求及历史T0例外，形成正文、图表与证据索引 | 保留历史版本，沿原开题论证顺序写作；结果未完成处保留计划语气，不把实验批次堆成正文 |
| 动态场景研究设计 | 从相邻时刻飞机移动与进出定义热启动、重配置次数、布局变化和规划时间，交付时序数据规范与同条件比较方案 | 先承接统一飞机ID和固定单机请求；真实时序验证与静态快照分开，当前不追加模型或训练预算 |
| 统一结果可视化 | 设计读取保存结果的视图，展示飞机、波束归属/宽度、需求，以及第二三阶段频率槽/功率/容量；支持同场景切换和导出论文图 | 读取已有完整字段，缺失标明；第一阶段几何/负载评价与跨阶段服务评价分开，旧T0案例不与新统一请求案例伪配对 |

若只新增两个窗口，优先“最终主线第二阶段适配设计”和“论文证据与正式报告更新”：前者减少第一阶段完成后的接续等待，后者能直接利用现有成果，无需等待训练结束。第三阶段和物理核查可作为随后两个独立专题。

已有“设计第一阶段可变波束方案”“分析三阶段问题的最优算法”等窗口的具体范围应先核对；相同设计或理论分析优先在原窗口继续，不再复制一条相同研究线。上述建议不改变现有训练预算、远端资源归属或任务调度，也不是新增实验授权。
