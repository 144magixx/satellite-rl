# Transformer记忆与算法创新

## 2026-10-01：除了状态消融，算法还有哪些根本性的优化空间？

**问题：**能否把t时刻输出拼到t+1输入，让模型记住过去？还有什么可作为创新方向，下一步怎样验证？

**结论：**可以研究历史记忆，但当前Transformer只在同一步状态字段间做注意力，没有跨波束记忆。最简单的方法是下一步加入上一束已执行的起始槽、槽数和功率；更完整的方法是用GRU或因果Transformer读取同场景的历史。Transformer核心是注意力，拼接上一动作本身不等于引入Transformer，也不自动构成原创算法。

当前t是场景中处理第几束，一回合的位置与需求固定；它不是飞机移动的真实UTC时刻。不同ADS-B场景随机排列，进入新场景必须清空历史。真实多时刻移动、波束身份衔接与切换成本属于另一个环境方案。

### 推荐的三个方向

| 方向 | 它帮助模型处理什么 | 必须怎样证明 |
| --- | --- | --- |
| 条件动作与联合价值 | 频率槽与功率相互配合，而非三个动作各自打分相加 | 原策略/条件策略×加性Q/联合Q四组，保持207维旧奖励不变 |
| 分配历史记忆 | 过去波束怎样消耗资源、形成干扰 | 无历史、上一动作、GRU、同窗口因果Transformer；不能省掉简单记忆对照 |
| 逐束干扰关系编码 | 哪些波束容易互相干扰，地理布局变化后关系如何变化 | 同2946维原始信息比较原分段编码、逐束编码、物理关系注意力 |

近期优先建议第一项，因为已经从代码定位到结构限制：现有联合掩码能让起始槽与槽数统计相关，但合法组合打分仍是两头相加；功率独立，各Critic也把频率、槽数、功率的Q相加。它限制可学习的合法动作配合，但尚不能认定这是G09低功率或服务缺口的唯一原因。候选条件策略为`π(f,l,p|s)=π(f,l|s)π(p|s,f,l)`，联合Q评价完整组合，采样、熵和SAC目标都要一致。

历史记忆也有边界：当前剩余功率、占用、干扰已概括部分过去信息，历史可能冗余；历史不能补出从未观测过的未来波束信息。建议先用最多16步窗口；上一实际动作3量加有效位1形成211维有意义输入，再比较GRU与因果Transformer。训练须从同回合重建连续历史、避免看未来，双Q与目标网络各自重建表示；只改在线动作函数会造成训练与使用不一致。首版不宣称完整实现Transformer-XL或GTrXL。

## 2026-10-01追问：为什么J0、J2比J1、J3好这么多？

**最明确的分界是价值网络：J0/J2用加性Q，J1/J3用完整联合Q；后两组在本轮发生了明显的价值学习失稳。** Q可以理解为算法对某种频率槽—功率分配方案的好坏评分，策略网络根据这些估值学习如何选择。四组的207维观测、Transformer骨干、环境旧奖励和掩码相同；这不是状态维数或有没有Transformer的比较。

配对结果支持这个定位：原策略下J1相对J0的SI降低9.57个百分点，条件策略下J3相对J2降低6.00个百分点。两个策略背景下都出现退步，说明应优先检查完整联合Q及其配套学习设置。这个改变还包含参数量、初始化与优化难度差异，不能单凭四组证明唯一根因。

### 1. 加性Q的一条经验能直接影响许多组合

加性Q用`Q(s,f,l,p)=q_f(s,f)+q_l(s,l)+q_p(s,p)`组合评分，每个Critic输出100个起始槽分量、10个槽数分量、10个功率分量，共120项。完整联合Q为100×10×10种组合输出10000项。**环境动作空间一直最多是10000种，这次没有扩大动作空间；改变的是价值的表达和输出规模。**

例如一次选择“起始槽20、2个槽、25W”：加性Q中对应的三个分量都获得这条TD误差的直接梯度，它们又被其它包含相同分量的组合共用。联合Q在输出层直接监督的是`(20,2,25W)`这一行；相邻组合行没有因为这一条经验就获得同样的直接监督。联合Q仍有共享状态编码器，也能间接泛化，不能说是10000个独立网络或完全不共享。

加性结构牺牲部分复杂交互表达，换来较强的信息共享和结构约束。完整联合Q表达更自由，但在有限经验覆盖下估值更难稳定，是本轮合理的机制解释。120变10000不代表需要精确83倍数据；40万环境交互也不等于每个组合被均匀独立观察40次，回放更新还会重复利用样本。

### 2. 本轮差距已经超出普通的小幅拟合差异

以下为同一末1000个每50步记录的学习诊断点中位数，记录横轴350049–399999，不是全部398001次更新。

| 指标 | J0/J2 | J1/J3 |
| --- | ---: | ---: |
| Critic1损失 | 约0.24 | 约6.6–6.8×10¹⁰ |
| TD绝对误差 | 约0.35 | 约24万 |
| 当前Q均值 | 约76 | 约11万–13万 |
| 目标Q均值 | 约76 | 约36万–37万 |
| 温度α | 约0.236 | 约3.85万 |

TD是预测值与当前学习目标的差距，不是已知真实最优价值的误差。后两组连移动的学习目标都没有跟上；它们训练回报和固定验证回报同时回落，也不能仅归为“训练集很好、考核集不好”的过拟合现象。

### 3. 温度与价值目标可能形成放大反馈

当前非终止SAC目标为`y=r+γ(Eπ[min Q_target]+αH_next)`；环境旧奖励r没有改变。H衡量动作分布的多样性，α控制算法对这种多样性的重视程度。αH还进入价值学习目标，所以真实业务回报下降时，内部Q目标仍可能因熵项而上升。[SAC官方说明](https://spinningup.openai.com/en/latest/algorithms/sac.html)和[离散SAC论文](https://arxiv.org/abs/1910.07207)给出了相关方法背景，具体证据来自本轮日志和代码。

新增只读统计发现，前1000个记录点（2049–51999步）J1/J3的批平均熵低于批目标熵的比例为99.7%/99.0%，平均差为−4.07/−3.59；J0/J2分别约85.3%/85.6%，平均差−1.28/−1.50。按现行温度更新公式，低于目标时会推动α上升。中后期熵差均值已接近零，但J1/J3温度和Q目标已很大，并继续漂移。

日志中的`α×熵`后期代理量在J0/J2约1.5，在J1/J3约25万，可帮助理解量级。**它不是精确的TD目标分解**：日志α在温度更新后记录，熵来自Actor更新前的当前状态；实际目标使用更新前α和下一状态熵。不能据此算出熵项精确贡献比例，也不能仅凭α大就断言动作已完全随机，动作偏好还取决于Q差值相对α的大小。

完整联合Q较难估准、策略变得偏斜、温度调节和自举目标相互放大，是与现象一致的可能链路；最初哪一环触发了失稳尚未被隔离验证。不能把温度当成已证明的唯一原因，也不能从本轮推出所有联合Q方法都无效。

### 4. 资源用量也说明问题不只是功率不足

J1平均用了2974W，比J0的2585W更多，SI仍从93.11%降到83.54%；J3又呈现另一种功率/槽数偏好。因此“给的功率太低”不是解释两组共同退步的充分原因。价值评分不可靠时，多分功率也可能分不到合适的波束和频率槽上；终态同时存在欠供和过供，见报告11。
