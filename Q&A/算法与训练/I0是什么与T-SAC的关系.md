## 2026-10-18 问题

S2-FIX方案（Claude维护05）是不是在最新的T-SAC（带0.5瓦档位）基础上做的？I0是什么？

## 结论

**一半是。**方案里有两个学习方法：L2是最新的直出T-SAC（W32最好的配置P01-M1），在新需求和新链路模型下重训，作为历史主线的延续；L1是I0，是方案的主学习方法，与T-SAC不是同一个模型。

**关于"0.5瓦每档"。**W31试过两种加法：只加一个0.5瓦选项（档位0.5、5、10、…、50瓦，11档），和把0.5到50瓦全按0.5瓦一档细分（100档）。两者供需匹配提升几乎相同（+0.139对+0.137），所以后来的W32和这次都用"只加一个0.5瓦选项"的版本，不是每档0.5瓦。

**I0是什么。**名字来自2026-10-09方案19的编号，I指"改进"（improvement），0是第一条改进路线；同批还有C0、C1两条"构造"路线。它和直出T-SAC的区别：

| | 直出T-SAC | I0 |
| --- | --- | --- |
| 起点 | 空白 | 贪心规则给出的合法分配 |
| 模型做什么 | 逐个波束决定频率起点、槽数、功率档位，一次给出完整分配 | 每步从候选修改菜单里挑一个（移动一束的频率块、调整相邻两束的边界、同组两束互换、2到4束窗口重排、回退到最好版本、停止），用真实物理算一次效果 |
| 预算 | 每束一次决策 | 每景最多32步、32次物理探测 |
| 功率 | 自己学离散档位 | 不学，规则给初值，第三阶段SCA定终值 |
| 输出 | 最后一步的分配 | 过程中最好的一版（满足率、供需匹配、基本服务三项都不退步才替换） |
| 历史成绩 | 可变束数下需求满足率从未超过贪心，优势在供需匹配 | 2026-10-09在880景上比贪心高3.26个百分点，比同预算规则搜索高1.75、随机搜索高0.68（第二阶段报告15） |

**为什么主方法选I0而不是T-SAC。**2026-10-09定下"学习负责离散结构、数学优化负责连续功率"的分工，I0正好符合；它也是第二阶段唯一在满足率上稳定胜过贪心的学习结果。T-SAC保留为L2，是为了和W31、W32的结果接得上，只报告不设门槛。

**这次对I0的改动。**候选菜单加"两束交换频率组"（因为热点叠放后组的分配很关键），训练步数从历史40万宏步减到20万，其余超参不动。代码在`src/satellite_rl/sac_improvement/`。

## 2026-10-18 结果（S2-FIX报告12）

**I0比贪心高、能用少十倍的探测达到强搜索的质量，但同样耗时下贪心＋禁忌搜索一样好；直出T-SAC在需求压力下不如贪心。**主档43.2 Mbps、SCA后的业务量加权满足率：

| 方法 | 开发20景 | 确认88景 |
| --- | --- | --- |
| 贪心G1 | 94.4% | 92.5% |
| 贪心＋禁忌搜索32次 | 96.6% | 94.5% |
| 贪心＋禁忌搜索320次 | 96.9% | 94.9% |
| I0（32次） | 96.9% | 94.9% |
| 直出T-SAC | 89.5% | 88.3% |

- I0比贪心高2.5个百分点（过第一条判据），比同预算贪心＋禁忌搜索只高0.3（门槛1.0，不过），与320次贪心＋禁忌搜索持平。按预先写定的结局，第二阶段主算法为贪心＋禁忌搜索，I0记"同质量少探测"。I0每一步要生成候选并过一次网络，一步的耗时约等于贪心＋禁忌搜索三次探测；给贪心＋禁忌搜索同样的耗时（96次探测），两者一样好。
- I0在训练前2万步就学到了好的挑选办法，之后开发集几乎不再提高，加训练步数不会改变结论。新加的"两束交换频率组"动作被大量使用（约四分之一）。
- 直出T-SAC比贪心低4—5个百分点；把Transformer换成多层感知机满足率不变，所以对满足率而言Transformer不必要。
- 历史上I0"比规则搜索高1.75"的那个对手每步按固定优先级挑一个候选、不先看效果；这次的贪心＋禁忌搜索每步按同一优先级试前4个候选、取实测最好的一个，并禁止走回头路，强得多。详见[报告12](../../docs/Claude维护/S2-FIX第二阶段需求压力/12_S2-FIX第二阶段需求压力实验报告.md)。

## 2026-10-23 问题：从强化学习的角度，改进式T-SAC和直出式T-SAC有什么区别

**两者解的是两个不同的马尔可夫决策过程（MDP）：直出式是"构造式"——从空白开始逐束往下填，学的是"下一束怎么填"；改进式是"改进式"——在一整套已经合法的方案上，学的是"这一步挑哪种小修改"，本质是学出来的局部搜索。** 以下按 S2-FIX 的代码（直出 L2：`power30/`；改进式 L1：`s2fix/search_env.py` 与 `sac_improvement/`）说明。

| MDP 要素 | 直出式T-SAC | 改进式T-SAC（I0／L1） |
| --- | --- | --- |
| 一个回合 | 一个场景从空白填到满，按需求从大到小每束一步，共 N 步（115—150） | 一个场景从完整合法方案（容量感知贪心，或新提出的分散摆放规则）出发，最多 32 步，可主动"停止" |
| 状态 | 只看当前这一束：位置、需求、束宽、剩余功率，加上它所在频率组 100 个槽上的干扰和占用；Transformer 把这些切成 14 个令牌（几个标量令牌、10 个"每 10 槽一块"的频率块令牌、1 个全局令牌） | 看整套方案：每束 14 个特征（位置、需求、组号、起点、槽数、功率、当前容量/需求、历史最好方案的起点/槽数/容量比、起点时是否有基本服务、序号），最多 200 束，加 12 个全局量（已用步数和试算次数、当前/最好/起点的 SI 与 SGM、总功率比例），共 2812 维 |
| 动作 | 固定的离散三元组：频率起点（100）× 槽数（10）× 功率档（11 档，0.5、5…50 W），约 1.1 万种组合；组号不归它选（新环境由贪心事先定，原版按处理顺序除以 8 的余数）；用合法动作掩码排除冲突和超功率 | 从当步生成的候选菜单里挑一个（最多 16 个＋停止）：起点挪 ±1/±5、相邻两束间挪一个槽、同组两束互换、3—4 束轮换、跨组互换、退回历史最好方案；每个候选用 28 维特征描述"改了哪几束、怎么改、属于哪类"；功率不学（按需求比例给，最后交给 SCA） |
| 状态转移 | 把这一束写进方案；它的速率之后还会被后来同频的波束拉低 | 把修改用到整套方案上，用真实物理把所有波束重算一遍（一次"真实评价"） |
| 奖励 | 每束一个人工设计的塑形奖励：这一步让总满足率整整多了一束（本束补满且没拖累前面）记 +1，否则 −1；加本束 SGM；减供需偏差超过 50 Mbps 的罚分；减撞上已占用槽的罚分 | 只有刷新"历史最好"时才有：100 ×（新的最好满足率 − 旧的最好），且不能让起点时已有基本服务的波束掉到需求的 10% 以下；一回合奖励之和恰好等于最终比起点提高了多少 |
| 折扣、温度 | γ = 0.99，固定温度 α = 0.01（沿用 T0 配置） | γ = 1（为了让奖励累加正好等于总提升，代码里强制），固定 α = 0.01 |
| 网络 | Transformer 编码器（2 层、8 头、128 维）；三个输出头；评论家给每个头一组 Q 值，联合 Q 按"起点 Q ＋ 槽数 Q ＋ 功率 Q"相加近似 | 多层感知机：状态编成 128 维，每个候选编成 64 维，拼起来给每个候选打一个分（策略）或一个 Q 值（两个评论家）；候选个数可变，用掩码处理。名字叫 T-SAC，但目前没有 Transformer |
| 推理代价 | 每束一次前向，不调用物理评价 | 每步一次真实评价，共 32 次，外加候选生成 |
| 保底 | 没有，可能比贪心差 | 只保留历史最好，不会比起点差 |

从强化学习看，这些差别带来四个后果：

1. **奖励和目标对不对得上。** 直出式真正要的是"全部波束放完、干扰全部算完后的总满足率"，但它拿到的是逐束的塑形奖励；后放的波束拉低前面波束的损失，没有完整记到当初做决定的那一步，链条又长达一百多步，信用分配难，容易学出固定习惯（原版权重几乎每束都给 20 W、槽给得偏多）。改进式的奖励就是目标本身的增量，γ = 1 时回报正好等于最终提升，32 步以内，这个偏差不存在。
2. **动作空间与探索。** 直出式每步面对约一万种组合，靠分头输出和掩码降低难度，而 Q 值"三项相加"的近似忽略了起点、槽数、功率之间的配合。改进式每步只在十几个人工设计好的候选里挑，好探索，但能力被菜单框住：菜单里没有的改法它学不到。这也是它在强起点上只能多 0.1—0.2 点的原因之一。
3. **对数据和起点分布的依赖。** 直出式的初始状态永远是空白，输入的量级和范围一变就失效：原版权重放到欧洲数据只剩 19%。改进式的输入多是相对量（容量/需求比、相对改动），换环境也能用，在原版环境里不重训仍比贪心高 3.5 点。但它的"初始状态分布"由起点算法决定：在贪心起点上学的策略换到分散摆放规则起点，只有约 30% 的回合找到更好的修改。这是初始状态分布偏移，所以建议从新起点重训（报告21的 X1）。
4. **适用场合。** 直出式是"一次推理出整套方案"，推理时不需要物理评价，适合评价很贵或要实时出方案的场合；改进式是"带真实反馈的学习型搜索"，要求能快速算真实效果，换来质量下限和可随时停。组合优化的强化学习研究里，这两类通常分别叫构造式（construction）方法和改进式（improvement）方法。两者也能串起来用：直出式给初解，改进式接着改。

和实测对应：新环境确认集 SCA 后，直出式 88.3%；改进式从贪心起点 94.9%，从分散摆放规则起点（不重训）95.8%。原版环境里直出式（96%）反而比改进式（贪心起点 91.4%）好，原因见[报告21](../../docs/Claude维护/原版框架复现/21_T-SAC系列提升路线与变更范围.md)第 1 节：原版干扰强，摆放最要紧，而直出式在原版里能用满 8 个组、自由选起点。
