# 第二阶段怎样承接可变波束数量和逐束宽度

2026-10-14。

第一阶段交付实际布局，第二阶段照这份布局分配频率资源，第三阶段再调整连续功率。飞机、归属、中心、宽度、需求和波束身份在传递中保持一致，每架飞机统一21.6 Mbps。

本轮在独立分支补上第二阶段所需的输入：不只知道当前束需求，还能看到各束宽度、对应增益、束间干扰及已有分配。程序能处理1至200个实际波束；批处理补齐不会变成额外飞机或波束。只选择合法频率起点和槽数，规则给功率起点，最终连续功率由第三阶段处理。

旧模型输入和动作头不同，不能直接拿旧权重当成新模型。新接口、掩码、共享物理和旧权重拒绝已做针对检查，完整学习效果仍待验证；全包隔离导入还有一项既存R6路径依赖问题，见[工程核验记录](../../docs/工程文档/07_第二阶段可变布局适配核验.md)。

正式方案建议训练两组各15万次决策：一组直接读取宽度和增益，另一组隐藏这几项信息，但保留同样的真实布局和物理计算；两组都与贪心、固定规则和随机合法分配比较。先看直接结果，再看相同频率分配经过第三阶段后的结果，分别报告需求满足程度、供需匹配程度和耗时。

**当前先不训练。** 用户审核批准[通俗方案25](../../docs/第二阶段/方案/25_可变布局与逐束宽度的T-SAC适配方案.md)后，才实时核验远端任务归属、GPU/显存/CPU和并行条件；无冲突或能够安全并行才开始训练。不能用旧的空闲记录决定占卡，也不打断其它实验。新组与历史T0三算法复验分开，后者的例外不扩展到这里。

## 2026-10-14追问：两个组、状态空间和历史区别

两个组均为从头训练的新T-SAC，网络大小、数据、真实布局、共享物理、动作、奖励、种子及各15万步预算相同。L25完整组读取全部信息；A隐藏显式宽度/增益组仅把每束宽度、每束峰值增益、两束之间的发射增益三个输入通道置零。数组形状和网络均不缩小，环境仍按真实宽度计算容量。后者保留位置、角距、分组、槽重叠、容量和SI等间接信息，不能称完全不感知物理，也不是旧T0。它检验明确提供这三类信息的增量作用，不检验整套新架构的每项改动。

每步为一个波束作决定，但同时读取全部实际N束。状态主体为每束表N×16、两束关系表N×N×4、全局摘要12项，另有当前束索引、真实束mask、1001项合法动作mask和身份/协议元数据。展平主体含4N²+16N+12个数，实际按表处理，并非把它当固定长度向量。批处理才补齐，补齐项不参加注意力与平均；100仍是频率槽数，与N独立。

| 每束字段类别 | 字段 | 项数 |
| --- | --- | ---: |
| 几何与信道 | 中心纬度、经度、完整束宽、峰值增益、星地距离 | 5 |
| 请求 | 本束请求、占全景请求的份额 | 2 |
| 资源组和进度 | 资源组、是否已处理、是否当前束 | 3 |
| 已执行分配 | 频率起点、槽数、规则功率 | 3 |
| 当前服务结果 | 容量、SI、SGM | 3 |

两束关系的4项是角距、发射束按其自身宽度产生的方向增益、是否同极化且不同资源组、实际频谱重叠槽数。它提供干扰相关信息，不是完整逐槽实际干扰功率矩阵。全局12项是实际N、处理进度、已用功率、已用槽数、全景平均SI/SGM、总请求、固定每槽功率规则，以及4个占用率摘要（每项合并相邻两个资源组）。各字段按代码固定尺度表达，真实需求及发布对象不被改写。容量、SI、SGM取当前已执行分配，未服务束为0，不读取未来动作结果。

| 历史实验 | 当时比较什么 | 与方案25的区别 |

| G11 T0及S2-T24 | T0原任务，T24比较SAC/PPO/DQN | 207维当前束/频率槽摘要、固定100束/0.5°，学习频率/槽数/离散功率；新组读真实可变布局和宽度 |
| S2-P17 V0/V1 | 固定100束训练与混合束数训练 | 同为210维状态，关键区别是训练束数分布；0.5°方向图不变，场景由准备工具生成，不等于S1最新实际布局 |

| S2-P19 I0 | 从贪心完整分配开始，多步学习修改 | 方案25当前按束从空分配构造，不是直接将既有I0赢家换接口；未继承其学习效果证明 |

T0的207维由当前束等基础4项、100个频率槽干扰、100个频率槽占用和3项全局摘要组成。两个100是槽数，不是波束数。P17在207维后增加束数、剩余束数和功率压力等3项到210维；后来P18继续修正和扩展，不能把所有历史模型都概括为没有逐束信息。

方案25相对T0还有五项实质变化：只学习起点和槽数，功率按3.75W/槽给定；显式1001动作含零槽，旧T0则学习5—50W离散功率；新掩码不沿用为每个后续束预留1槽/5W的机制；外部奖励改为全N平均SI差分且gamma1，SGM不直接进入奖励但仍作为状态字段和评价指标；网络改为逐束关系Transformer和完整频率联合Q。新方向图又与legacy图不同，因此历史分数不能直接排名。

这些变化中，稳定身份/需求守恒/实际宽度对应物理和状态支持属于本次接口目标；具体网络、Q结构、奖励、功率规则、零槽及预留选择并非实现可变宽度的唯一必需方式，是待审议的新研究设计。两组比较只能归因显式信息的贡献，不能证明全部变化各自有益。此次只补充解释和文档，不改代码、实验预算或授权状态，不启动训练。
