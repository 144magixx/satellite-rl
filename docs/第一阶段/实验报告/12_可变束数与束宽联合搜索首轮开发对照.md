# 可变束数与束宽联合搜索首轮开发对照

S1-AI17｜2026-10-13｜首轮开发中间报告；原768条诊断教师已计算完成，标签完整性另核，正式AI模型尚未训练。

**这轮证明了联合调整波束数、宽度和飞机归属可以产生新的可行取舍，但尚未证明新搜索在相同资源限制下优于已有方法。** 规则搜索在79/80个开发案例中扩展了初解的Pareto结果，30秒参照也在79/80例中找到了10秒规则结果之外的新点。另一方面，在共同束数与角域预算内，规则搜索与初解的61个可比案例峰值全部持平；固定宽度JOINT加末端缩宽仍是很强的对照。根进一步发现80案例中18例的INIT/RULE/RANDOM初始档案SHA集合不一致，因此当前只能保留开发描述与有限诊断教师，正式训练暂停准入；不能把这一步写成严格同初解的排序收益、AI已经有效或最终算法已经完成。

## 比较的是什么

本研究只处理第一阶段：全部飞机几何覆盖、唯一归属、请求需求守恒、实际非空束数N≤200、空间负载分配和规划成本。宽度是卫星视角全宽，重构菜单为0.3°、0.5°、1.0°，可在固定中心与归属后收缩至[0.3°,1.0°]内的合法包络。覆盖逐束独立复算；不使用业务满足、承载、PHY、SI、SGM作为指标或门槛。

数据是2024年1月12日的20个开发母场景，每母产生原始、单热点、双热点和边缘集中四种合成请求分布，共80案例。四种分布保持该母的飞机位置、ID集合与总请求不变，只改变请求的空间分布。它们不是80个独立母样本，更不是实际通信流量观测。当前结果全属开发证据。

本轮已完成六个非AI配置480条、固定0.5°的07/JOINT两种目标桥接320条、30秒规则强参照80条，合计880条。科学源码为`fbd3a743dc93ac14a7352e4f66a30db9194dc300`；输入、配置和预算在运行前冻结。独立审计880/880通过、剩余问题0，表示这些计算和证据可以用于本开发报告，**不表示所有方法都成功发布解或通过科学效果门槛**。

| 配置 | 实际作用 |
| --- | --- |
| INIT | 三档宽度纯几何初解及合法包络收缩，保存可行非支配档案 |
| RULE | 规则顺序检查区域重构任务，可改变局部束数、离散宽度、中心与归属 |
| RANDOM | 与RULE相同任务及重建器，只改变检查顺序，随机种子51001 |
| N_ONLY | 只允许束数变化，全宽固定0.5° |
| W_ONLY | 固定0.5°初解的N，允许逐束宽度与区域重构 |
| POST_SHRINK | 固定N/0.5°运行原JOINT，再做末端包络收缩；检验新增联合搜索是否超过强后处理 |

联合方法每景上限为10秒/8192次完整候选，先到先停；初始化共享2秒/2048且计入总账，生成、几何核验和收缩均占用预算。POST_SHRINK在同一总账内预留1秒收缩。原07/JOINT桥接每景2秒/4096候选，保留独立预算；30秒/24576候选的RULE只作较强的有限参照，不与10秒法称同预算胜负。开发时三端并行，墙钟截断会受争用影响。[共同起点复核](../../../outputs/experiments/first_stage_ai_search_20261013/preflight/root_common_initial_mechanism_check.json)确认80案例中18例的INIT/RULE/RANDOM实际初始档案SHA集合不一致；共享2秒初始化的墙钟截断是待核原因，不能预先断言唯一成因。当前不满足严格同初解因果比较，实际有解集合不同须单列，不能把差异全部归给排序。

## 新取舍确实出现，但峰值未同步改善

联合搜索保存五维结果：实际N、总角域Ω、原单位峰值负载、最重10%束的平均负载及CV，均越小越好。Ω为各束圆锥立体角之和，重叠重复计入，**仅是几何占用代理，不是地面并集、容量、能耗或天线资源**。不同维度相互取舍，不能压成一个总分。CV继续保留作为均衡诊断，不能单凭CV较低否定峰值或束数代价；跨N不能用分母已变化的P/T排冠军。

空间门槛比较RULE与INIT的完整档案，79/80案例存在新的非支配目标点；按母顺序分前后两半，分别为40/40、39/40。较长参照相对10秒RULE也有79/80案例出现新点。门槛按目标数值判断，不把布局文件SHA变了就算进步。离线oracle排序机会计数为0，教师准入是由较长参照分支通过，不能补说“已经证明排序能节省20%计算”。

后续只读诊断进一步区分了“没有机会”和“当前证据未达到门槛”：122个参考任务池中79个未满24任务、20个含截断，只有23个可判。可判池全部是束数或角域优先，没有峰值优先池；22池存在字典序改进，但质量最佳六项的实际解码时间是规则前六项的3.21–25.94倍，中位9.65倍，候选成本也全部超出规则前六项。旧oracle比较固定六项，不是达到目标的最短前缀，故其零计数不能解释为完全没有排序信号，更不能反向当作已证明负载排序收益。原门槛保留，第二版需另行定义有意义的目标与成本比较。

## 波束数和宽度是否真正参与决策

RULE发布成员的N范围为62–163，INIT与RANDOM为62–164，N_ONLY、W_ONLY、POST_SHRINK为42–78。它们是各景按峰值优先选出的描述性成员，完整科学结果仍是各自档案；不同方法的N分布不能直接当作等资源条件下的效果排名。实际没有N=200的压力证据，也没有验证整个1–200范围。

区域任务确实允许增减束以及在离散宽度下重建中心和整机归属。审计显示，RULE在77/80案例出现改变N的候选，在78/80案例出现混合宽度候选；RANDOM对应67/80、79/80。**这些是候选层面的机制证据，不表示全部被接受，也不等于最终选出的成员同时改善N和宽度。** 其中“离散菜单重构”字段也会计入固定0.5°的N_ONLY，故不能单独把该字段当成“宽度实际改变”的证据。

图3的Pareto投影固定采用母清单第一项的base场景`2024-01-12T00:37:00Z`，没有按成绩挑图。该景RULE的峰值优先成员全宽均为0.3°，W_ONLY则为0.3°至约0.49847°的逐束混宽。图4进一步读取全部480条开发原记录，478条有最终发布成员；INIT和RANDOM各一条未找到的宽度保持未知。各方法真实最终宽度如下，混宽仅表示同一布局内宽度不同，不等于质量更高。

| --- | ---: | ---: | ---: |
| INIT | 79 | 0.3 | 0（另1未知） |
| RULE | 80 | 0.3–0.5 | 19 |
| RANDOM | 79 | 0.3–1.0 | 8（另1未知） |
| N_ONLY | 80 | 0.5 | 0 |
| W_ONLY | 80 | 0.3–1.0 | 80 |
| POST_SHRINK | 80 | 0.3–0.5 | 67 |

补充核验按实际父布局的持久beam ID比宽度值，并对新束检查其宽度是否超出原区域的宽度值集合，排除数组长度变化。这给出保守的充分见证：RULE有62/80、RANDOM有51/80案例出现同一次候选同时改变N与离散菜单宽度；N_ONLY真实变宽见证为0。候选存在不表示已接受或最终同时改进。POST的内部任务轨迹缺失，不能画成零次变化；其最终束宽有实际布局可核。末端缩宽只在原中心和归属上收紧包络，与改变宽度后重新分组、增减束不是同一机制。

## 成本、审计与证据边界

六法端到端观测时间均值依次为INIT 1.59秒、RULE 10.05秒、RANDOM 9.95秒、N_ONLY 10.05秒、W_ONLY 10.05秒、POST_SHRINK 8.84秒。对应完整候选数均值约2.44、45.81、44.23、79.68、47.56、3482.38。完整候选的工作量并不相同，大量未形成完整布局的几何尝试也耗时；不能仅凭候选多或GPU空闲判定方法高效。30秒参照均值30.07秒、119.36个完整候选，属于额外计算成本。

![图5：开发并发下的端到端观测成本与完整候选数，包含初始化；不是严格算法速度比较。](../../../outputs/experiments/first_stage_ai_search_20261013/analysis/publication_r1_development/05_observed_development_cost.png)

上述时间是实际争用和不可分割操作下的观测值，预算附近的小幅超时计入实际成本，晚完成结果不能回填早期节点。POST_SHRINK的终态布局与common切片质量有真实数据，但原记录缺少可靠的完成时点，图1中其严格2秒和10秒节点均保留缺失，不由终态补画收敛曲线。

初次后处理曾把区域超过256机时提前返回所省略的`attempts`字段误判为预算问题。修订审计使用21项工程检查及556条带源码语义的提前返回计数证明，确认该分支未进入候选求解；原缺字段、无法恢复的时间信息和旧失败报告全部保留。六法开发中，超过256机的提前返回分别发生于RULE的207任务/34案例、RANDOM的185任务/29案例、N_ONLY的13任务/8案例、W_ONLY的9任务/6案例；这些任务的独立耗时未知，不补零。556条证明涵盖所审计范围，不能与仅开发的上述414条机械混为同一分母。此次修复只改审计解释，未修改科学源码或数值、未重新求解，不能称发生了556次几何违规，也不能据审计通过宣称日志每一时间字段完整。

统计采用同母四profile等权后跨母汇总；某母缺任一profile时不进入该指标的均值区间，同时保留缺母与案例状态。图中95%区间由母级、日期分层bootstrap得到，5000次、seed51001；开发母来自同一日，不能据此宣称跨日期稳定。区间用于描述，未作正式多重比较结论。原请求单位bps，图表峰值除以10⁶转为Mbps；Ω为sr。出图软件为Python 3.11.11、NumPy 1.26.4、Matplotlib 3.8.0。全部场景的逐束宽度点之间相关，仅展示实际分布，不按独立样本计算置信区间。

## 下一步已衔接，但AI与最终考核仍待

通过的是开发阶段的搜索空间与教师准入门槛。原192训练母×4分布、768案例的教师已在03:15根实际API核得全部完成、科学worker退出；因共同起点问题，本批仅作为R1有限诊断教师，禁止自动转入训练，标签完整性与是否复用另核。其预算为单景15秒/3072完整候选，总上限2,359,296候选；不是追加种子或无限延长优化。原计划拟从头训练一个23,682参数的53维排序MLP，seed51001、固定10000更新终点，检验它是否在相同解码器和总预算下优于规则与随机顺序。这项正式训练尚未准入；共同初始化诊断已完成，须据此冻结R2修订，不得把旧G1通过回执当作绕过新问题的许可。本报告没有AI质量点、学习曲线或已完成训练的结论。

Feb17–20输入准备曾有16次连接超时，四个原任务同ID恢复后完成输入验收；新验证20母80景、最终考核40母160景已合并保存。**准备了test输入不等于运行了test算法，目前没有这些新test的算法结果。** 先看教师与验证证据，再按冻结规则决定是否开启独立考核；若某学习分支无效，保留失败并改进有证据支持的机制。静态N/宽度联合能力、AI额外贡献、独立泛化和完整归档分别验收，不把这份中间报告写成动态覆盖或全课题已经完成。
