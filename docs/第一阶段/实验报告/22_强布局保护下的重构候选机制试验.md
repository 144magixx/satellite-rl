# 强布局保护下的重构候选机制试验

S1-AI17-R9-M｜2026-10-14｜完整训练前机制报告。固定12个原训练母、384描述槽及345次实际内核进入已独立审核并由根复算；M未通过学习必要性门槛。本R9的剩余84母标签、1000更新模型与开发640描述预算全部关闭、不转移，heldout未读取。

**有限局部重构确有负载价值，但本轮结果不支持为这组候选训练排序模型。** 全池oracle在7/12母达到相对受保护原点的质量目标，超过6母要求；然而，它没有一母进一步超过较强几何规则前8的目标，低于3母要求。固定位置1——最重束与最近邻的2→2重构——同样覆盖全部7个成功母，oracle成功数减最佳固定位置为0，未达3母差距。因此停止R9后继，保留实际数学算子的价值；没有进行模型训练，不能称作学习失败、模型无泛化能力或全部AI路线无效。[根负结果接受](../../../outputs/experiments/first_stage_ai_search_20261013/round9/M_independent_analysis_01/root_M_negative_result_acceptance.json)已正式冻结这一判定。

## 研究问题与固定范围

依[方案26](../方案/26_强布局保护下的局部重构价值学习草案.md)及[结果前v3合同](../../../outputs/experiments/first_stage_ai_search_20261013/design/round9_design_v3.json)，本轮拟学习具体“区域＋目标束数”的候选价值，而非重复R2的固定八任务选择器，也不沿用R8旧owner分数的同收益排序。M阶段本身没有学习模型，其作用是决定后续监督学习问题是否有依据。局部改写与学习邻域选择的研究来源沿用方案26所列原论文，本文不引入新的方法或外部成绩。

数据是原576个统一请求训练母中预定96母的首个机制子集。96母按原索引0、6、12、…、570选取，M使用其中固定的0、6、12、18、24、36、42、48、54、60、72、78，共12个。它们是训练角色下的机制样本，不是12个独立验证或test样本，也不是从结果较好的案例中抽选。后续训练划分与20个重复开发母保持原设计，当前没有读取heldout。

每机请求为21,600,000 bit/s，完整飞机及稳定ID均保留，每机只归属一个实际非空波束，逐束需求等于归属飞机请求之和。实际N≤200以及各母原prepared的Ncap和Ωcap同时适用，不能把200当作每母都可用的配额；束宽是[0.3°,1.0°]内的真实卫星视角全宽。第一阶段只考察覆盖、归属、请求负载、资源与重构成本，不用PHY、SI、SGM或业务满足指标。

## 强原点、候选与非学习参照

每母先新构造一次原RULE提议并调用原D5一次，得到共同的RULE保底终点。只有D5实际status=success才是合格保底；fallback虽可发布Wenv，仍意味着该母资格失败，原12分母保留，不用T或Wenv替代，也不重抽或重试。该解释已在真实结果前通过[success-only资格澄清](../../../outputs/experiments/first_stage_ai_search_20261013/design/round9_RULE_floor_qualification_clarification.json)固定，不是看到M结果后增加或修改门槛。

原Wenv和已有T仅在峰值、上尾、CV都不劣于同景RULE（原容差）时才可参选，随后按峰值、上尾、CV、N、Ω及固定来源名的原值字典序选定唯一共同原点。所有候选独立从它出发，不能用前一候选先改变原点。候选最终发布须同时保护原点与原RULE的三项负载指标，防止累计容差放宽；没有合格改善就保留原点。

候选池最多32个描述：最重8个源束，每束依固定顺序有1→2拆分、与最近邻2→2重分、2→3扩展、2→1合并四种结构。区域全部成员最多128，超限保留明确不可用描述，不删飞机或追加替代区域。候选中心取区域实际飞机锚点，确定性整数容量流分配区域全部成员，再计算真实外扩包络及完整Ω。区域外飞机到稳定beam ID的关系、锚点、宽度和需求保持原值；数组序号压紧不等同实际改归属。

新内核严格拒绝外扩nextafter后超过1°的包络，不裁成1°；这种拒绝只能说明该保守内核没有发布该候选，不能宣称原覆盖问题数学不可行。固定锚点、强制锚点自归属、最多8次可行流与有限扫描也决定了全池结果只是这个有限候选域的上限，不是区域或全局最优。

| 参照 | 使用什么信息 | 在M中的用途 |
| --- | --- | --- |
| 全池oracle | 完整池已知终点，按受保护目标选最好点 | 描述有限候选上限，不能当模型成绩 |
| Hq前8 | 全景峰值下界max(区域外最大人数, ceil(区域人数/目标束数))，再按Ω下界 | 强几何规则参照 |
| HΩ前8 | 先按区域外Ω＋目标束数×floor束Ω，再按同一全景峰值下界 | 另一种强几何规则参照 |
| 固定位置 | 所有母都取同一个原候选位置 | 反证是否根本不需要学习选择 |

Hq、HΩ各自的前8终点由完整池中的原候选结果构成，M不另跑两份候选。两规则中较好的终点是更严格的比较参照，不能称其为只花8项预算的实际组合算法。固定位置也不能逐母挑不同位置；那样等同用了oracle信息。
