# 邻域余量与两步波束重构的机制比较

报告25｜S1-AI17-R12｜2026-10-15

**本轮为限定范围内的有效负结果。** 十二个开发母场景完整审核后，事后最好两步结果对强历史参照、综合强参照和一步结果的命中均为0/12，原四项合取门槛全部未满足。本轮序列选择器与对应训练分支关闭，既有最佳已核方案不变。结论已获[根科学接受](../../../outputs/experiments/first_stage_ai_search_20261013/round12/root_actual_R12_scientific_closure.json)；本报告只整理保存的小表与独审CSV，未重新执行求解或几何审核。所选规范归档仍在准备。

## 1. 研究问题与方法选择依据

在多波束HTS覆盖规划中，全部飞机得到几何覆盖并不意味着各波束的请求负载已经均衡。飞机密集区域可能形成多个并列最重波束，而局部重构若只涉及其中一个波束，便无法降低全景峰值。本研究因此考察一种包含全部峰值束及相邻低载束的联合重构，并进一步比较一步选择与两步选择的效果。研究目标是判断有限动作空间中是否存在超过强规则和固定序列的选择余量，为后续是否采用学习方法提供依据。

此前探索已经提示，数学重构产生收益与学习选择产生额外收益必须分别验证。整体归属预测曾遇到修复困难；固定模型分数未证明相对几何规则的增量；较小局部候选池与全景成本族中的收益也可能被一个强规则或固定动作覆盖。这些结果推动本研究先检验动作空间，再考虑模型训练。R11因完整审核未闭合而保留为不完整结果，其部分质量摘要不作为本轮选题依据。历史失败、未通过门槛的结果与中间方案均保留，不能将其改写成新方法已经有效的证据。

原[方案29](../方案/29_联合瓶颈结构动作与两步价值试点.md)只联合全部并列峰值束。若有r束、每束p架，联合区域人数为rp，同束数重构且不允许提高峰值时，每束仍只能为p架，人数多重集不变。在原核的成员与目标束数依赖下，先同束数重构再增束与直接增束落到同一问题，不能构成所需两步优势空间。该方案在真实科学执行前被静态否决；这是结构性设计证据，不是一次算法实验负结果。

随后冻结的[方案30](../方案/30_邻域余量支持的两步波束重构试点.md)加入一个与峰值区域有覆盖接触的低载邻束，使同束数重构有可能改变人数多重集和下一步作用区域。它消除了原支配证明的前提，但没有预先证明两步一定有效，也没有证明固定“增束—增束”不能覆盖全部收益。本轮全部对照正是用于区分这些可能性。

## 2. 场景、决策变量与评价边界

试验固定使用索引0、6、12、18、24、36、42、48、54、60、72、78的12个已见训练母场景，共4715条飞机记录。这些场景已经反复用于方法开发，本轮属于开发机制试验，不是独立测试。不得因观察到新结果而替换场景、原点或历史参照。

所有飞机采用相同的21.6 Mbps请求量。布局须保持完整飞机集合、稳定ID和位置，每架飞机唯一归属一个非空波束，总请求守恒。实际束数不超过200，并受原场景Ncap和总立体角Ωcap约束；逐束全宽由真实成员包络决定，范围为0.3°至1.0°。本轮只研究同束数或增加一束的局部动作，不包含减束与动态时序决策。覆盖、请求负载分配和几何资源是第一阶段指标，未引入PHY、需求满足率、SI、SGM或实际承载目标。

共同原点B为R10采用的已审核R9终点，历史强参照来自同B的R10固定束数顺序重构S2和可变束数顺序重构SH-C。旧方法不重跑，原输入、完整归属和历史费用仍作为来源保留；不能将这些已计算原点视为没有构造成本的部署输入。

评价记录峰值请求、上尾10%波束平均请求、变异系数CV、实际束数N和总立体角Ω，并保留每束中心、宽度及归属。每机请求固定时，负载排序与整数人数排序一致。变N、变宽或相对原点改善只能说明数学动作产生了变化，不能单独证明选择学习有效。

## 3. 邻域支持的两步重构

对当前状态X，先找出全部并列峰值束P，设峰值人数为p、峰值束数为s。支持束必须位于P外，人数小于p，且与至少一个峰值束的当前锚点存在按最大允许束宽定义的覆盖接触。完整联合区域还须满足s≤30、总人数不超过128。筛选后按人数下界、支持束人数、到峰值区域的最小中心角距及稳定beam ID确定唯一支持束，所有信息均来自动作前状态。

覆盖接触保证当前锚点域存在候选跨区域覆盖边，但不保证新锚点图连通、完整匹配可行、总立体角合规或负载保护通过。没有合格支持束的场景保留原点，并保留在12场景分母中；不改变接触阈值或删去该场景。

联合区域R包含全部峰值束及一个支持束，共r=s+1束。动作J0保持r束，动作J1改为r+1束。两者使用同一局部核构造锚点、查找有容量限制的完整匹配，并根据成员重新计算真实束宽。区域外的beam ID、中心、宽度和归属保持。超过Ncap、最小宽度Ω下界或实际宽度/Ω约束的候选按原规则拒绝；候选还须同时满足相对当前状态与共同原点B的负载保护。

同束数动作能够使峰值下降一架的必要人数条件为支持束人数c≤p−s−1。该条件只用于解释机制，不用于事后剪枝；满足它仍可能因几何关系而失败，不满足它也可能通过减少峰值重数或改善其它受保护量而改变下一步区域。

每一步重新确定峰值集合与唯一支持束。在B上分别执行J0/J1，再从两个首层结果分别执行J0/J1，形成00、01、10、11四个深度二序列。共享前缀及相同语义节点只引用已完成结果，不重复求解；每母最多6次核调用，全组最多72核、576次内部流。拒绝动作保留原状态，而不是强制采用不可行布局。

内部排序采用排列不变的键K=(最大人数，T/t，NU，N，Ωkey)。其中t为上尾10%的束数向上取整，T为对应人数和，U为所有波束人数平方和。T/t通过整数交叉乘法比较；在总飞机数固定时，CV²=NU/n²−1，因此可变N时不能仅比较U。Ωkey对规范排序的逐束浮点项作精确和，消除排列导致的末位差异，不增加物理模型精度。最终显示指标、硬约束及命中容差仍沿用原定义。

## 4. 对照关系与预先冻结的门槛

| 方法 | 固定定义 | 用于回答的问题 |
| --- | --- | --- |
| S | 同B的历史S2/SH-C按原规则选择较好终点，平局选S2 | 新动作是否超过已核的强历史参照 |
| H | 每层根据动作前人数与资源下界选择一个动作 | 简单可计算规则是否已足够 |
| G | 每层比较两个真实保底终点，以K选较好者，平局J0 | 两步前瞻是否超过同核的逐步贪心 |
| F00、F01、F10、F11 | 对全部母场景采用同一个固定两步序列 | 是否必须按场景选择序列 |
| Q | 以K在S、H、G中择优，完全相同按S/H/G打平 | 相对强非学习参照的剩余空间 |
| O1 | 原点及两个首层终点中的有限最好点 | 一步动作已经能够取得多少收益 |
| O2 | 四个两步序列末状态中的有限最好点 | 两步有限池中的事后最好结果 |

O1和O2均为有限候选池的事后选择结果，不是已训练模型，也不是全局最优。H、G、固定序列与O2共享同一核；必须分别统计逻辑调用成本与实际共享树成本，不能将整棵树的成本当成每种在线策略的独立实测耗时。

对指定参照的“命中”要求峰值请求不超过参照的0.99倍，同时上尾平均请求与CV不恶化，沿用冻结的绝对及相对容差。只有12母的身份、约束、树引用、来源、计数和退出全部审核完整后，才判定以下四项是否同时满足：O2对S命中至少3母；O2对Q命中至少3母；O2对Q成功数比最佳固定序列对Q成功数至少多3母；O2对O1命中至少2母。最佳固定序列按全12母相对Q的成功数选择，平局依次00、01、10、11。

上述门槛分别限制“只是超过旧算法”“只是超过弱规则”“只是一个固定动作有效”以及“第二步没有额外价值”的解释。即使全部通过，也只说明存在值得进一步研究的选择余量，不证明某个模型能够学到它；模型与标签预算仍须另案冻结。本轮模型初始化、前向、训练更新与heldout读取均为0。

## 5. 已完成计算与审核限制

十二母生产均记录正常退出，生产完成记录中的累计时间为26.368995秒。已收集188份原件，合计约2.56 MB。完整审核小表记录实际27次核、160次内部流、4715条生产射线及34988次生产角对操作；未使用槽位不补填。小表按逐母原生回执求和得到26.369149984791875秒，与生产完成记录采用不同计时口径，两者分别保留，不相加、不将其差异包装成性能改进。共享树费用也不能直接当成各方法独立在线运行费用。

首次独立审核因父进程递归目录观察与Journal原子发布的并发冲突而中断：临时文件在枚举与读取之间被合法替换，重复观察仍发生冲突，父进程因此退出。该错误属于运维观察机制，不能据此判断重构方法无效。旧源码、部分缓存、owner锁、错误和成本原件均保留。

原审核总上限为120秒，旧对照输入核验先扣10秒。首次审核的内部计时不足以覆盖全部外部等待，故按首次确认退出相对于reader出生的92.81705秒观察界保守上取93秒，累计先扣103秒，仅余17秒。根接受的[唯一接续约束](../../../outputs/experiments/first_stage_ai_search_20261013/round12/resume_20261015_0858/reader_continuation_design_01/root_one_reader_continuation_design_acceptance.json)要求实际缓存资格、必要复制、导入、剩余审核、保存和退出均包含在同一次17秒内；14秒停止新几何工作，预留3秒退出。它不是追加审核预算，也不允许重跑求解器或重新审核已完成的几何。

接续只修运维适配，科学数学源码保持。空间保护改为停产后的全轮静态字节基线，加新单写者发布前的限额检查，避免在原子发布期间递归扫描目录。原128 MiB规范产物、64 MiB临时空间、2 GiB父子RSS和实际磁盘余量要求保持。唯一接续实际外部计时约6.563秒，内部含保存约6.295秒，两者为包含关系，不相加。按事前收束合同仍将17秒额度全部扣账，累计审核预算120秒关闭；剩余时间不转移、不追加第二次审核。

终态审核记录为4715条射线、138215次角对、23个布局，inflight为空；首次已保存的891条射线、28170次角对及5个布局缓存得到复用，不作为新一次全量重审。生产计数与独立审核计数分别记账，不能混成单一方法费用。最终退出、缓存连续性及费用已由[独立实际验收](../../../outputs/experiments/first_stage_ai_search_20261013/round12/resume_20261015_0858/reader_continuation_review_01/actual_saved_output_review_01/independent_actual_reader_review.json)核实，并获根接受。
