# 第一阶段自主研究综合报告

S1-AI17｜R1—R14｜2026年10月15日暂停收束版

## 摘要

本研究围绕多波束高通量卫星的覆盖规划，探索在全部飞机几何覆盖、唯一归属和请求守恒条件下，联合决定波束数量、指向与逐束宽度，并改善波束间请求负载分布。报告综合本聊天自2026年10月13日以来的十四轮研究，以方案17—32、实验报告12—26及R14已接受记录为主要依据。此前第一阶段报告01—11用于说明方法演进背景，不计作本组新增实验；第二、三阶段仅讨论数据与接口一致性，不汇总其训练成绩。

截至本次暂停，研究已形成可变束数、逐束可变宽度的合法布局构造与修复方法、统一单机请求数据、可追溯教师标签以及多组有完整对照的有限机制结果。较明确的正面成果来自非学习方法：共同强初解上的飞机归属重分能够进一步改善负载；固定锚点域的成员修复提高了带误差提议的恢复率；强顺序重构在已见十二母场景上形成了值得保留的质量参照。统一请求版本保留全部飞机，每机固定21.6 Mbps，576个训练母中574个形成合格教师标签，564个教师同时改变实际束数并使用不同且不全取下界的束宽。这些成果说明问题建模、数据和若干数学算子已经具备可用基础，但不能归为学习模型的性能收益。

本组确实进行过一次科学模型训练：R7的200-query图神经网络集合模型以seed51001完成2000次更新，学习波束启用、飞机锚点及整机归属。在20个反复使用的开发母场景中，其新提议非回退仅1/20，质量成功0/20，未达到原门槛；剩余4000次更新关闭。R8改用相同模型的缓存分数辅助合法局部转移，非回退达到20/20，但相对几何／随机较好参照的质量成功仅2/20，仍未通过5景要求。因此，当前不能宣称已经得到优于强非学习方法的第一阶段AI算法。

后续研究逐步把学习问题收缩为候选选择与停止选择，并先检查其增量空间。R9、R10和R12的完整机制比较均未达到各自预先门槛；R11因审核不完整，只能保留未知结论。R13在十二条历史强顺序轨迹上发现提前保质机会，但最早安全位置相对逐母事后最佳固定规则只额外减少35/211=16.5877%的核尝试，未达20%。该值不是实际时间节省。R14转向可部署停止规则学习，目前140母数据资格、统一登记及全部合法初始布局B已完成并接受；教师轨迹、模型拟合、校准和开发评价实际均为0。用户现已要求暂停，后续不由本报告自动恢复。

本报告的主要结论是：第一阶段已经积累了可信的几何与负载优化基础，也识别出若干不值得在原条件下继续投入的学习分支；尚未完成的核心事项，是在可变N及逐束宽度、严格覆盖与资源约束下，证明一个实际学习决策相对强因果规则的质量或真实时间增益。现有数据多次参与开发，单seed与有限候选的结果不支持独立泛化、全局最优、动态部署或三阶段业务效果结论。

## 1. 研究背景、范围与问题界定

### 1.1 从覆盖可行走向负载与计算代价协调

多波束覆盖规划不仅需要把飞机放入某个覆盖范围，还需要避免少数热点波束集中承接过多请求。增加波束或扩宽覆盖范围通常能够改变分组可行性，却也改变几何资源使用和后续资源分配所面对的结构。因此，本研究没有把“覆盖率较高”“CV较低”或“束数较少”单独作为最终完成条件，而是在全部飞机保持、几何合法及资源约束内，分析峰值负载、重载上尾、整体分散程度和配置代价之间的关系。

此前研究已提供若干直接动机。早期固定百束PPO与聚类、局部搜索比较，没有建立学习微调的稳定优势；覆盖修补能够显著改善覆盖，但不等于负载均衡目标已达到。区域重构研究说明缓存、接受状态与独立几何审核必须一致。后续可变束数、多路线和MLM比较进一步显示，强规则与联合重分是不可忽略的参照。尤其报告11的多束联合重分形成了有价值的非学习基础，而模型拟合教师标签并没有自动转化为优于规则顺序的收益。[历史背景：报告02](02_七组覆盖规划独立场景对照.md)、[报告06](06_区域重构PPO机制检查与停止诊断.md)、[报告08](08_可变波束全覆盖与负载均衡十二路线对照.md)、[报告10](10_非DRL十二路线覆盖与负载均衡对照.md)、[报告11](11_几何约束负载重分组与MLM候选排序对照.md)。

这些历史组采用过不同请求、固定宽度及评价条件，其中部分还使用后续阶段的服务指标。它们保留原假设，不与本组统一请求结果拼成总排行榜。本组当前的第一阶段边界是纯几何、请求负载和规划代价；业务实际承载、需求满足、PHY、SI和SGM属于后两阶段及另行定义的跨阶段评价。原开题中的动态最优、稳定性与部署预期仍是研究目标，不写成已证成果。

### 1.2 决策变量、硬约束与质量指标

对一个母场景，令飞机集合为A，飞机a的位置、稳定身份和请求分别为p_a、id_a和d_a。布局由实际非空波束集合B、指向c_b、卫星视角全宽w_b及唯一归属变量x_ab构成。当前统一请求版本满足d_a=21,600,000 bit/s，x_ab∈{0,1}，且每架飞机有且只有一个所属波束。逐束请求为L_b=Σ_a x_ab d_a，因而Σ_b L_b=Σ_a d_a。飞机数及身份不能因生成布局失败而改变。

几何约束要求每架飞机位于其所属束的合法覆盖范围内，实际非空N=|B|≤200，逐束全宽处于0.3°—1.0°。0.3°、0.5°、1.0°是部分重构方法的候选菜单，最终宽度可由实际成员包络在连续区间内形成，不能把三档菜单误写成全部发布宽度。每景另有自己的Ncap和Ωcap；全局N≤200不意味着所有场景都可以用满200束。Ω是各束圆锥立体角之和，重叠重复计入，仅为几何占用代理，不是地面覆盖并集、通信容量、功耗或真实载荷资源。

质量评价采用原单位峰值请求、最重ceil(0.1N)束的平均请求，以及全部非空束负载的总体标准差除以均值得到的CV。比较时同时保留N、Ω及布局合法性。统一请求后，负载可等价表达人数组合，但交付仍保存真实bit/s。跨N的平均负载、上尾集合和CV分母均会变化，不能只凭某项归一化量宣布全面更优。各轮采用其事前冻结的质量容差与门槛；本报告不把它们重写成一个事后统一成功标准。

### 1.3 学习的实际位置与证据层次

本研究先后考虑了三类学习作用。第一类是决定优先尝试哪个重构任务；第二类是直接预测波束启用、锚点和飞机分组，再由几何方法修复；第三类是在已有合法布局和强重构方法上，选择局部候选或停止规则。只有第二类在R7实际产生了科学训练模型；R8复用其缓存分数，其他相关轮次大多止于学习前机制检验，R14尚未拟合。

为避免把方法提出、代码实现、计算完成和效果成立混为一谈，本文分别使用以下证据层次。

| 层次 | 可以支持的陈述 | 不能据此支持的陈述 |
| --- | --- | --- |
| 方案及实现 | 决策和约束已有明确实现方式 | 已运行、已改善质量 |
| 工程资格 | 指定输入、接口、约束或恢复行为通过检查 | 真实场景总体收益、AI有效 |
| 教师／候选计算 | 有合法目标或有限可达点 | 模型已学会、全局最优 |
| 实际训练 | 指定模型完成指定更新 | 直接输出可行或超过强基线 |
| 完整共同评价 | 在指定数据和预算下可判断门槛 | 未见分布泛化、多种子稳定性 |
| 部分输出／审核未知 | 已保存哪些计算和证据缺口 | 科学成功或有效算法负结果 |

## 2. 可变几何与强初解：先明确优化本身能做什么

### 2.1 联合改变数量和宽度，并不自动降低峰值

R1从三档宽度初解出发，对比规则顺序、随机顺序、只变束数、只变宽度，以及固定0.5°优化后再缩宽。研究意图是分离“联合几何变量带来更多取舍”和“同等资源内负载真正改善”。20个Jan12母场景各含四种历史合成请求分布，形成80案例；同母四分布并非独立位置样本。

规则搜索在79/80案例扩展了初解的非支配结果，说明联合几何具有新的可行取舍。然而，在共同N/Ω切片内，规则与初解的61个共同可比案例峰值全部持平。固定宽度JOINT再缩宽仍是强对照。更重要的是，80案例中18例的INIT／RULE／RANDOM实际初始档案不一致，限时初始化下的起点不公平使排序因果解释受限。因此，R1保留开发描述和诊断教师，不以候选变化或Pareto扩展宣布学习排序成功。[报告12](12_可变束数与束宽联合搜索首轮开发对照.md)。

### 2.2 在相同强起点上，简单重分已覆盖排序机会

R2直接冻结已经审核的强布局，使D0和D1真正使用同一输入、父布局及八个任务描述。D0保留较大邻域，D1只调整最多64架活动飞机，降低有限池完整计算的难度。完整20母80案例中，D1全部任务池闭合，36例达到峰值至少降低1%、上尾和CV不恶化，覆盖16母；D0为30例、13母。先导6母24案例只是完整集的一部分，不在综合统计中重复计为新样本。

这一结果确认了局部归属重分的价值，却没有给原八任务排序模型提供足够理由。固定执行最重区域的归属重分就覆盖了D1全部36个目标成功案例，其达到目标的射线对成本相对有限池事后最好顺序，逐案例超额中位为0%。因此，学习排序不应仅与随机顺序比较，也必须与足以覆盖成功集合的固定任务比较。原10000更新分支未启动，非学习重构成果保留。[先导报告13](13_共同强初解与峰值对齐重构先导对照.md)、[完整报告14](14_共同强初解与可变束宽重构完整开发对照.md)。

这两轮改变了研究重点：可变N和逐束宽度应真实进入方法，但变量更多不保证强约束下更优；学习也需要一个简单规则尚未解决的决策。因而下一步不再继续调整同一八任务排序，而转向从原始飞机输入构造布局。

## 3. 直接学习构造：标签、修复与模型输出之间的差距

### 3.1 从整数补全到锚点域修复

R3将原始飞机转换成公共多宽度候选，拟由学习筛选并以整数求解补全。24案例的公共准备完成，但六法144槽仅12槽发布、3槽在ORACLE选择接口处出错、129槽未执行。已有三个正请求案例的参考结果不满足合格标签或同质量要求，足以触发原先冻结的停止规则。这里同时存在接口错误和有限教师证据不足，不能写成全144槽已比较，更不能据此否定整数优化方法家族。[报告15](15_多宽度候选构造与整数补全先导对照.md)。

R4把学习输出改为波束启用、飞机锚点和离散分组，由共同几何过程决定合法指向及宽度。精确教师输入在24/24案例恢复到教师质量，说明该接口能够表达已有解；但扰动输入只有3/24达到同质量，低于18/24要求，相对规则／随机最好终态的质量成功4/24，也低于6/24。精确标签可解码与实际模型误差可修复是两个问题，前者不能替代后者。[报告16](16_离散分组与共同几何修复先导对照.md)。

R5进一步保持飞机锚点域，并使用有限成员撤回、插入和补全代替容易损伤分组的处理。168次新解码及同输入配对显示，OWNER10和JOINT10的教师质量恢复分别从旧方法2/24、3/24提高到12/24、14/24；48组配对新增达标21组、损失0组。不过，两类仍未达到各18/24的绝对准入门槛。该改进应归于共同几何修复器D5，不归于尚未训练的模型；原学习后继关闭。[报告17](17_锚点域成员修复与同输入对照.md)。

### 3.2 历史异质教师与统一请求版本必须分开

R6开展一次固定D5下的真实监督学习试点准备，以检验人工扰动未能直接回答的模型问题。实际完成192母×四种异质请求的768份教师标签，原标签门槛通过，但尚未进行科学模型更新。随后用户要求所有飞机采用相同固定请求，并保证三阶段一致性，旧标签的训练后继因此关闭。它们仍是有效历史资产，不能通过替换需求字段变成统一请求训练成绩。[报告18](18_异质请求教师标签与统一请求改制归档.md)。

R7据此重新建立576训练母与20开发母，共596母、621421条飞机—时刻记录。每机21.6 Mbps由原T0数据量级审计选定，恢复全部飞机后保持原ID、位置与请求总量。576个训练母中574个得到合格、非平凡教师，两个基础设施中断案例保留缺失，不换母重试。教师是原T的合法终点；D5 EXACT的再优化终态仅用于验证解码，不替代监督目标。

在共同正常的574母上，Wenv、原T、D5 EXACT的平均峰值分别为2196.9909、1040.5254和791.3352 Mbps。实际束数均值也分别为80.5749、88.3397和94.5749，因此这些数值反映数量、分组、宽度共同作用，不能称作固定束数收益。564母同时变N并使用不同且不全取下界的宽度，是教师变量能力证据。[报告19](19_统一请求教师标签与三阶段接口核验.md)。

### 3.4 R8的合法骨架解决了发布问题，没有证明模型信息更好

R8不再让模型直接给出完整可行分组，而从共同合法Wenv出发，只接受经过覆盖与资源检查的整机转移。固定模型的缓存owner亲和分数仅用于相同主要负载收益候选的次要排序；几何G和哈希R使用相同候选、接受条件及预算。局部处理后，各法都经过同一个D5。该轮新模型前向与更新均为0，历史模型训练和缓存获取成本也不能因此写成零。

## 7. 已证成果、论文表述与仍需证明的内容

### 7.1 可以作为本阶段研究基础的成果

本研究已将可变N、逐束真实宽度、完整覆盖与唯一整机归属纳入同一可追溯布局表示，并将请求负载与实际通信服务分开。统一21.6 Mbps请求数据及真实布局发布，使后续跨阶段接口不再依赖静默固定百束或固定宽度的假设。这部分适合写入问题建模、数据处理和实验平台章节；其贡献范围是本项目已经实现并核验的机制，未进行新的文献覆盖检索，不主张国际首创。

在算法方面，强初解上的归属重分、锚点域成员修复以及顺序结构重构提供了多组可复核的质量证据。R2、R5和R10分别支持它们在各自开发条件下的作用。不同请求、场景和资源条件不合并成单一改善率，数学方法的收益也不归给AI。R10的S2／SH-C及其逐景较好结果可保留为十二母域的已核强参照；R7 RULE继续作为20开发母域的重要参照，二者没有跨域冠军关系。

在学习研究方面，R7真实训练与R8固定分数使用给出了明确的模型行为证据；训练损失、非回退、实际变量变化和强基线质量被分别记录。R9—R13进一步通过强固定规则、有限oracle、全景／顺序比较、两步池及前缀包络，避免把“优化有空间”直接等同于“必须使用学习”。这些结果可写为方法选择依据和负结果分析，不能包装成学习优势。

### 7.2 不应写成已经完成的贡献

目前没有证据支持“第一阶段AI优于最强规则”“学习已经实现真实加速”“已获得全局最优”“具备多种子稳定性”“能适应真正动态航空业务”“三阶段联合服务目标已完成”。几何全覆盖不等于通信服务满足，教师合法不等于模型输出合法，异宽布局不等于模型学会调宽，代码和工程通过也不等于科学门槛通过。

R11的审核未知不是算法失败；R14的合法B完成不是停止树训练完成。研究中保留的故障、未闭合历史来源和费用未知应在论文实验设置或局限中说明，而不以额外试跑填补本次暂停期间的证据。原开题里关于鲁棒、部署与最优性的表述，如进入当前论文正文，应改为目标或待验证假设。

### 7.3 尚需证明事项及当前边界

若未来另获明确继续授权，尚需回答的核心问题是：实际可部署模型在与强因果规则相同输入、信息和核验范围下，能否严格保质并降低真实请求时间；该收益是否覆盖模型、初始化、审核及必要IO，而非只减少核次数；历史反复开发之外的未见场景及更多训练随机性是否支持外推。对于完整系统，还需证明后两阶段实际消费同一布局与请求，并在其自身条件下完成资源分配和评价。

这些是证据缺口的列示，不是新增实验计划、预算或自动恢复授权。R7、R9、R10、R12、R13已关闭的科学分支不因写入综合报告而重新开放。
