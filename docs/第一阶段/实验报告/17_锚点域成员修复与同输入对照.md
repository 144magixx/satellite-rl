**全程保持飞机锚点并进行成员撤回与补全，明显提高了同输入对照中的教师质量恢复率，但尚未达到预注册的绝对准入要求。** OWNER10与JOINT10分别由旧解码器的2/24、3/24提高到12/24、14/24；48组配对新增达标21组、失去达标0组。两类诊断仍低于各18/24的门槛，因此本轮不进入768例教师生成或2000/6000更新训练。该结果支持继续研究共同几何修复和实际模型输出之间的关系，不能记为AI贡献，也不修改上一轮的失败结论。

## 研究问题与共同条件

本研究面向多波束覆盖中的离散分组与连续宽度耦合：选择哪些飞机位置作为波束锚点、每架飞机归属哪束，再以实际成员包络确定各束宽度。上一轮共同解码能够保持精确教师标签，却可能在资源合并与最终中心回投时损伤带误差的分组。本轮依[方案21第二版](../方案/21_锚点域内归属修复与单模型验证.md)，将中间态与终态限定在同一飞机锚点域，并用有限成员撤回代替整束合并，检验是否改善有错提议的恢复质量。

本轮仅使用原Jan12开发集中的6个母场景，每母含原始、单热点、双热点、边缘集中四种请求分布，共24案例；不是全80开发，也不是独立test。四个请求分布共享母场景几何，且这些案例已反复用于方法改进，故本文保留母级与分布分层，不将24例视为24个独立样本作显著性推断。随机及扰动哈希固定seed51001，无跨种子稳定性证据。

原R4的24份成功prepare与教师T按原字节、来源和输入身份复用；首三个案例绑定恢复后成功准备，未将原unknown准备冒充已知成本。流式覆盖见证W确定共同束数上限Ncap=min(200,n,ceil(1.25Nw))与角域上限Ωcap，其成员包络收缩结果Wenv为合法回退点。实际角域Ω(w)=2π[1−cos(w/2)]，w以弧度代入，单位sr；每束全宽限制[0.3°,1.0°]，允许多束共用同景飞机锚点。全部飞机（含零请求）保留、唯一整机归属、请求守恒、实际非空N≤200以及同Ncap/Ωcap是共同硬约束。

负载为归属飞机的输入请求之和；峰值为最大束负载，上尾为最重ceil(0.1N)束的平均负载，CV为全部非空束负载的总体标准差除以均值。三项均越低越好。本文显示的Mbps仅将原bit/s除以10⁶，不代表实际承载；不使用业务满足率、PHY、SI、SGM或下游分配结果作为第一阶段目标。

## 锚点域成员修复及诊断输入

新共同解码器D5执行INITIAL、EVICT128、INSERT256、REFIT8、SPLIT64、MOVE56和最终AUDIT。INITIAL先排除几何不可达的归属，再在可达且有效的分数中选择，避免不可达高分遮挡已有可行目的。EVICT仅在Ω超限时依边际角域减少量撤回单架膨胀成员；被撤飞机及其请求进入待补全集合，绝不删除。INSERT按请求、有效分数、增量角域和负载等确定次序尝试重新归属，必要时有界尝试单机束。

首次完整合法布局Q0固定保存；随后重新拟合、分裂和整机转移除原字典序改善外，还要求上尾与CV相对Q0不恶化（使用冻结数值容差）。全过程中心均为飞机锚点，最终AUDIT只重算与核验，不再改变中心。被遮蔽分数不参与补全排序；其目的仅按几何与负载排序。失败则发布经过独立核验的Wenv并保留原因，不能用回退掩盖修复失败。

每次解码保持512候选、8次重新拟合、2048n射线对及5秒名义搜索预算；终端预留已包含在射线额度内。进程硬护栏15秒、父子RSS上限2GiB，失败候选与排序工作照实计费。该有界过程不保证找到所有可行补全，也不是全局最优求解。

| 输入 | 含义与用途 |
| --- | --- |
| RULE | 原规则锚点及距离归属分数，不读取教师标签 |
| RANDOM | 固定单次哈希随机锚点与归属分数，不多次抽样择优 |
| EXACT | 精确教师锚点与归属，经完整D5解码，检验可表达性 |
| OWNER10 | 保留原教师锚点，按原固定选择遮蔽floor(0.1n)架飞机的真实owner分数 |
| JOINT10 | OWNER10上再对floor(0.1K)个固定选中槽，将锚点换为最近的另一架飞机 |

JOINT10是有真实几何偏差的近邻离散锚点扰动，不是全局随机锚点错误。OWNER10及JOINT10是人工构造的诊断输入，其被遮蔽数量不能等同几何筛选后的实际归属错误，更不能等同尚未训练模型的误差分布。原提议、mask、实际锚点与归属及转换记录均保留在逐案例证据。实际每景遮蔽16–168架飞机，占9.7744%–9.9938%；INITIAL后按教师语义束ID核对并计入孤机，OWNER10实际归属错误比例为9.7744%–9.9938%，JOINT10为9.7744%–10.5590%，两类每景初始孤机均为0–3架。JOINT10共198个被改锚点的实际角偏差为0.002839°–1.446622°；最近另一架飞机仍可能很远，不能将其称为固定小角度扰动。

每例新运行D5五法120次，以及旧冻结解码器D4的OWNER10/JOINT10同输入48次，总168次。D4薄适配层外层保留真实诊断方法，内层仅为旧V1接口使用TEACHER_EXACT兼容标签和零offset；实际分数、mask与锚点仍为本轮有错输入。转换前后SHA、生产源和旧prepared来源分别保存，未调用旧proposer，未修改原69e解码数学。这是新同域对照，不能称为原R4 PERT重跑。旧R4 RULE/RANDOM/EXACT的72行仅作历史描述，不进入本轮168次计算或严格速度比较。

## 分支停止与后续研究依据

原P0整体未通过，因此停止本轮既定768例标签、2000/6000更新模型及其全80开发、验证与test后继；不补剩余56开发，不修改18/24门槛，不把未用预算转作重复调试。原新验证80与test160尚未被算法访问。D5对有错输入的同质量恢复有明确改善，可为下一轮提出研究问题，但本轮没有训练模型或验证真实预测。

人工10%遮蔽及近邻锚点变化并不能准确刻画所选模型将产生的错误。EXACT的24/24可表达性与两类8/9例质量机会，可作为另行预注册、有界实际模型试点的研究依据；该试点需要重新区分目标、预算、停止条件和真实模型评价，不能借此追认R5通过。下一轮方案仍属另立目的的设计与准入工作，本文不宣称其已开始训练或已经有效。

本研究继续以全部飞机覆盖、唯一归属、请求守恒、N≤200和逐束可变宽度为约束，最终须用同条件对照证明AI对质量或效率的贡献。当前结论限于重复开发24例、单固定随机种子、有限修复预算和人工扰动；不外推为独立泛化、动态重配置完成或所有AI路线成败。
