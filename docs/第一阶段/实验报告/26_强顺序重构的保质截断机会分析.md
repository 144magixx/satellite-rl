# 强顺序重构的保质截断机会分析

S1-AI17-R13｜2026-10-15｜完整十二景有限负结果。科学分析、独审与根接受已闭合，所选归档另行核验。本轮未通过事前20%额外操作量空间门槛，不进入计时或模型后继。

## 1. 研究动机

波束覆盖规划除了需要形成合法且均衡的布局，还需要控制得到这一布局所付出的计算成本。此前邻域支持的两步重构在12个已见开发母场景上未达到超过强参照、固定序列和单步方法的预设门槛，因此本研究关闭该轮质量选择器分支，并转向一个范围更窄的问题：已有强顺序重构方法是否在较早阶段就获得了与最终结果相当的布局，而后续尝试只增加计算量。

本轮保持强顺序重构SH-C的候选、顺序、内核和目标不变，只考察在其已保存轨迹上提前交付当前布局的可能性。若提前停止的机会能被简单固定规则覆盖，则没有充分理由训练停止模型；只有在严格保质条件下，因场景而异的停止位置仍明显优于预先固定的强规则族，才值得进一步测量实际成本。这里的第一步是判断操作量空间，实际提速和学习有效性仍需另外验证。

前轮[报告25](25_邻域余量与两步波束重构的机制比较.md)的完整负结果及所选双端归档已闭合，本轮不重新执行旧求解、旧审核或旧选择器训练，也不把前轮失败解释为全部AI方法无效。本轮研究问题与门槛见[方案31](../方案/31_强顺序重构的安全截断机会与成本可测性.md)。

## 2. 场景、状态与保质条件

本轮固定使用母场景索引0、6、12、18、24、36、42、48、54、60、72、78，共4715条飞机记录。这12母已经反复用于方法开发，本轮属于已见开发域的机制分析，不是独立测试。分析单位是母场景；同母的多个前缀是相关观测，不能当作相互独立的样本扩大证据量。

所有飞机保持稳定ID、位置和每机21,600,000 bit/s请求；每架飞机唯一归属一个非空波束，逐束请求严格由所属飞机请求求和。实际N≤200，同时遵守原场景Ncap和Ωcap；逐束全宽由真实成员包络决定，范围为0.3°—1.0°。第一阶段只评价覆盖、请求负载和几何资源，不引入PHY、SI、SGM或实际承载目标。后续三阶段仍须承接同一飞机集合、归属、布局和请求，本轮没有执行跨阶段验证。

每母以其自身完整SH-C终点为教师参照，不能换成R12的O2或历史S2/SH-C择优结果。令已完成t次核尝试后的保存状态为X_t，完整轨迹长度为T，且T≤32；X_0为原共同初始布局B。一个前缀只有同时满足以下全部条件，才标记为保质：峰值请求和上尾10%波束平均请求分别不超过教师值加10⁻⁶ bit/s及教师绝对值的10⁻¹²倍；CV不超过教师值加10⁻⁹及教师绝对值的10⁻¹²倍；N不多于教师，Ω不超过教师加10⁻¹² sr；原完整身份、覆盖、唯一归属、宽度及资源约束的资格证据有效。

几何合法与保质是两个条件。一个合法布局仍可能比完整教师更不均衡。最早保质前缀t*需要用未来终点进行事后比较，因此是机会分析标签，不是在线策略可以提前读取的信息。本轮没有在观察结果后放宽到1%质量损失。

## 3. 已存轨迹的前缀重建

本轮仅准入12份历史SH-C及12份对应common规范原件，正式路径、摘要、来源和程序须由执行合同绑定。从保存B开始，按原attempt顺序读取：只有已保存的admissible结果更新当前布局及指标，拒绝或无改善保持前态。每母至多恢复33个前缀，全组至多396条。前缀必须保留输入、attempt、状态沿革与原审核证据引用，不能从不完整摘要反求布局，也不能新算缺失几何或指标。

中间状态的资格依赖既有完整12×5审核证书、实际审核源码的控制流覆盖以及本轮精确24输入的身份绑定。不能仅以生产端admissible标签代替审核，也不重新读取旧804条审核大表。来源或语义关联不闭合时标为unknown，不能把unknown记作通过、失败标签或模型训练目标。

这些前缀是历史完整执行中的保存状态。本轮选择其中某处停止属于反事实分析，没有执行新的截断求解轨迹，没有测得其冷启动、保存和退出时间。

## 4. 对照与前瞻门槛

| 对照 | 固定定义 | 解释 |
| --- | --- | --- |
| 完整SH-C | 原自然池耗尽或最多32次核尝试 | 每母质量与资源教师 |
| 固定次数规则 | 0、4、8、16、32次尝试上限 | 是否简单固定工作量已经足够 |
| 连续未接受规则 | 2、4、8次已完成核尝试连续未接受即停 | 是否近期没有改善即可判断停止 |
| 强规则包络 | 每母在上述八条规则中事后选择最早且保质者 | 偏强、不可直接部署的机会参照 |
| 最早保质前缀 | 在全部合格保存前缀中选择最早者 | 事后可达机会，不是已训练模型 |

所有规则保留自然耗尽停止。连续窗口只统计真实完成的核尝试；接受后清零，结构性跳过不算失败核。接受后可以在下一轮池构建前停止；失败后停止不能把已经构建的池追溯记成省下的费用。八规则固定，不作事后阈值搜索。

以e_i和t_i*分别表示母场景i的强规则包络与最早保质前缀尝试数，操作量相对减少率为(Σe_i−Σt_i*)/Σe_i。分母为0时该门不通过。它仅以核尝试次数衡量，不能写成秒数节省率或加速比。

但是，预先固定规则族构成的逐母事后包络，已经把总尝试数从384降至211，覆盖了大部分可见机会。最早保质前缀还能从211降到176，即额外少35次核尝试，占包络的16.5877%，未达原定20%。即使有5母比包络至少少4次，AND门槛仍未通过。这个包络本身使用逐母事后选规则，不能将其211次写成一条已锁定在线规则的实际成绩。

## 6. 成本信息与结论边界

旧轨迹没有逐核、逐池墙钟起止，以及前缀独立冷启动、必要保存和退出时间。整体历史算法计时不能均匀分配给各次核，操作账也不能自动覆盖池构造和全向量操作。本轮读取耗时是分析成本，不是SH-C在线运行时间。前置B获得与验证的成本若不可恢复，应列为缺失，不能用零代替。

完整审核结果表明，在这12个已见开发母场景和固定SH-C轨迹内，提前停止确有保质空间，但相对强规则包络的额外操作量空间未达到事前门槛。根按原门槛接受本轮为限定范围的机制负结果，关闭停止机会分支及其B/C后继，不降低20%或沿用余额训练。

这一结果没有测量实际加速，也不能证明AI无用。它只说明本轮固定轨迹、严格保质标准和强事后参照下的额外机会不足以通过预设研究闸门。母场景存在冗余，与继续训练停止模型缺少本轮门槛依据并不矛盾。

阶段B计时和阶段C浅决策树原为条件性提议，没有分配额度；本轮A未通过，不能自动进入它们。其它后继路线须另作前瞻设计，不把本轮改称通过。当前没有模型，因此不能将数学动作产生的可变束数与逐束宽度写成AI已经学会，也不能声称泛化、全局最优或部署成熟。
