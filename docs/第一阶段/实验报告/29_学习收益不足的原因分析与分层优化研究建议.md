# 学习收益不足的原因分析与分层优化研究建议

2026-10-16｜既有证据分析，无新增实验。用户明确要求“先分析，不恢复实验”，并要求设计非学习与学习结合的分层优化路线。本文及[方案33](../方案/33_非学习骨架与学习调度的分层优化实验设计.md)只形成分析和候选设计，不解除2026-10-15晚的暂停，不恢复旧关闭预算，不准备新实验源码，不运行求解、教师计算、训练、科学重评或远端调度。

## 1. 结论及其证据范围

目前值得优先检验的工作假说是：**强几何规则已利用许多容易识别的机会，而已训练模型的预测任务与最终优化目标不完全一致；把原模型改作局部引导时，又只给了它很小的决策空间。** 后两项是可从源码和方案核实的结构事实，但它们各自造成多少退步、是否为主要原因，尚无因果消融确认。这些是解释线索，不能当作已经找到唯一根因。现有证据不足以把失败归结为“问题天生不适合学习”，也不足以断言换一个更大模型或延长训练就会成功。

在当前统一请求主线中，确有一次2000更新的集合模型训练，以及一次使用同一模型旧分数的局部引导对照；十四轮研究不能理解为十四个充分训练的模型全部失败。许多轮次是在训练之前检查候选空间、教师、修复能力或计算机会，另有工程审核不完整和用户暂停的分支。[完整历史](27_第一阶段自主研究综合报告.md)保留这些区别。

“学习一直没有超过规则”也需要限定为当前主线。历史[报告07](07_区域重构PPO修复版共同考核.md)中，修复版关系PPO的主体CV为0.602222，同批搜索为0.663655；[报告09](09_R04引导的DRL覆盖A阶段对照.md)中，BC的总体CV为0.47579，规则H1为0.49433，但3.75%的改善仍未过当时5%质量门。旧请求、固定宽度、覆盖资格和指标分母限制均保留，这些正例既不能移植为当前成绩，也不能在解释学习作用时抹去。

最直接的当前学习增量证据来自R8：同20个开发母场景、同合法初解、同候选池、同主要负载键、同接受规则、同搜索上限和同D5。模型排序的峰值均值1069.2 Mbps，几何排序1063.8 Mbps；逐景4胜、10平、6负。模型对固定哈希排序有改善，但相对几何规则没有均值优势。原质量门仅2/20，未达到5/20。这支持“当前模型信息尚不能增加强规则的效果”，不支持“全部学习算法无效”。[报告21](21_保覆盖局部引导完整开发对照与停止.md)

## 2. 为什么问题结构对规则方法有利

现行第一阶段输入包括已知飞机位置、完整飞机集合和固定单机请求，不需要预测未知业务量。设每机请求为q＝21.6 Mbps，第j束拥有n_j架飞机，则该束请求恰为q·n_j；峰值请求等于q乘以最大束人数。因此，识别过重波束、相邻可接收波束和几何可行转移，可以直接从当前状态计算。热点由密度形成，不能人为制造异质请求来增加模型的表面用途。

这意味着学习没有“知道了规则不知道的请求量”这一信息优势。若一个决策的正确收益能用廉价整数计算直接得出，训练模型近似它往往没有必要。学习更可能有价值的位置，是**在大量可行的局部重构中，提前预测哪一处值得花较昂贵的求解时间**，而不是重新学习覆盖检查或逐束人数求和。

但已知输入和确定性约束不等于问题容易，也不等于不适合学习。联合决定归属、中心、逐束宽度和实际N仍有组合选择。是否值得学习，取决于强规则之后还有多少可预测的剩余机会，以及预测成本是否小于节省的搜索成本。这里是由当前问题定义得到的方法判断，不是已测得的加速结论。

已有有限机会分析提醒我们，不能把“有更好布局”直接当作“需要AI选择”：R9有限候选池虽改善原点7/12，但没有增加强规则前8的成功场景；R10固定Gr已覆盖全景方法的成功，最好的全景法仅1/12超过强顺序参照；R12两步候选池的四项门槛全部未达。这些结果针对各自固定池、起点和12个已见母场景，不构成所有可能布局的全局上界。[报告22](22_强布局保护下的重构候选机制试验.md)、[报告23](23_全景容量协调与顺序重构的机制比较.md)、[报告25](25_邻域余量与两步波束重构的机制比较.md)

## 4. 实验设计中需要改进的地方

**首先，已有证据强弱不应混在一起。** R7/R8是实际模型对照；R9/R10/R12是训练前的有限空间检验；R11因审核不完整无法判整轮效果；R14只有140景数据与初始布局完成，教师与拟合均为0。机制试验有用，但没有训练的轮次不能算作某种学习算法的负结果。

**其次，质量与成本要采用两种互补比较。** R8同搜索上限的设计能够回答模型排序有无增量，值得保留；但它用了旧缓存分数，训练、前向和部分完整费用存在历史差异或缺口，不能同时证明冷端到端速度优势。未来既要比较相同候选和求解工作上限，也要从原始输入开始，在共同真实时间上限内比较最终布局；模型加载、特征、推理、初解、后端、审核与必要IO都要计入。离线标签和训练单列，不把它们当作在线免费资源。

**再次，规则对照必须强，而且能实际部署。** 随机排序可以检验模型是否含信息，却不足以证明实用优势。要与使用同样因果特征的负载—几何规则、训练期锁定的规则调度器及同场景强顺序方法比较。逐母事后挑最优规则属于机会参照，不能叫已部署规则。R13的211次强规则包络正是后者；最早保质176次相对它额外减少16.5877%，不是已实现的在线提速，也不能直接判断R14拟选规则的模型是否有效。[报告26](26_强顺序重构的保质截断机会分析.md)

**最后，当前数据只能支撑开发判断。** 同一母场景的多飞机、多候选和多前缀不是独立样本；反复使用的12或20母不能继续称独立考核。现有140母即使重新拆分，也不消除历史暴露。未来应按母场景及日期/连续轨迹块隔离，模型与规则均只在开发范围选定，独立确认需要另行登记来源未暴露的输入；Jan15不能因为新文档而自动开放。单seed51001的结果也不能证明跨训练种子稳定性。

同样需要保持资源解释：同景Ncap和Ωcap相同是基本条件，实际N和几何占用仍须一起报告。多用波束取得较低峰值是资源取舍，不自动等于相同资源下的均衡优势。不能把20母1069.2与另一批12母230.4 Mbps相除，得出学习落后4.64倍。[分组对比与更正](28_第一阶段算法指标分组对比.md)

## 5. 建议的分层优化路线

建议保留规则擅长的合法构造、几何计算和精确接受，把学习放在有可能节省昂贵搜索的位置。流程是：**共同合法初解 → 公共规则生成有限邻域与求解选项 → 小模型选择下一项 → 同一非学习后端实际重构 → 按真实指标接受或保留原解**。学习可以决定检查哪个区域、尝试哪种局部结构和投入哪个有限计算档位；它不负责猜测几何是否合法，不允许删飞机或篡改请求。

这一路线让学习改变有限预算实际花到哪里，不要求模型直接输出整套复杂布局。监督目标应来自同一个后端对候选的真实增益与成本，包含无改善和失败；在线输入只能是决策之前可得的状态及本次已付费执行的历史，不能读取尚未执行候选或未来步骤的真实求解结果。标签昂贵但在线节省可能存在，是否合算需实测。

研究设计按三个问题递进，而不以训练次数作为进度目标：

1. **有没有值得学习的选择空间？** 在预定开发子集上比较有限候选的事后机会与强因果规则；如果一个固定动作或简单规则已覆盖机会，停止该候选接口，不能靠扩大网络挽救。
2. **有空间时，当前信息能否预测它？** 用针对后端收益的小模型及去关系特征消融比较；分别查看训练拟合、跨母开发误差和真正下游增益，区分目标/表示/拟合与泛化问题。一次固定候选机会不能当作多步全局上界。
3. **预测能否转化为净收益？** 把推理费用和所有在线处理计入，在共同时间上限下与强规则正面对比；只减少核调用但不改善端到端耗时，不能称为加速成果。

完整对照组、模型、因果特征、有限预算、数据角色、资源护栏和预注册判据见[方案33](../方案/33_非学习骨架与学习调度的分层优化实验设计.md)。本分析不选择事后最有利指标作为成功标准，不假定新方案必胜，也不重新打开原R7、R9、R12、R13或R14。
