# 全景容量协调与顺序重构的机制比较

S1-AI17-R10｜2026-10-14｜完整报告，科学结论与三图已根验收。原12母×5法已全部完成保存数组审核，独立派生统计复核一致。全景组合达到固定q目标9/12母，但超过较好顺序法仅1/12，未达第二项3母门槛；[根科学接受](../../../outputs/experiments/first_stage_ai_search_20261013/round10/science_actual_acceptance_02/root_R10_scientific_gate_acceptance.json)将本分支定为有效负结果，不再追加R10计算或成本族选择器学习。新模型初始化、前向与更新均为0。

**全景协调能降低峰值，但本轮多数情况下没有超过强顺序重构。** 少改归属规则Gr覆盖全景组合的全部9个目标成功和唯一1个超顺序成功；Gd、Gw各只有2个目标成功、0个超顺序成功。这个结果既不支持训练一个成本族选择器，也不说明全景优化普遍无效。需要保留强数学参照，区分目标函数、固定中心和多步重构的作用，再决定后续研究。

## 研究问题与方法依据

[报告22](22_强布局保护下的重构候选机制试验.md)发现，原R9有限候选池虽在7/12母改善强原点，却未提供超过强规则前8的峰值收益；固定最重束2→2也覆盖同样7个成功母。因此R9后继标签与模型训练已关闭，不改门槛、不转移余额。

原归属还表明，5个未命中母的每个局部候选都遗漏至少一个并列峰值束；区域外不变时，这些候选不可能降低全景峰值。本轮按[方案27](../方案/27_多峰负载下的全景容量协调机制草案.md)及[数学合同47cb](../../../outputs/experiments/first_stage_ai_search_20261013/design/round10_design_v2.json)，比较能够同时改变全景归属的容量匹配与更充分的顺序局部重构，检验联合作用范围是否具有额外价值。

这是一轮纯数学机制研究，没有模型初始化、前向或参数更新。未来AI若要介入，须有实际边代价敏感性或计算瓶颈证据，再另立学习方案；数学方法得到好解不能直接称为AI收益。

## 共同输入、真实变量与五个方法

共同原点B来自原12个训练母已经审核的R9全池最好实际终点，按原字节与差量恢复，不重新生成。它们是已见训练诊断，不是独立验证或test。原索引为0、6、12、18、24、36、42、48、54、60、72、78；共4715架飞机记录、594873字节恢复输入，当前B实际N为61–104，各母原Ncap为65–107。来源见[12母静态资格](../../../outputs/experiments/first_stage_ai_search_20261013/round10/input_preparation_01/root_exact12_static_origin_qualification.json)。

全部飞机及稳定ID、位置、每机21,600,000 bit/s请求保持；每机唯一归属，逐束需求等于实际成员请求之和。N≤200和各母更严格的原Ncap、Ωcap同时适用。发布宽度必须由实际成员包络产生并处于[0.3°,1.0°]，不能用名义菜单或数组容量代替真实N／宽度。本阶段不以PHY、SI、SGM或业务满足为目标。

目标人数q固定为B中最大束人数减1。全景方法比较固定N₀及事前两个增束菜单，新增中心只来自峰值束实际成员的确定前缀，所有原飞机仍进入匹配；整数流对每束设置下界1，不强制锚点飞机归自身束。匹配后重新检查真实宽度、整景Ω、身份与三项负载保护，可覆盖流可行不等于最终几何／资源可行。

| 方法 | 决策方式 | 束数与每母算法上限 |
| --- | --- | --- |
| Gd | 最小化固定量化距离费用的全景分配 | 最多3个不同N结构、每结构一次固定q匹配 |
| Gr | 先最小化相对B改归属人数，再最小化距离费用 | 同上 |
| Gw | 最小化量化扩宽代理，再以距离解平局 | 同上；代理不等于真实Ω |
| S2 | 全部当前源束上的最重束／最近邻2→2顺序重构 | 固定N，最多32次不同可用内核尝试 |
| SH-C | 结合全景峰值、q超载、整数平方和与Ω下界的顺序结构重构 | 可变N，最多32次不同可用内核尝试 |

顺序法同状态不重复求解同一语义描述，已知不可用、seen和重复筛选分别计费。母36的固定61束无法容纳185架飞机且每束至多3架，但S2仍运行，因为它可能改善上尾和CV；只有把q作为硬约束的全景特定N结构可由该计数下界直接判不可行。人数必要条件成立也不能据此认定覆盖或Ω可行。

这三母没有中心不足或全宽越界的证据。保存记录没有独立mincut证书，reader没有重跑求解器，故“图不可行”保留为已审源码产生的有限图报告，不扩展为其他中心、N或全局规划都不可行。完整结构分类见[108槽原分类](../../../outputs/experiments/first_stage_ai_search_20261013/round10/science_independent_statistics_01/global_slots.csv)。

强顺序方法的优势也不能仅归结为多用波束。同N下已有反例：母48的Gr与SH-C都为79束，最大人数分别10与8；母60的Gr与S2都为85束，分别15与12；母78的Gr与S2都为104束，分别44与33。但方法同时存在两项差异：Gr只把q=M−1作为可行容量，首目标是少改归属，并不直接最小化峰值或负载分布；S2／SH-C可以在32次机会中继续调整区域锚点和成员。因此，本批结果支持检查目标与多步结构的差别，不能从这些配对直接断言q、中心或任一因素是唯一原因。

全景108槽实际包括27个重复结构引用、3个计数不可行、15个报告图不可行、3个Ω拒绝、41个质量保护拒绝和19个可接受结构；真实全景流为78次，不是108次。顺序法实际768次局部内核包括159次提交、470次Ω拒绝、107次相同／较差目标、30次双重质量保护拒绝和2次未取得原匹配；不是768个独立场景。局部方法也受到强资源约束，不能把32次机会用完解释为取得局部或全局最优。
