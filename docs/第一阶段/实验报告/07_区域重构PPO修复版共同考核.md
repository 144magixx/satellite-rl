# 07 区域重构PPO修复版共同考核

实验编号：S1-03-R1；报告日期：2026-10-05；依据方案09，固定种子51001。主结果为策略原终态，best仅作同景诊断。

## 1 结论与尚未达到的目标

修复版PPO在本轮独立100景中改善了负载均衡，且平均表现优于同重构器搜索。P1主体CV均值为0.602222，初始布局R0为0.855564，搜索R3为0.663655；带内束均值分别为23.68、18.03和20.54。P1相对R0的Q提高97景、持平3景，没有Q下降；相对R3，Q提高70景、下降30景，主体CV降低71景、上升29景。因此不能称PPO逐景优于搜索。

**原定目标仍未达到。** 五方法均有93/100景双100%覆盖，另外7景双覆盖均达到99.9%但未达到严格100%；近全覆盖与严格全覆盖分开统计。主体CV≤0.20、全100束中至少90束落在主体均值±20%及最多10个几何认证例外的完整目标，各方法均为0/100。P1的平均主体CV和带内束数离目标仍很远，不能把“相对改善”写成“绝大多数波束已经均衡”。

本轮没有降低科学门槛、删除失败景或追加训练/考核。旧S1-03缓存缺陷运行保留在报告06；其65k接受率不能被解释为纯PPO学习失败，也不能用旧有缺陷成绩直接衡量本次学习增益。

各方法共用100束、0.5°全宽、同一初始化及重构几何层；取消旧聚类中心0.25°绑定。动作包括合并拆分、2/3束区域重划、用户归属重分配与STOP，失败原子回退并计费，允许覆盖合格但负载暂时变差。每景最多32宏动作，每动作256/每景8192几何调用，初始化独立8192；4模板、邻居3、拆分目标12、R3宽度8。P1为两层128关系网络，32环境×32步采样，小批量256、4epoch，奖励为有界覆盖等级Q差、gamma=1且无计算成本项。Q不是容量、SI或SGM。

R0仅采用共同初始布局；R1、R2和R3分别使用规则、随机和预算匹配搜索选择同一重构器的动作；P1以PPO选择动作。动作候选/几何调用上限相同不等于实际调用次数相同；R3搜索存在额外候选尝试成本，不能只按接受动作次数比较计算量。

## 8 解释边界与下一轮讨论

本轮支持“修复后区域重构PPO在固定预算下学到了有用选择，相对共同初始化和同重构器搜索有平均改善”，不支持“覆盖和主体均衡问题已解决”。只有一个训练种子51001、一个独立日期的100景，不作跨种子稳定性或普适最优结论；相邻时间场景可能相关。第一阶段没有计算容量C、有效承载min(C,D)、C/D、SI、SGM，这些指标均不适用。

后续值得讨论的重点是：为何全体达99.9%而7景仍未严格全覆盖，以及为何主体CV与90束带内目标存在大差距。应区分候选重构能力、几何可达性与Q目标对带内束的驱动力，再提出新冻结方案；本报告不以继续堆训练步数、挑best或删边缘束作为已验证解决办法，也不自动新增科学组。
