# 第一阶段算法指标分组对比

2026年10月16日｜只读汇总已有成绩，研究继续暂停。报告27及其PDF保持原样；本文不进行科学重评。

## 直接结论

1. 当前统一21.6 Mbps主线，按已核负载质量选择一个单方法，优先保留 **SH-C强顺序结构重构**。它在同12母五个单方法中，峰值、上尾和CV均值最低；并非每个场景都赢，也未证明最省束或最快。
2. 同20个统一请求开发母中，**RULE+D5**是该批最强负载参照。它和上述12母不是同一对比题，892.08与230.4 Mbps不能直接跨批排名。
3. 当前已测学习辅助路线中，**R8固定GNN分数＋合法局部调整＋D5**比R7直接学习提议更可用，但未超过同条件几何排序G；也没有证明超过原RULE+D5。不能把它称为已胜强规则的最终AI方案。
4. 历史固定宽度对照中，**BC行为克隆**在报告09同批学习方法中优于两种PPO；报告07修复版关系PPO也曾在同批平均胜过搜索。它们不满足现行全部数据/宽度条件，不能与R8跨批定总冠军。
5. 双跑S2/SH-C后逐母择优的S组合记录更好（峰值228.6 Mbps），但要支付两臂计算，不能把该值作为SH-C单方法成绩。R11不完整、R14未训练，均无可用于排名的完整新算法成绩。

## 口径

峰值和上尾均为请求量Mbps，越低越好；上尾为最重ceil(0.1N)束的平均请求。CV为指定束集合负载标准差/均值，越低越好。N表示实际非空束数，反映资源使用，不是单独的优劣排序。所有当前比较保完整飞机、唯一归属及同景Ncap/Ωcap，但实际N仍可能不同。合法发布不等于模型新提议成功，保底回退必须另看。NA表示未发表、未执行、不适用或精确口径未闭合，不是0。

当前统一请求组与历史异质请求组分开。历史主体CV和全体CV分开；历史SI/SGM仅保留原报告口径，不作为当前第一阶段目标。所有下表是既有已发表统计的整理，未重新打开科学数组求新均值。
