# 多宽度候选构造与整数补全先导对照

S1-AI17-R3｜2026-10-13｜24案例准备完成；六法评价部分执行后科学停止；没有模型训练或新验证/test算法评价。

**本轮完成了公共多宽度候选的构造与核验，但有限预算的整数求解尚未产生可用的新教师证据，因此停止当前学习分支。** 预定144个方法槽中，12个已发布，3个在ORACLE选择阶段发生接口错误，129个未执行。已有三个正请求案例的REF均不具备合格标签或同质量目标，已足以触发事前G2的两项缺失规则；后续案例无法改变当前合同下的准入结论。停止的是本轮分支，第一阶段研究继续，不能据此称全部24例质量评价完成或所有整数优化方法无效。

## 从原始飞机输入构造布局

本研究要在全部飞机几何覆盖、唯一整机归属和请求守恒的条件下，同时调整实际非空波束数量与逐束宽度。前轮共同强初解上的局部重构已经显示一定负载改善，但未证明继续训练八任务排序模型的必要性。本轮将问题前移：从原始位置与请求生成公共候选束，判断有限候选域是否能得到可靠布局，以及是否存在值得学习的筛选空间。

依照[方案19](../方案/19_学习辅助可变束数与束宽构造方案.md)，先取Jan12预定6母、每母四种请求分布，共24开发案例；完整开发集原为20母80例。四种分布共享同母飞机位置、ID和总请求，不能视为24个独立母样本。Jan12已反复用于方法开发，不是独立test。新验证与test保持隔离。

每景先用流式0.5°全宽构造覆盖见证W，失败时才从输入重新尝试1.0°。令W的非空束数为Nw，所有方法共用Ncap=min(200,n,ceil(1.25Nw))及由原W确定的菜单角域上限Ωcap。随后从见证中心、组均值、高请求飞机和最远点生成最多512个中心，每中心配置0.3°、0.5°、1.0°菜单，各两个副本。相同中心可以同时启用多个副本或不同宽度，最终启用束必须非空。

该字典是有限候选域，不覆盖全部连续中心、宽度和同点重叠方案。Ω为几何角域之和，单位sr，不是通信容量。本轮Ncap、Ωcap与R2的资源切片不同，不用跨轮峰值高低声称同资源算法胜出。第一阶段只评价输入请求负载的峰值、最重10%束平均请求、全束CV、几何约束和计算成本，不以实际承载、业务满足、PHY、SI或SGM作目标。

## 六法的共同条件与不同用途

| 方法 | 候选与求解方式 | 用途 |
| --- | --- | --- |
| WITNESS | W加共同后处理，不调用MILP | 输入端几何起点 |
| RULE | 保留见证域，按请求覆盖/菜单角域规则选同M个非见证副本 | 非学习筛选对照 |
| RANDOM | 同见证域、同M，seed51001固定随机筛选 | 单次随机对照 |
| FULL | 使用完整公共候选字典 | 不筛选对照 |
| REF20 | 完整字典、较长预算两阶段求解 | 强参考与潜在教师 |
| ORACLE_RESTRICT | 用合格REF标签确定子域，再同预算补全 | 离线学习机会诊断 |

除WITNESS外，统一使用highspy1.15.1原生HiGHS及完整W整数起点；常规主目标为最小峰值，名义2秒、2000节点、相对间隙0.001。REF20先用12秒优化峰值，再在有效主解峰值约束下用8秒优化L1均衡代理；第二阶段的目标和界均不是精确CV、上尾或峰值证书。REF20预算较长，不能与2秒方法直接组成同预算排名。

所有合法结果或外置W回退均使用相同的有界整机转移微调与固定中心包络收缩，再核验全部飞机。菜单宽度和实际包络宽度分别保存。常规方法一次MILP，REF最多两次；完整矩阵上限144次MILP。ORACLE必须先有合格REF标签，缺标签时应返回typed不可用且不调用求解器；它读取真值，不能称在线AI，也不是所有候选子域的全局最优上界。

## 原生求解证据与完整成本

14次原生调用中，12次保存了规范原始向量，独立检查表明这些向量及完整起点在模型中可行、物理布局均与W相同；另2次没有规范原始解，分别为case32的FULL和REF第二阶段，保留watchdog失败。12次有向量的返回状态均为TimeLimit、节点计数为0；这不能单独区分presolve、根LP或其它耗时瓶颈，也不证明增加有效界或更换模型一定无效。

case16的FULL须单独说明：虽然保存了可行的W向量，但原生日志没有明确的起点/incumbent接受证明，且没有有限界；外层watchdog结束记录为−9。因此只承认可检查的W向量和合法外置W回退，不宣称原生已确认incumbent或完成优化。原生向量存在、起点接受、峰值界证书是不同资格。

三个REF主阶段相对原W峰值的界差距约为97.71%、100%、100%，均远未达到0.1%的冻结间隙要求。第二阶段L1界不能代替峰值证书。三个REF最终均来自外置W，`valid_reference_labels`与`valid_reference_target`全部为False；后处理后的合法布局也不能倒推为合格原生教师。

## 为什么部分结果已足以停止本轮

本轮有两个独立问题。工程上，调用方将`label_unavailable`字典当成可用标签，读取不存在的`active_slot_ids`，三个worker在ORACLE原生调用前退出。科学上，错误发生前已经完成的三个REF结果均没有合格标签或目标。修复接口只会让ORACLE正确返回不可用，不会产生新的教师布局。

冻结合同规定：预定正请求案例中，必要方法缺少合法发布终态使G2质量分支失败，ORACLE缺标签不能被删除；必要REF没有有效原生结果或合格起点证书使效率分支失败，不能用未经证明的W降低目标。三个案例已同时触发两条规则。故G2=False，剩余案例即使表现很好，也不能挽回当前合同下的准入条件。该判断不是把三例平均效果外推到24例，而是事前全分母硬条件的逻辑结果。

根已据此停止R3，G0/G1仍标“未完成全24评价”，没有追补缺失结果。caller最小修复`090e9b4`已在本地集成至`9fe23fb`并通过4项mock检查，未部署、未恢复科学任务；原错误及消耗保留。[根科学停止记录](../../../outputs/experiments/first_stage_ai_search_20261013/round3/analysis/root_scientific_stop.json) · [独立门槛见证审计](../../../outputs/experiments/first_stage_ai_search_20261013/round3/analysis/partial_gate_witness_audit.json)

## 结论、限制与下一轮

本轮确认公共候选/W准备可复现，固定中心的整机微调与包络收缩在已执行三例中改善了请求负载；有限预算整数求解没有提供优于W的新物理布局或合格峰值证书。有限投影暴露的是离散菜单角域限制，不能当作原问题不可行。没有AI训练，因此没有AI收益、学习收敛或泛化结论。

12次合成toy MILP和4次CUDA更新属于先前工程资格，不能记为科学训练成果。已发布的三例全为base，热点与边缘profile没有方法效果结果；没有完整24景排名、独立test或跨种子稳定性证据，也没有完成最终可变N与逐束宽度的学习方法。有限搜索不称全局最优，当前分支停止不表示最终研究完成。

后续已收束为[方案20：离散分组学习与共同几何修复](../方案/20_离散分组学习与共同几何修复先导方案.md)，先实现B0的24教师/96有界解码，避免把逐景冷启动大MIP作为取得标签的必要条件。该阶段仍是无训练先导，教师、缺失、修复、真实成本和准入条件重新事前冻结；不修改R3旧门槛或借新方案掩盖旧失败。最终是否采用学习方法，仍须同资源对照证明其质量或完整成本贡献。
