# 离散分组与共同几何修复先导对照

S1-AI17-R4-B0｜2026-10-13｜24开发案例、24教师与96解码结果全部完成并独立核验；G0通过，G1、G2未通过，停止本轮学习分支。没有AI训练、MILP或新验证/test算法评价。

**共同几何过程能够保留精确教师分组，但本轮扰动后的恢复能力与同质量效率不足，尚不支持据此启动所选集合模型训练。** 精确教师输入24/24例达到教师质量容差；扰动输入虽然10/24例形成合法新布局，只有3/24例达到同质量，低于18/24门槛。其相对规则/随机最佳终态的质量成功为4/24，低于6/24门槛，效率分支也未通过。本结论仅约束本轮冻结的提议、修复器和预算，第一阶段持续探索继续。

## 研究问题与共同资源

本研究希望把学习作用放在波束启用、飞机锚点选择和整机分组上，再由共同几何过程求实际指向与逐束宽度。训练前需要回答两个问题：有界教师能否提供合法参考分组；当分组和指向出现误差后，统一修复过程能否保留参考质量，而非频繁退回起点。[方案20](../方案/20_离散分组学习与共同几何修复先导方案.md)因此先安排离线教师输入诊断，并未把教师标签当作在线模型输出。

评价沿用Jan12的6个开发母场景，每母原始、单热点、双热点和边缘集中四种请求分布，共24案例。四分布共享母场景的飞机、位置与总请求，已被反复用于方法开发，不能称为24个独立样本或独立test。随机方法固定seed51001，不作多次随机择优；本轮无训练种子稳定性证据。

各景从原始输入重新构造流式覆盖见证W，优先0.5°全宽，失败才重新尝试1.0°。以原W冻结共同束数上限Ncap=min(200,n,ceil(1.25Nw))与角域上限Ωcap；Ω(w)=2π[1−cos(w/2)]，w转为弧度，Ω单位sr。另将W按成员最小包络收缩为Wenv，作为教师起点和失败回退点，上限仍取原W。Wenv不是前轮R2强布局的免费接续点，跨轮不同资源口径不组成统一质量排名。

最终非空束数与逐束全宽均可变；实际全宽限制为[0.3°,1.0°]，中心取同景飞机锚点位置，允许多束共用锚点。所有发布点须满足全部飞机几何覆盖、唯一整机归属、请求守恒及同N/Ω上限，零请求飞机也不删除。负载为分配到束的输入请求之和。本文峰值取最大束请求，上尾取最重ceil(0.1N)束的平均请求，CV取全部非空束负载的总体标准差/均值，均越低越好。它们不代表实际承载或业务满足；第一阶段不以PHY、SI、SGM或下游分配作为目标。

## 教师、提议与统一修复

教师T从Wenv出发，依次执行整机转移、分裂、再转移、合并、锚点重新拟合和转移。接受键按峰值、上尾、CV、N、实际Ω字典序比较，最多2048个候选、16次重新拟合，30秒名义护栏。候选几何失败或资源拒绝同样扣账；有限搜索返回最后合法点，不是全局最优。

| 输入或方法 | 实际作用 | 教师信息 |
| --- | --- | --- |
| T（TEACHER） | 从Wenv构造有界参考布局 | 自身有限搜索 |
| RULE | W的锚点与按距离生成的归属分数，经共同解码 | 不读取 |
| RANDOM | 同束数、固定哈希随机锚点与归属分数，经共同解码 | 不读取 |
| TEACHER_EXACT（EXACT） | 教师锚点及精确归属分数，经共同解码 | 离线读取标签 |
| TEACHER_PERTURBED（PERT） | 同教师分组，中心偏移0.01°，屏蔽floor(0.1n)架飞机的真实归属分数，再解码 | 离线读取标签后扰动 |

四种提议均经过同一初始归属、资源合并、孤立机插入、重新拟合、分裂、整机转移和最终锚点回投。每次解码最多512个候选、8次重新拟合、2048n射线对及5秒名义护栏；最终回投只使用已记录锚点，不追加中心搜索。回投后重新核包络和资源，失败才发布已审计Wenv，保留失败原因和成本。EXACT也不能直接复制教师终态跳过解码，因此其最终结果可以继续改善教师。

方案预选的后续学习器为“启用query＋飞机锚点指针＋整机归属”的集合模型，默认方向偏移为零，宽度由包络确定。本轮没有训练、推理或评价该模型，EXACT和PERT的结果均不能记为AI收益。

## 停止当前分支与后续研究依据

按原合同，本轮不进入768教师生成或2000/6000更新训练，不扩新验证/test，也不通过修改接受阈值继续旧分支。当前证据支持优先研究保持合法覆盖的局部提议或更稳健的分组表达，并分别定位资源修复、归属丢失和最终锚点回投的限制；它尚不能证明增加预算就会解决问题。下一轮应重新事前冻结可比较的输入、资源、有限预算与科学门槛，再判断是否存在值得学习的决策空间。

最终研究目标仍是全部飞机覆盖、唯一归属与请求守恒下的可变N≤200及逐束宽度，并用同条件对照证明AI对质量或效率的贡献。本轮只停止已验证不足的具体分支，不推断所有AI、几何修复或优化方法失败。此前各轮结果、失败原因和未用额度保留，不回写为成功。
