# 02 强教师与模仿学习BC：学习逐步布局动作

日期：2026-10-12。状态：独立建议，训练、教师及评价预算**尚未批准执行**。与[专题总览](00_专题总览与共同比较约定.md)共用物理、数据划分和双轨口径；它不依赖[01 MLM](01_MLM掩码布局重构.md)成败。已有[报告09](../../实验报告/09_R04引导的DRL覆盖A阶段对照.md)显示旧BC在其旧动作空间优于两PPO主要质量指标，这只提供研究动机，不能把旧权重宣称为本方案模型。

**一句话做法：**先让限时强搜索在同一操作菜单里走出经过终态核验的改进轨迹，再教一个小网络根据当前布局选择下一步动作，直接比较它与同预算教师和同菜单规则搜索。

## 学习什么

输入是当前场景飞机位置/需求、完整当前布局、各束负载、合法动作菜单及剩余在线时间或动作额度。动作是**在当前布局上执行的一步合法调整**，例如指定区域内的飞机转属、中心候选替换、有限束的拆并；动作的对象由身份/几何特征表示，不能依赖任意数组序号。首轮只启用固定宽度和保持同N的动作子菜单。模型输出候选动作分数和终止分数，执行器决定动作是否通过；它不生成全布局标签，也不遮盖归属，故与[03直接构造](03_监督学习直接构造布局.md)和01有明确区别。

教师从共同强初解出发，只在同一菜单与相同可行域内搜索，保存每步的**执行前状态、候选集、所选动作、执行后全场景结果**。终局布局不能倒推为任意中间状态的正确动作：如果教师改变了早先分组，必须保存真实轨迹，不能把终局分配硬拆成标签。搜索可用更多离线时间，但须分别记录其求解时间、候选试算数、终态质量和失败。学生在线预算与非AI比较方一致，不能将离线教师成本藏在推理时间之外。

## 具体流程与回退

1. 先锁定共同场景、初解、动作菜单、几何核验与目标。教师采用限时大邻域/局部整数优化或多起点搜索，在训练母场景上产生多条可行轨迹；只对通过全场景核验且相对当前状态实际改善的动作记正示范。停止标签区分“已检查菜单无合格改善”与“预算耗尽”；后者不得标成最优停止，只保留为截断轨迹。标签保留教师可能给出的多个近似等价动作。首版只学可逐步执行的单调改善轨迹；需要中途退步的搜索路径不是首版学生的可达示范。
2. 学生用候选图或集合编码器表示飞机、束与动作，建议128维、3层、4头，输出变长候选分数。对示范动作集合A*使用集合交叉熵 `-log(sum(p(a), a∈A*))`，终止作为单独动作；首版不另叠收益回归头。按母场景再按状态抽样，避免长轨迹凭步数主导训练。廉价几何检查只能屏蔽已知非法动作，未试算候选不等于已证合法，输出屏蔽不替代执行后终态核验。
3. 推理时每步重新构造合法菜单并打分；按分数尝试前若干动作，真实核验后只接受按冻结目标改善的完整布局。记录拒绝、回退及停止原因；若模型给不出合格动作，保留当前可行布局。固定动作上限与在线时间，到限即停。
4. 若开发发现学生在自身轨迹上快速偏离教师，可预先留一小段预算做DAgger式纠错：采集**学生实际到达的状态**，请同一个教师在这些状态补动作。该分支需单列采样与教师预算，不能在考核后临时增加；若无明显分布偏移，则不启用。

教师质量首先要可达到。建议开发20母中至少6母存在经核验的>1%相对CV改善，且教师平均不劣于共同强初解、承载退步不过共同限；若不成立，先改教师/动作可达性，不能把失败归结为学生网络。轨迹只从训练母场景产生，划分先于数据增强。旧BC使用的状态、动作、标签和候选域若不一致，旧权重不能直接加载。首轮只训练一个强教师BC；若后续要隔离“教师更强”的收益，再另列同架构、同样本量、同更新数的弱教师BC消融，不能暗含第二模型。

教师所选宏动作必须已经出现在学生推理时可生成的菜单中。局部求解器若负责产生新重建动作，其在线调用也必须属于学生与规则比较方的共同生成器并计费；不能离线把求解出的布局写成一个动作ID，在线却假定该动作免费可得。教师试算后的收益、可行性和最终得分只作标签，不能进入学生的低成本输入。BC也是监督学习，但其标签是当前状态下的下一步决策，区别于03的完整布局标签，也区别于04对每个候选的真实试算排序。

首轮逐机承载统一调用冻结版本的`variable_downstream.evaluate_layout`，固定其中分配器、天线与TDMA口径；这不是完整第二/三阶段算法评价。教师轨迹与各对照不得改用不同下游，若扩展完整链路须另定共同预算。

## 对照与有界建议

同N轨保留共同初解I0、同菜单无学习贪心H、同菜单限时强搜索T、强教师BC以及随机排序R。H/BC/R共享初解、菜单生成器、几何核验、尝试上限及在线时间；同一冻结状态另做同菜单配对，自主轨迹分叉后不声称后续状态和菜单逐项相同。教师T在线版本也受相同时间，离线制标签的长搜索单独列。此矩阵检验BC相对搜索的在线价值，不能单独证明教师增强优于弱教师。若教师用局部整数优化，需增加同一优化器、同区域/候选数的无学习比较，不能把求解器收益记给学生。

**待批准上限：**最多5000条教师轨迹起点（来自训练母场景，不等于5000个独立母场景），每起点最多20步、每步最多32次真实候选试算；各局部上限与总计1,000,000次试算、50,000秒教师墙钟同时约束，先到即停，不要求跑满5000×20×32。每轨迹最多10秒。开发审计及可选纠错也从这两个总账扣除；纠错最多1000个学生状态、每状态最多1秒，不能额外加到总账之外。记录实际母场景、去重状态、动作标签和试算数。首轮1模型、seed51001、最多10000监督更新、batch 32条状态，每1000更新固定验证，使用预算终点权重；若科学停止则报告未达门槛，不以更早偶然高点替代终点。开发20母、新验证20母、新考核100母×三档；方法数随共同矩阵冻结，不自动累计成已批准任务。在线每景最多8步、每步最多4个候选尝试，共同2秒算法时限；实际与其它路线共同校准。

正确性闸门包括教师动作前后场景身份一致、需求守恒、唯一归属、N≤200、几何覆盖，且教师记录的CV变化可从发布布局重算；标签中的动作必须在当时菜单，而不能只在终局菜单。**小例：**两束三机，第三机只能被束A覆盖。教师提议将其转到B时应被拒绝，学生训练标签不能出现该动作；若对第一机转属使A/B负载从(3,1)变(2,2)，标签可检验实际CV下降。失败信号是教师好而学生在冻结验证常选非法/退步动作，或同菜单规则已同等有效而教师/学习额外成本无收益。

正式成功仍按[共同质量或效率门槛](00_专题总览与共同比较约定.md#4-数据预算与推进规则建议尚未冻结执行)预先冻结：同在线预算对H和T（涉及求解器时含其无学习对照）平均CV均降≥5%，或CV均值劣化≤2%时完整总时中位数均减半且P95不增；两支均要求逐机承载下降≤0.5个百分点、发布布局全可行、逐景退步公开。若固定验证到预算终点没有质量或速度收益，科学停止并保留训练与失败曲线。单种子只支持该种子结论。

可变N轨需给动作菜单加入拆束/并束并冻结跨N质量、承载和束数选择准则；变宽动作必须重算天线增益与干扰；动态轨输入上一时刻布局、只使用已知业务并记重配置成本。这些是后续独立预算，首轮BC不能称完整自适应目标完成。

实现可沿用`coverage/variable_design.py`和几何/下游核验，新建轨迹采集、候选编码、BC训练和逐步执行模块，保存每步请求与实际动作。短验证须做可枚举三机例、标签回放等值、真实参数更新、断点恢复、预算超时和整景重算。正式工作台需新增教师类型/限时、动作菜单版本、是否纠错、轨迹与更新预算、模型和结果页面的动作/拒绝日志，并在服务端冻结及校验；本轮文档无需改前端。

方法出处：[Learning to Search via Retrospective Imitation](https://arxiv.org/abs/1804.00846)启发从搜索过程提取示范，[DAgger原论文](https://proceedings.mlr.press/v15/ross11a.html)说明学生访问状态与教师分布可能不同，[Neural Diving](https://arxiv.org/abs/2012.13349)展示学习与整数求解结合的另一种分工。这些工作并不证明本项目教师足够强，也不提供飞机覆盖或天线性能保证；纠错和求解器作用都要单独计费、归因。
