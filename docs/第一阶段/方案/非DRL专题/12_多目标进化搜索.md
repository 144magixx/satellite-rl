# 12 多目标进化搜索

日期：2026-10-12。性质：多目标非学习搜索设计，尚无新运行或效果结论。全覆盖硬约束、两条比较轨道、数据与任务矩阵见[专题总览](00_专题总览与共同比较约定.md)。本路线解决的不是只把一个CV压低，而是保留“更均衡、承载更高、束数更少”的不同可行布局，观察取舍边界，并在独立考核前固定如何从前沿选出**一份**要发布的布局。

## 决策、目标与编码

输入包括同一时刻飞机身份、地理位置、逐机不可拆需求、共同强初解、真实几何规则和冻结的资源/承载评价器。个体编码为实际N、N个中心、首轮共同0.5°全宽及逐机唯一归属；编码顺序用飞机与束身份的确定规范化，避免交换两个束编号产生看似不同的解。个体必须可解码为完整布局。优化目标可取最小全体实际束负载CV、最大模型估计逐机TDMA承载比例、最小实际N；需求带内比例、正需求束CV、资源约束和完整端到端时间另列，不由一个合成分数掩盖。需求带内范围按正需求束均值的0.8–1.2；零需求边界遵守专题总览。

硬约束先于Pareto排序：每景全部飞机几何覆盖、逐机唯一归属、需求守恒、1≤N≤200、中心/宽度在合法载荷域、全场资源约束通过。不可行提案保留原因与成本，但不得因代理分数好进入可发布前沿。承载用冻结下游模型估计，不称实测流量；改动中心、归属或宽度后必须重算全场干扰与承载。若下游计算昂贵，可用便宜代理筛选候选，但任何进入正式前沿的点都要完整核验并计入预算。

## 搜索流程与原子保护

1. 以共同强初解入初始群体。其它合法种子可来自同预算规则的扰动，不能把已有独立考核中的最优布局拿来温启动。扰动包括同束数的跨束移机、两束联合重建、中心在可行域内移动；可变N轨增加拆一束、合并轻载束。每个新解经相同几何修复器，修复失败保留失败记录，并回退至生成它的完整合法父代。
2. 选择两位可行父代，交叉时只复制闭合的地域片区或束组，不直接拼接两份相互冲突的归属。重叠飞机按冻结规则重新归属；缺失飞机必须补回。变异率、动作菜单和修复次数事前确定。任何候选若超过修复限额、全景违规或评估超时，不能部分提交。
3. 对通过全场核验的候选做非支配排序和拥挤距离选择，例如NSGA-II的保优思想。前沿中若某点在CV、承载和N上均不优于另一点，且至少一项严格更差，删除被支配点；完全相同的目标向量按冻结去重规则处理，不能相互支配后全部删除；需给指标数值设一致容差，避免浮点噪声制造假前沿。保留每代、每景的可行点数、重复率、前沿变化及全部函数调用数。
4. 到共同在线预算停止搜索。为最终单解使用**只在验证集拟定并冻结**的选择规则，例如先满足逐机承载不得低于强初解0.5个百分点，再在同束数轨选CV最低点；应用轨在验证时冻结N惩罚或分层阈值，不能在考核前沿上看哪个点漂亮再挑。全部测试场景按这一规则自动选一点，遇到分数并列按预定的更少束、较高承载及布局哈希顺序打破；固定N时略过束数比较。选点规则、归一化尺度、容差和承载门槛一起冻结。若前沿没有合格点，就退回共同强初解。完整布局的回退包含中心、归属、宽度和N。

固定N轨群体只能在相同实际N中演化，跨景N可不同；应用轨可探索不同N但不超过200。两轨前沿分开画，不能将同N轨最优CV与应用轨少束点混成一个冠军表。若以后引入可变宽度，宽度档位、天线增益/干扰和载荷依据需另冻结；动态业务则要有真实时间序列和重配置代价，静态三倍率不是动态验证。

## 建议预算、对照与停止

可从群体16个、最多8代、每景最多128个**新增生成提案**起步；128包含初始化扰动与各代子代，共同初解另列，不再给初始群体额外16次免费试算；每个提案的几何修复、代理评估和完整物理核验都计调用，重复/拒绝/回退也计时间。建议同束数轨仍以2秒共同在线总时限起步，若128次完整物理调用做不到，则按时限停止并报告实际代数与调用数；不能只报“8代”隐去真实工作量。种子仅用于搜索复现，不是模型训练种子；先建议51001，与其它路线同场景配对。群体、代数、调用数、2秒均是短工程核验后待冻结建议，不是已获正式预算。记录初解、构造、修复、模型估计、终局核验和全场总时间，另报达到某CV/承载门槛所需时间。

对照包括共同初解、同预算单目标搜索、同菜单随机扰动、固定N下的均衡优先搜索，以及多目标搜索。它们共享候选变异菜单、真实评价器、可用调用数和墙钟；单目标与多目标差别应主要是保留与选择机制。NSGA-II作为本路线的一个实现，GA、PSO或DE不分别充作三项独立科学模型；若将来比较这些搜索器，共用总预算并说明额外机制。若报告前沿覆盖或超体积，必须先把各指标统一为最小化方向，再按验证集冻结尺度和参考点；参考点不能由每个方法或测试前沿各自决定。逐景计算、按母场景汇总，不能将不同飞机场景的点拼成一个前沿。固定N时N是常数，使用CV—承载二维指标；跨N才使用三维。点数受重复与容差影响，不是质量指标。非支配只表示候选之间有取舍，既不证明对强初解逐项改善，也不保证全局Pareto最优；另报相对初解的支配／互不支配／被支配比例，以及冻结单解的逐景收益与退步。最终正式质量/效率按专题总览的同场景指标评价。

首轮物理评价统一冻结`variable_downstream.evaluate_layout`的分配器、天线与逐机TDMA版本。搜索使用的代理分数、原始编码可行率、修复后可行率、回退及最终发布性能分别保存，不把复制父代的回退计为新增可行发现。相同在线墙钟是主比较，生成数、真实全景调用上限及其实际消耗并列；另做固定评价次数消融，不能声称相同墙钟就必然执行相同次数。神经训练为0；群体、算子和概率调参建议仅开发集最多6组配置、合计2小时离线墙钟，验证集按预定规则一次选型，不循环调到验证指标好看。全部上限待统一冻结。

正确性小例：三个可行布局A=(CV 0.40，承载80%，N=50)、B=(0.45，83%，N=50)、C=(0.50，78%，N=55)。在最小CV、最大承载、最小N下，C被A支配，A与B互不支配；若测试代码保留C为非支配点，排序错误。另造一个D=(0.30，90%，N=45)但漏覆盖一架边缘飞机，必须拒绝D而非让它占前沿。20母开发景若发布点有任何硬违规就修复；若群体大多是重复/不可行，或在实际统一时限内少于3/20母有通过承载门槛的可行CV改善（超过冻结数值容差），则停止扩大搜索，分析编码与修复。验证集固定单解选择后才可进入新独立考核，考核不回流调选点规则。

## 接入及论文边界

正式实施时工作台需提供方法枚举、固定/可变N、群体/代数、生成/物理调用上限、变异/交叉菜单与概率、修复上限、支配容差、验证集冻结的前沿单解选择规则、在线墙钟及种子；服务端校验并冻结，展示实际前沿、可行/拒绝/回退率、调用账和分段时间。目前工作台没有这些参数，本轮纯文档不改页面。

[NSGA-II（Deb等，2002）](https://ieeexplore.ieee.org/document/996017)提供保优非支配排序与拥挤距离机制，原文并未验证本项目飞机覆盖。[FlexBeamOpt（2023）](https://onlinelibrary.wiley.com/doi/10.1002/sat.1481)综述和使用灵活GEO布局的组合方法，不能把其载荷与性能数字迁移到本场景。[Optimization in VHTS Satellite System Design with Irregular Beam Coverage（2021）](https://www.mdpi.com/2072-4292/13/13/2642)说明不均匀业务下不规则覆盖的设计动机，不替本路线提供全覆盖或Pareto优势保证。来源适用范围见[文献附表](../../../../outputs/research/beam_coverage_routes_20261012/文献与适用边界.md)。


**统一验收补充：**本篇发布单解的主比较对象固定为总览定义的BH；前沿收益另对同编码同预算单目标进化归因，不用前沿点数代替质量。 在线承载容差始终相对共同初解I0，正式均值门槛相对上述比较方；详见[共同约定](00_专题总览与共同比较约定.md#正式主比较对象)。
