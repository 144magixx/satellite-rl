# 01 掩码布局重构：学习补全局部归属

**执行更新（2026-10-12）：**本路线已纳入获授权的S1-ND12四端首轮验证。以下保留方案形成时的建议；实际任务、分账及停止条件以[专题执行状态与冻结计划](00_专题总览与共同比较约定.md)为准。当前处于正式数据准备，尚无新效果结论。

日期：2026-10-12。状态：**MLM已确定保留为独立研究路线；本篇参数和预算仅供冻结前讨论，尚未批准执行或取得新结果。** 共同比较、数据划分和指标按[专题总览](00_专题总览与共同比较约定.md)。[原方案15](../15_掩码布局重构与约束优化方案.md)保留更完整的建模推导；本篇是专题内的可实施设计，不另算第二个MLM模型。

**一句话做法：**把局部区域若干飞机的波束归属遮盖，让网络依据位置、需求和未遮盖布局补全，再用硬约束核验；同一网络还可给约束优化器缩小候选域。

## 决策、输入与输出

本研究先在固定0.5°全宽、同场景共同束数N的机制轨检验局部重构。输入是飞机方向与需求、候选波束中心/宽度、几何可覆盖边、区域外已锁定归属、区域内可见归属及从可见部分计算的负载。遮盖飞机的真实归属、教师最终中心、完整束负载和隐藏束启用状态不能进入输入。飞机与候选的序号仅用于对齐，不能作为可记忆日期或教师解的特征。候选池由共同初解与场景几何规则在教师求解前生成、去重并保存哈希，原解的候选和边必须保留。

每个局部选择空间为可覆盖该飞机的候选索引，网络只学习**被遮盖飞机的候选归属概率**。实际启用波束由最终非空归属导出，不另预测与归属冲突的N。区域由2–6个相邻束及其全部飞机组成，区域外不变，首轮区域内仍须恰好使用原来的k束；飞机过多可按冻结规则缩区，不能丢机。输出保存原始概率、原始补全、执行/修复和最终布局四份身份可对齐的记录。

## 从参考解到发布布局

1. 先按母场景与时间块划分数据，再在训练母场景上生成共同初解与候选池。教师在相同池、同k、相同外部归属下限时求局部可行优质解；保存优化状态、目标、耗时、可用界和gap，超时可行解不称全局最优。
2. 从优质完整解随机或成片遮盖25%、50%、75%及全部局部归属；另从共同初解或搜索中间态遮盖，但教师必须在**保持可见归属**条件下补全。一个母场景的多掩码只是增强样本。等价高质量解可保留多份，不以对单一标签的完全一致衡量最终质量。
3. 用飞机和候选双集合编码器经可覆盖边交换信息，再对每个遮盖飞机的合法候选分类。建议128维、4层、4头，交叉熵只计遮盖位置；非法边和填充位严格屏蔽。上述宽度是显存与可表达能力的工程起点，开发短验证后冻结，不宣称最优。先不叠加PPO或软物理惩罚。
4. 推理M使用冻结置信度顺序逐批填入、实时重算部分负载、按相同几何核验；失败、束数错误或未改善即回退原可行布局。推理MO用**同一权重**为每机保留前8合法候选和原归属候选，同一数学优化器决定最终归属。这里“原解”指本轮遮盖前的当前可行布局，其中心、边及可见归属均须保留，不能仅保留最初I0而与已经改变的可见上下文冲突。求解超时且没有更好可行解也回退。两种推理不算两个模型。

多解训练首版每个样本只抽取一份完整可行补全，交叉熵不混合两份互斥分组的逐机标签。候选重排时概率向量及标签同步置换；飞机重排时输出逐机对应。并列置信度按稳定几何键处理，不能靠数组顺序制造质量差异。训练教师给定的可见归属先做一致性核验；不能用另一份教师终解替换隐藏部分后破坏可见条件。

同N、同总需求时，全体实际束负载平方和与全体负载CV同序；平方目标若走现有线性MILP，须使用共同分段线性近似并记录误差，最终仍用精确CV验收。几何合法候选不能保证全局唯一归属、恰好k束、N≤200或下游承载，必须对整个场景重核。

首轮下游统一冻结现有`variable_downstream.evaluate_layout`的分配器、天线与逐机TDMA版本；这属于模型估计评价，并未运行完整第二阶段学习分配与第三阶段连续功率优化。不同路线不得私换下游或求解精度，若将来加入完整链路须另定共同预算。

## 对照、预算与闸门

六法固定为共同初解I0、同区域规则H、全候选优化O、网络补全M、网络筛选加优化MO、同规模规则筛选加优化HO。冻结同一局部输入时，六法共用区域、完整池和核验；MO与HO均先强制保留当前原归属，再用各自分数补足相同边数，上限为每机9条合法边，避免“前8加原边”去重后数量不同。O显示全池成本。多轮自主搜索一旦布局分叉，只能保证同区域规则、生成器、容量与在线预算，不能声称后续输入池仍逐项相同；单步同池审计与最终闭环成绩分开。这样可区分网络、候选裁剪及求解器的作用。旧BC/PPO只作历史背景，不能跨动作空间直接排行。

**待批准上限：**一个seed51001模型、最多10000监督更新、每1000更新作冻结验证；教师最多20000局部问题，每题求解器最多1秒，即最多20000求解器秒，候选准备与审计另账。建议batch 32并按局部规模分桶。每个问题可含多机标签，分别登记母场景、局部问题、掩码样本、标签数和更新数。开发20母用于可达性，另取新验证20母；新100母×三需求档×六法为1800条方法记录。在线建议每景最多8区域、每区域4次补全、每次8轮解码，共同算法预算起步2秒；优化每区域最多0.25秒且受总预算约束。这些时限须先经短工程验证，再统一冻结。

教师20000次包括可见条件改变后的重新求解及开发可达性调用；仅重新遮盖同一已保存可行解不增加求解数。验证不再临时调用教师来改标签或调模型。全部局部问题、候选生成与核验离线成本均登记，不能只报告求解器秒。

开发闸门为：较充分教师至少在6/20母上取得相对I0超过1%的CV改善，且原解在裁剪域内始终可表达。未过先诊断池、区域和初解；损失下降但冻结验证布局无改善，到上限停止并保留失败。正式质量或效率成功采用[共同门槛](00_专题总览与共同比较约定.md#4-数据预算与推进规则建议尚未冻结执行)：相同在线预算下MO对HO和O平均CV均下降至少5%，或在CV不劣于2%、P95不增条件下完整总时中位数均减半；两支均要求逐机承载下降不超过0.5个百分点、全部发布布局可行且不劣于I0，逐景退步公开。M另报相对H/I0的净改善，不把MO成功当M成功。主结果用预算终点权重，考核不挑权重，单种子不推断稳定性。

**正确性小例：**两束、三机中，第三机只在原束A足迹内。遮盖第三机后非法B概率必须为零；即使MO前8裁剪，A仍在域内，强迫B的伪标签应被拒绝。失败信号包括隐藏真实负载改变了模型可见输入、候选重排后输出不等价、回退前原始提议频繁不可行、教师可改而模型仍无增益。

## 扩展、接口和出处

可变N轨把局部k作为输入条件，允许启用/停用束但全局≤200；跨N不能沿用固定N的平方和等价论证，应在验证前冻结CV、束数与承载取舍。可变宽度候选须同时进入增益、干扰和足迹核验；动态业务只输入已知历史并记切换成本，首轮结果不能外推为这两项已完成。

实现拟复用`coverage/variable_dataset.py`、`variable_design.py`、`geometry.py`和`variable_downstream.py`的接口，新建掩码数据、模型、解码、局部优化与任务配置模块。短验证包括可枚举小例、重排等变、隐藏答案不泄漏、原解裁剪保留、真实参数更新、超时回退及全场景指标复算。正式实施时工作台需提供掩码比率、候选池、k/N模式、两推理模式、教师/更新/时限等配置，贯通服务端校验、冻结任务、模型元数据、日志和结果展示；本轮只有文档，不需改前端。

方法借用：[BERT原论文](https://aclanthology.org/N19-1423/)的遮盖恢复目标、[MaskCO原论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/d85816bf41e54d9b0847e02249f4fcc6-Abstract-Conference.html)的组合解局部掩码思路，以及[Neural Diving原论文](https://arxiv.org/abs/2012.13349)的学习缩小求解域思想。它们研究的文本、路径或整数规划问题都不提供本项目飞机硬覆盖、天线物理及200束保证；候选、教师、修复和在线计算收益需在本项目独立归因。


**统一验收补充：**M按共同门槛独立比较H；MO仍须对HO和O均验，两种推理分别报告。 在线承载容差始终相对共同初解I0，正式均值门槛相对上述比较方；详见[共同约定](00_专题总览与共同比较约定.md#正式主比较对象)。
