# 04 学习候选排序与搜索：先核值得试的调整

日期：2026-10-12。状态：独立建议，训练、试算和考核预算**未批准执行**。共用[专题总览](00_专题总览与共同比较约定.md)的可行域及归因口径。本路线排序已经由规则产生的**具体候选调整**，不是[01掩码补全](01_MLM掩码布局重构.md)的归属预测，也不是[05区域选择](05_学习区域选择与大邻域重建.md)的“先选哪一片再重建”。

**一句话做法：**规则按固定菜单生成局部调整，网络预测哪些调整值得真实试算，在相同候选数与时间内优先核验高分项，接受经过整景计算的真实改善。

## 状态、标签与执行机制

输入是当前可行布局、飞机方向/需求、当前束负载、候选调整的对象与几何摘要、低价代理目标及剩余时间。规则枚举的候选包括转属、交换、中心候选替换等，首轮固定0.5°与同N；候选生成与01的补全集合、05的区域列表不是同一个动作对象。模型输出每个候选的**排序分数或真实收益概率**，不直接改变归属。所有候选即使被学习跳过也必须在日志中有身份和生成成本。

训练标签需要真实试算，而不是把代理CV当答案。对选定训练状态的候选，执行同一几何与下游核验，计算完整场景ΔCV、承载变化、是否可行和单次试算时间；按事前目标把可行且有改善的候选排在前面。不可行候选记失败，不用任意大收益值填充。可用组内成对排序损失 `log(1+exp(-(s好-s差)))`，并以实际正改善幅度作有界权重；候选分数之间的绝对尺度并非目标。建议候选图/集合编码器128维、3层、4头，状态与候选共享编码，batch 16个状态，先经短验证冻结参数。标签来自真实整景试算、非学习规则的候选域；模型若仅复现便宜代理，必须在对照中显现其额外价值。

在线每轮由**同一生成器**产生候选池，网络/规则/随机各自排序并取前K个真实试算；相同的是试算数量上限，不是被选择的候选身份。首版在完成的前K项中选真实目标最优且合格的一项，再更新状态，不混用“首个改善即停”和“取最好”两种规则。试算须满足硬覆盖、唯一归属、同N、需求守恒及预设目标改善；接受后重建候选池，直到时间、轮数或无改善停止。预算截止只在已经完成的试算中选解，未完成项记超时未知而非不可行/负收益。最终无合格解保留当前布局。新束中心使全景干扰或承载改变时以整景结果为准，不能只凭局部代理收益接受。记录生成、编码、排序、每次完整试算、最终核验和初解/端到端时间。

全景承载统一使用冻结版本的`variable_downstream.evaluate_layout`分配器、天线与逐机TDMA评价；这只是当前模型估计下游，不表示完整S2学习分配与S3功率优化已执行。所有排序对照共用该版本与精度。

## 样本、预算与漏检

先划母场景与时间块，再在训练母场景收集同菜单、不同布局状态，不能把一个母场景的上百候选当上百独立场景。训练标签应覆盖有改善、无改善、不可行及不同需求档，且对教师搜索状态和规则搜索状态分别记录来源，避免只会排序已很好的布局。候选全集若太大，抽样规则先冻结；**未试算候选不能当负例**，开发小子集可全枚举以估计被跳过的最佳改善及top-K召回。

**待批准上限：**训练最多2000状态、每状态最多64次真实候选试算；连同开发审计和固定验证的真值调用，总次数≤128000、总试算墙钟≤12800秒，任一先到即停。开发20母全枚举审计每母最多256候选、共≤5120次；验证20母各固定一个审计状态、每母最多64次，共≤1280次，真值保存后各验证节点复用。训练剩余最多121600次，不能再运行2000×64满额后叠加两类审计。开发的“全枚举”仅指该冻结有限池，池超过上限即先按规则截断并注明。

单次0.1秒只是待短工程验证的试算目标；整景物理调用若不能安全中断，按实际完成时间扣总账并记录超限，不把0.1秒伪装成已实现硬截止，也不将未完成调用填为负标签。单seed51001、最多8000监督更新，1000更新一次固定验证，主结果取预算终点；候选生成、整景物理核验与训练时间分别记。在线每轮K=8、每景最多8轮、算法预算2秒起步，实际完成候选数受截止约束；同K的静态机制审计不冒充同2秒闭环结果。K与时限经短工程试验共同冻结，不能为学习方法放松。新考核100母×三档、方法数按最终共同矩阵冻结，其正式调用预算另列，不能混作128000训练/诊断标签。

开发闸门是：全枚举小审计显示20母中至少6母存在>1%相对CV改善的合法候选；再用包含于8000总额的前2000更新试点，要求固定验证池的top-8可行改善召回高于规则排序至少5个百分点，且已完成试算的真实最佳改善不更差。否则先诊断候选生成或特征，试点未过即保留失败，不自动加预算。召回分母是该已完整标注池内的合格改善候选数；没有改善候选的状态单列，不按召回零或一处理。排序输入中不得出现试算后CV/承载、真实可行标记或耗时真值。top-K召回只解释漏检，正式效果仍以完整布局和成本衡量。**小例：**同一状态三个候选A/B/C，真实全景CV变化分别为−0.10、+0.02、不可行；网络应把A列前，C即便局部代理最优也不能给正标签。K=1时选择B、错过A属于可量化漏检。失败信号包括训练排序损失下降而top-K真实改善召回不升、模型排序耗时超过节省的试算时间、优秀候选持续落在K外，或收益全来自候选生成器。

## 配对归因与范围

同N轨至少比较共同初解I0、规则排序H、随机排序R、学习排序L。另在冻结相同状态/候选池上记录全试算F，作为**这个池的一步最佳改善参照**，不能称全局布局或多步搜索上界，也不计为同预算在线方法。L/H/R的单步机制审计共享同池、K、试算器与接受准则；自主搜索接受不同动作后状态会分叉，后续只能保证同生成器、候选上限、K和总在线时限，不能声称逐轮候选完全相同。若学习路线额外使用局部整数优化器，必须增设同候选数、同优化器的规则排序对照。只比较模型前向速度不算完整加速，离线标签成本单列。

正式成功采用[共同门槛](00_专题总览与共同比较约定.md#4-数据预算与推进规则建议尚未冻结执行)：对事先固定的最强低成本规则排序H（不能考核后才挑），相同在线预算平均CV至少降5%；或CV均值劣化≤2%且完整总时中位数至少减半、P95不增。两支均要求逐机承载下降≤0.5个百分点、发布布局全部可行，并报告逐景退步；逐景漏检只能对另行完整标注的池计算，不凭未试算项猜测。若另与更强非AI搜索比较，需在共同矩阵显式列方法及调用预算。考核前冻结质量/速度分支和比较对象；单种子结论有限。若模型只比随机好却不比规则好，应如实记探索失败。

可变N应用轨加入开/关束候选并冻结跨N选择准则；变宽候选须重核增益、干扰和物理宽度；动态业务再用上一时刻布局、当前可知需求和切换成本作状态。首轮仅固定宽度机制，不能据此声称已完成动态覆盖规划。

实现可复用现有候选几何与`coverage/variable_design.py`核验，新建候选身份/试算缓存、标签收集、排序网络和限时搜索模块。短验证包括候选顺序置换后排名等价、实际试算标签可复算、无试算候选不被标负、硬时限/回退、真实梯度更新及整景指标一致。正式工作台应增加候选菜单、K、每景轮数、试算与监督上限、排序器类型、任务冻结与进度/漏检展示；纯文档阶段不改界面。

方法借用：[NeuroLKH原论文](https://arxiv.org/abs/2110.07983)的学习引导启发式搜索思想、[Learning a Large Neighborhood Search Algorithm for Mixed Integer Programs](https://arxiv.org/abs/2107.10201)的学习辅助局部搜索，以及[Learning to Search via Retrospective Imitation](https://arxiv.org/abs/1804.00846)关于从搜索取得监督的思路。原问题是路径或一般整数规划，不能把其加速比外推到卫星几何、天线与飞机需求；本篇所需的候选真实试算标签和整景硬核验须单独建立。
