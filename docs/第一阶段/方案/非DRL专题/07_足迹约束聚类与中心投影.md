# 07 足迹约束聚类与中心投影

**执行更新（2026-10-12）：**本路线已纳入获授权的S1-ND12四端首轮验证。以下保留方案形成时的建议；实际任务、分账及停止条件以[专题执行状态与冻结计划](00_专题总览与共同比较约定.md)为准。当前处于正式数据准备，尚无新效果结论。

日期：2026-10-12。状态：仅方法设计，无新实验授权。[专题总览](00_专题总览与共同比较约定.md)给定相同强初解、两条比较轨和全景核验规则。本研究检验一个很具体的问题：当一组飞机的需求与归属暂定后，能否在**真实可指向、所有成员均在足迹内**的范围内移动波束中心，再交替调整分组，使布局更紧凑、负载更均衡且不损失承载。路线为非学习算法，可用作后续AI方法的可行执行器或强基线，不把几何投影本身说成AI效果。与[06 需求约束聚类](06_需求约束聚类与归属重分配.md)相比，本篇重点是中心可行集合及其与分组更新的耦合，而不是用整数分配直接逼近负载目标。

## 几何对象与项目适配

输入为飞机ID、位置、需求、共同强初解的束中心/归属/N、GEO卫星位置、项目现用射线足迹判断与合法指向域。输出为实际中心、固定0.5°全宽、唯一归属、N≤200及全景核验账。令 F(c,θ) 表示由项目**原几何实现**给出的中心 c、全宽 θ 的地面覆盖集合；一个分组 S 的真实可行中心集合是 C(S)={c在载荷允许域内：每个i∈S均落入F(c,0.5°)}。中心候选必须逐机调用原射线判定验收，不能以平面距离阈值代替。飞机负载 L_b=Σ_i∈S_b d_i、全体实际束CV与正需求束CV另算；几何紧凑不必然等于更低负载CV，也不必然改善带干扰的模型估计逐机承载。

[GeoClust 原论文](https://www.mdpi.com/1424-8220/26/8/2384)在其定义的GEO地面用户场景，使用给定平面足迹半径、圆盘覆盖初始化及Boyle–Dykstra投影更新中心，并给出该模型下的可行与收敛论述。那里的圆盘约束与本项目从卫星出发的射线、地表投影、0.5°角宽和合法指向域**不是同一个集合**，因此其投影公式与定理不能直接套用。本项目仅借鉴“先写可行域、再在可行域内更新”的算法思想。若工程上用局部切平面近似求候选，必须对每个候选调用真实几何验证；反例或边缘数值失败时缩步、改候选或回退，不宣称近似映射保可行或收敛到局部最优。

| 步骤 | 建议处理 | 接受条件 |
| --- | --- | --- |
| 1 保存起点 | 记录共同强初解的N、中心、归属、每机射线覆盖与哈希 | 原起点全景可行；否则该景单列异常 |
| 2 生成分组邻域 | 从负载偏离、几何松弛最小的束对提出单机转移、两机交换；每轮最多16组 | 转移后每机仍唯一归属，不删除零需求机 |
| 3 中心候选 | 对固定S先尝试需求加权球面方向，再沿旧中心→候选缩步；采样指向域边界与成员约束交汇附近，最多24点 | 每点真实射线覆盖S所有飞机、满足指向限制 |
| 4 联合验收 | 对每个完整布局重算全景几何、负载、资源、干扰和冻结下游承载 | 只保留预先目标更优的可行布局；失败回退完整状态 |

对固定分组，只要旧中心可行，C(S)至少包含旧中心；增入边界机后若未找到合法候选，撤销该次转移，但仅能记“有界搜索未找到”，不能据此证明C(S)为空。中心内部采用卫星到地表的单位射线，需求加权方向须归一化，并与地球求交、转回现有Layout的经纬度；未与可见地表相交、区域越界或低于最低仰角均拒绝。现有可见域只代表项目注册的区域与仰角条件，不能称已经取得实际载荷全部指向限制。全零需求组用无权方向或旧中心，不做零分母加权。角半径为全宽的一半，即0.25°；几何核验沿用平方弦长阈值和冻结公差。

使用经纬度线段或球面缩步时，不把局部平面投影的可行性自动外推到真实射线与指向域，逐点验收。候选中心可用局部小规模约束优化搜索，但真实几何作为硬门；优化器若仅给近似可行解，必须标记“原始提议失败／修复后可行”。分组更新后重算全部成员，而非只验新增飞机；移动指向可能改变与区域外波束的干扰，因此只有全景模型估计结果可以用于发布判断。固定分组移动中心不会改变CV，本篇采用“分组提议—为新分组寻找中心—全景联合验收”的原子操作；只改中心的消融以几何余量和承载诊断，不要求其产生不存在的CV下降。最差情况下保持原强初解并报告无改进，不把保底可行率当作投影算法原生可行率。

首轮同N机制轨固定0.5°全宽；每景最多8轮，每轮最多16个分组操作，每操作最多24个中心候选，真实射线判定与全景核验都收费，在线算法预算暂定2秒。原封不动强初解作回退，所以不用虚构“对所有任意分组必有可行投影”。2秒下候选预算可能过大，应先以4轮×4操作×6中心做短工程吞吐核，再统一冻结实际参数；不得单独为本法加长时限。无神经训练成本；建议开发20母×三档×最多3组步长/邻域配置即180次，20新验证母挑选冻结配置，100新母×三档最终考核。可变N应用轨在固定宽机制过闸后加入有界拆合，按跨N准则决定是否保留，仍须N≤200并记录真实N；角宽可变须重新定义 F(c,θ)、合法宽度和天线增益/干扰，不能把半径参数当作已实现的角宽控制。动态业务则需将中心重配置和时序成本纳入目标，另行设计与授权。

正确性闸门先做项目真实几何的小例：平面近似与真实射线在边界的判定差异、合法指向域边界及插值逐点验收、新分组无合法候选时回退、零需求飞机仍在束内。对具体模型未构造出的反例不得写成已存在，更不能只因采样失败就声称可行域为空。接着在20开发母要求至少15母有可提出的非平凡中心或归属调整，并有至少8母在同N、同2秒预算下全景CV相对强初解下降超过1%，同时所有发布布局射线覆盖通过、承载不过共同下降容差；门槛按总览先归母统计，达不到就保留失败结论，不因几何可行率高而放行。对照为强初解、只改中心、只改归属、无需求权重中心、相同邻域数的[06](06_需求约束聚类与归属重分配.md)，以及原论文式平面候选经本项目几何修复后的版本；这几类须分开列原始失败、修复和回退率。若联合方案只达到“只改归属”的质量且不更快，应报告未证明中心更新的增益，不能仅凭中心发生移动认定有效。

首轮冻结现有`variable_downstream.evaluate_layout`分配器、天线和逐机TDMA实现，任何中心候选的全景调用都计入搜索成本；这不是已跑完整第二阶段学习和第三阶段连续功率优化。固定验证后新共同考核使用总览的同N质量／效率成功条件：平均CV至少比事前指定强参照低5%且逐机承载平均下降≤0.5个百分点；或在CV不劣于2%、承载下降≤0.5个百分点的情况下，完整总时中位数减半且P95不增。全部发布布局可行是硬前提；逐景记录N、全体束及正需求束CV、带内率、几何边距、中心位移、模型估计逐机TDMA承载、初解/分组/投影/修复/核验/总耗时。几何更紧凑可能改变离轴和干扰，不能以平面半径变小直接推断承载提升。

实现上复用现有 Layout、指向域和原射线函数，新增中心候选生成、真实可行缓存和失败分类；短测试核边界舍入、公差、地球曲面、回退前后位级布局一致、全景再算。工作台将来要有路线07、宽度模式、候选上限、缩步次数与几何容差配置，服务端校验、任务冻结和页面显示原提议／修复／最终结果；目前只是文档，未修改前端。原始出处：[GeoClust](https://www.mdpi.com/1424-8220/26/8/2384)、[Honnaiah 等的需求自适应GEO足迹](https://orbilu.uni.lu/handle/10993/49263)与[不均匀业务下的卫星不规则覆盖设计](https://www.mdpi.com/2072-4292/13/13/2642)。它们分别支持可行中心、需求驱动和灵活覆盖的研究思路，不保证本项目的几何、负载或模型估计承载结果。
