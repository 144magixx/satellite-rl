# 09 地理邻接图划分与波束构造

**执行更新（2026-10-12）：**本路线已纳入获授权的S1-ND12四端首轮验证。以下保留方案形成时的建议；实际任务、分账及停止条件以[专题执行状态与冻结计划](00_专题总览与共同比较约定.md)为准。当前处于正式数据准备，尚无新效果结论。

日期：2026-10-12。性质：待验证的非学习方案；没有新增训练、评价或正式预算。比较条件、指标及最终任务矩阵以[专题总览](00_专题总览与共同比较约定.md)为准。本路线研究的是：先用飞机之间的空间关系找出可重组的需求片区，再把每片转换为真实可用的波束。图只是提出分组的工具，几何足迹与资源核验仍是硬门槛。

## 场景、变量与输出

输入为同一时刻的飞机身份、位置、不可拆的逐机需求、载荷可用指向区域、当前合法宽度与共同强初解。图节点是一架飞机；边表示在球面或卫星视角角距离下相邻，边权可综合距离、需求互补和原束归属。边不表示两架飞机可以被同一波束服务。决策是节点归属、实际束数、每束中心与后续可变宽档位。输出必须是逐机唯一归属、每束非空且有合法中心、全部飞机覆盖、束数不超过200的完整布局，同时保留图分组、被拒绝分组和回退记录。

首轮固定0.5°全宽。对任一组飞机，须求解共同足迹中心的可行域：把每架飞机按实际卫星射线允许的中心区域相交，再与载荷指向域相交。只有找到一个合法中心，并按项目冻结的视角、边缘和数值容差规则重算全部组员覆盖，才能构造一束。近似中心搜索没找到解只能记“在当前预算内未找到可行中心”；除非有有效不可行证书，不能写成真实交集为空。图团中的每两点相邻，即使每一对分别存在可覆盖中心，也仍可能没有覆盖整组的共同中心。平面圆盘或球面帽的结论须核对本项目几何条件后才能采用，不能把团覆盖当成物理覆盖证明。

## 逐步算法

1. 由共同强初解给出可行回退和同束数轨的目标束数。预先计算按真实卫星几何定义的邻近列表，只保留每节点最多建议12–24个近邻；距离阈值、近邻并集或互近邻的无向化规则、并列距离排序与列表上限在开发集冻结。稀疏图只限制搜索，不是物理可行域；不连边不能推出不可同束。孤立点和高需求点保留合法回退归属及可覆盖它的候选，不能一律新增单机束而破坏固定N或200束上限。
2. 生成候选连通片。先按重载束、轻载束或跨束边界选种子，沿边尝试合并、切开或交换节点；每次扩张同时更新中心可行域和需求负载。证明为空或预算内未找到合法中心时均拒绝该次扩张，但两种原因分开记录。候选片区的优先分数结合预计负载差、边界长度及中心移动，分数只用于排序。
3. 构造完整划分。同束数轨在保持实际N不变的条件下，允许一片拆开同时在另一片合并；不能借多束降低CV。可变N轨允许拆分或合并，但每步检查1≤N≤200，记录每个N的候选质量。为每组从可行域选中心，再以真实几何、全场负载和冻结下游承载模型评估。
4. 只提交全景通过硬约束且达到预先规定接受准则的布局。一次候选不佳可继续在预算内搜索；预算耗尽、构造失败或正式核验失败，原子回退到最后一个完整合法布局。回退时不能保留新组的局部归属或中心。输出原始图提案、修复后的方案与最终方案三份状态，方便区分图搜索和几何修复各自作用。

图划分可用受限区域增长和局部交换实现，不必先上通用最小团划分器。图边权对负载的解释仅是启发式；目标仍由完整布局计算。若一个组拆成两个但相邻组无法合并，固定N轨直接拒绝这次组合。零需求飞机仍须覆盖和归属，零需求束按总览的边界规则计入全体束统计。

## 预算、对照与推进门槛

建议每景最多产生200个片区提案、对其中最多60个执行真实中心求解与完整布局核验；同束数轨在线算法预算先参考2秒，包含建图、搜索、拒绝、修复和内部核验。可变N轨也先用同一总时限，分别报告N、质量及时间。共同初解与最终一次下游核验另列分段时间，并给完整端到端时间。邻居数、提案数和时限是**待短工程验证冻结的建议**，不是已批准执行预算。若显著超时，先缩小候选而非只给本方法延时。

公平对照包括共同初解、相同N和同在线预算的R04/非学习局部搜索，以及仅按距离建图、加入需求边权、加入真实几何剪枝三层消融。每层用相同场景和可用核验次数。图方法若比纯几何区域搜索强，需确认改进来自图选择而非多次试算。质量按平均CV、需求带内比例、束数、模型估计逐机承载和逐景退步并列；后续资源与干扰改变时全场重算，不只报告图割或组内方差。沿用总览的同束数质量/效率判据，应用轨须先在验证集冻结跨N取舍规则。

正确性小例：三个点A、B、C各自到另两点的角距离都小于建边阈值，但合法中心区域三者交集为空。构图会得到三角团，算法必须拒绝三人同束，并保留原完整覆盖。另一例把边缘零需求飞机放在唯一可覆盖的束内，拆组后不能将它从输出丢掉。20母开发景中若出现任何发布布局失覆、重复归属或N越界，先修实现；若合法且配对CV改善少于3/20母、逐机承载明显退步或多数场景超时，则停止扩大该路线。这里的3/20仅是开发筛选建议，正式门槛仍按专题总览在验证后事前冻结。

首轮所有进入接受判断的完整布局，统一使用冻结的`variable_downstream.evaluate_layout`分配器、天线与逐机TDMA版本；搜索中的每次调用计入在线成本。这仍是模型估计，不能称为完整第二／三阶段联训验证。神经训练为0；建图参数与边权调参建议限开发集最多6组配置、合计2小时离线墙钟，失败和重试计入，验证集只作一次预定选型。该上限待统一冻结，不自动增加正式预算。

## 接入与来源边界

未来工作台应新增“地理邻接图”方法枚举、邻近度量、最多邻居、边权版本、区域扩张及交换次数、固定/可变N、中心可行域求解容差、提案/核验上限、墙钟限制和随机种子；服务端需校验并写入冻结任务配置，进度展示已试片区、拒绝原因、实际N、回退率和分段耗时。目前工作台没有这条新路线，文档不表示页面已经支持。当前仅写方案，不需同步现有前端。

方法动机来自[Fast Beam Placement for Ultra-Dense LEO Networks（2025）](https://orbilu.uni.lu/handle/10993/66355)，其图方法用于超密LEO用户的波束放置与负载平衡；本研究不搬用其LEO链路、用户规模或性能数值。[FlexBeamOpt（2023）](https://onlinelibrary.wiley.com/doi/10.1002/sat.1481)说明灵活GEO布局需要把候选构造与实际束分配结合，但其目标和载荷约束不同。[Demand-Based Adaptive Multi-Beam Pattern and Footprint Planning（2021）](https://orbilu.uni.lu/handle/10993/49263)提供需求驱动的GEO足迹规划背景，不证明本图划分器有效。原始来源的适用范围见[文献附表](../../../../outputs/research/beam_coverage_routes_20261012/文献与适用边界.md)。
