# 05 学习区域选择与大邻域重建

**执行更新（2026-10-12）：**本路线已纳入获授权的S1-ND12四端首轮验证。以下保留方案形成时的建议；实际任务、分账及停止条件以[专题执行状态与冻结计划](00_专题总览与共同比较约定.md)为准。当前处于正式数据准备，尚无新效果结论。

日期：2026-10-12。状态：独立设计建议，未训练、评价或批准预算。共同比较条件见[专题总览](00_专题总览与共同比较约定.md)。本研究让监督模型决定**拆哪一片波束与飞机**，让确定性的几何与局部求解器重建该片；学习模块不直接发布归属，也不使用强化学习。它与[04 学习候选排序](04_学习候选排序与搜索.md)的区别是：04 对已生成的单步候选排序，05 先选一组关联变量，允许这些变量同时重排。与[11 非AI大邻域搜索](11_大邻域搜索与局部整数规划.md)共用完全相同的区域生成器、重建器、时间上限与接受准则，唯一差异是选区次序。

## 问题、输入和输出

给定同一母场景的飞机位置、不可拆需求、共同可行初解及实际束数 N。每个实际束有中心、0.5°全宽、飞机归属和负载；邻接由可交换飞机、相邻足迹及需求不平衡构图，不能只看地图欧氏距离。一个区域是2—6个相邻实际束及其全部归属飞机；若要跨边界转移，须先把接收束完整纳入区域，区域外束与归属固定。模型读每束负载、边界可转移需求、覆盖余量、相邻关系、局部代理目标及已经尝试过的区域标记，输出对**区域集合**的分数，不读该区域求解后的答案。原始输出是区域ID与分数，执行输出是重建器给出的中心、唯一归属和实际束数；最终仅发布全景核验通过且符合预先目标选择准则的最好布局。首轮不增加学习停止动作，以免把停止策略的收益混入选区贡献。

| 环节 | 建议做法与上限 | 作用 |
| --- | --- | --- |
| 区域提名 | 与11共用菜单，每次最多12片供模型排序，大小2—6束；每原束最多8个中心候选 | 限制模型决策数，防止“多试几倍”伪装学习收益 |
| 区域重建 | 固定外部，局部整数归属与合法中心候选共同求解；每片最多0.1秒，每景最多40次提案，2秒总墙钟优先 | 计算规则、整数解和几何核验与11一致 |
| 终止 | 在线总算法时间暂建议2秒；两片无全景改善或候选耗尽即停 | 将模型推理、生成、求解、拒绝检查全部计时 |

每轮先从当前最好可行解生成区域；模型选择未试且成本估计仍在预算内的一片。局部问题保留每机唯一归属和实际非空束，包括服务零需求飞机的束，允许区域内中心重选、整片重分配；同 N 轨禁止拆增、合并或以删除空束改变N。局部求解器返回无解、超时无可行解、全景几何失败、最终逐机承载或代理目标不合格时，恢复本轮前的完整布局，保留随机数与尝试日志，标记拒绝原因后继续下一区域；不能回滚尝试记录而反复抽中同一失败提案。首轮与11统一只接受全景CV更低、模型估计承载未超过共同下降容差的可行态，连续两次无改善即停；不另开劣解探索或接受温度。对05应分别报告选区合法率、求解器原始布局可行率及发布可行率：模型本身只给区域，不应声称它直接生成了可行布局。

教师用同一最多12片区域列表逐片调用**同一重建器**，以完整场景目标改善和求解用时给每片标注；没有可行改善的状态保留全负标签，不丢弃，也不新增在线停止动作。昂贵教师按母场景而非随机切分的局部片建立，先划20开发母、20新验证母和100新考核母，再从开发母生成样本。建议上限：20开发母×三档×最多16个局部状态×12片＝**11520个区域求解**，每次0.1秒，求解器时限合计1152秒；标签最多960个状态，每状态一组最多12片排序，模型最多4000次监督更新，单seed51001，离线教师与训练合计墙钟建议2小时。1152秒不含候选生成和全景评价，并非教师总墙钟保证；全部准备、失败、重试与工程先导计入总账，截止后不再发新调用，不能删除超时样本。先用4片×4状态的子预算工程核估计可达改善与吞吐，再冻结正式上限；有效样本若远少于预期，应如实缩减或停止，不自动加母场景。可用正负区域的成对排序损失或对比损失；标签为**同一个状态下、同样重建预算的实际终态改善**，可行性与承载门不过者标负，CV改善优先、并列时才比较成本，不能用几何接近或教师最终中心替代。教师逐片试算的离线最优仅是标签参照，不冒充在线2秒可部署基线；共同起点轨迹优先由非AI规则生成，所有候选试算均留账。

开发闸门先要求全景正确性小例覆盖零需求束、区域边界飞机、中心切换后的干扰重算和无解回退。然后要求在20开发母中至少8母存在同 N、同时间预算内可重复的区域重建改善，且在同一状态的区域试算中，最好区域比均匀抽取区域的期望CV改善率平均高至少1个百分点；先在每母内汇总三档与局部状态，再跨母平均。这里最好区域是假设已知所有试算结果的离线参照，仅验证“值得学习的选区差异”，不算在线速度或最终成功。验证集比较模型、按最差负载规则、随机选区和11的非AI选区：每法调用同一重建器、同一候选生成规则、同一在线算法时间，记录选区命中、漏掉好区域、原始与发布可行率。路径分叉后布局不同，不能要求后续区域ID仍逐项相同；用额外的同状态固定候选检查数消融隔离排序贡献。过闸后才在新100母×三档独立考核，不在考核上选模型或调阈值。

首轮下游统一冻结现有`variable_downstream.evaluate_layout`的分配器、天线与逐机TDMA实现，并把每次全景调用计入对应候选/搜索成本；这只是模型估计，尚非完整第二阶段学习加第三阶段连续功率优化。同束数轨按[总览](00_专题总览与共同比较约定.md)冻结质量或效率分支：相同在线预算平均CV比事前指定强非AI参照至少低5%且逐机承载平均下降不超过0.5个百分点，或在CV平均不劣于2%、逐机承载下降不超过0.5个百分点下，完整总时中位数至少减半且P95不增。二者均须全部发布布局可行，公布逐景退步、全体束与正需求束CV、需求带内、模型估计逐机TDMA承载，以及初解、推理、求解、修复、最终核验和总耗时。既有[报告09](../../实验报告/09_R04引导的DRL覆盖A阶段对照.md)只证明BC在那组条件下优于两PPO，不能当本路线预期收益。

可变 N 应用轨另让区域操作允许有界拆分／合并，仍不得超过200束；区域标签与跨N目标要重新生成，不能把固定N的平方负载代理直接用于跨N排名。0.5°固定宽度先验证机制；可变宽与动态业务需另核载荷允许范围、波束图样、重配置代价与时间块迁移，不能把理论可扩展称已实施。

实现时新建区域提议、监督数据及求解接口，复用项目 Layout、卫星射线几何和冻结下游核验；短测试覆盖区域外不变、每机唯一归属、N上限、超时/无解回退、同初解同种子复现，以及教师与在线求解器参数一致。正式工作台需增加路线05、区域大小/片数、求解时限、模型权重与数据版本参数，服务端校验并冻结进任务配置，页面展示区域分数、执行/拒绝原因、模型与结果；本设计未修改前端。原始依据：[Sonnerat 等的模仿学习选邻域](https://arxiv.org/abs/2107.10201)、[Huang 等的对比学习大邻域](https://proceedings.mlr.press/v202/huang23g.html)及[Ropke–Pisinger 自适应大邻域](https://pubsonline.informs.org/doi/10.1287/trsc.1050.0135)。前两者研究整数规划，后一篇研究取送货；其性能和最优性条件均不能直接移植到GEO射线、整机需求与全景干扰。


**统一验收补充：**本篇主比较对象固定为11的非AI规则选区版本；其余规则/随机为消融，不在考核后改主比较方。 在线承载容差始终相对共同初解I0，正式均值门槛相对上述比较方；详见[共同约定](00_专题总览与共同比较约定.md#正式主比较对象)。
