# 08 最优传输分区与几何修复

**执行更新（2026-10-12）：**本路线已纳入获授权的S1-ND12四端首轮验证。以下保留方案形成时的建议；实际任务、分账及停止条件以[专题执行状态与冻结计划](00_专题总览与共同比较约定.md)为准。当前处于正式数据准备，尚无新效果结论。

日期：2026-10-12。状态：设计提案，未执行训练或评价。[专题总览](00_专题总览与共同比较约定.md)规定共同场景、强初解和时间统计。本研究用最优传输（OT）的**连续需求质量分区**产生候选，然后把候选转换为“每架飞机归一个实际波束、每束真实足迹覆盖”的硬布局。OT只负责提出负载较均匀的分区与中心方向；不可拆飞机归属、束数选择和GEO射线几何由后续离散化与修复处理。若最终只靠强初解回退才可行，要明确报OT原提议失败，不能称OT原生满足全覆盖。

## 分组、中心与束数是三个不同决策

输入是飞机位置 p_i、整机需求 d_i、卫星位置、合法指向域、0.5°固定全宽、共同强初解及每景同N目标。先取强初解的实际N个中心作“种子”，把一架飞机的d_i视为位于p_i的一份质量；OT松弛变量 q_ib≥0 表示其需求被连续分到中心b的份额，满足Σ_b q_ib=d_i，并以每中心目标需求配额和几何距离/射线可达的代价构造分区。这个 q 只是**软质量**，不是最终飞机服务；一架需求 40 Mbps 的飞机即便软分20/20 Mbps，发布时仍必须全部归某一束。中心由软分区的需求重心提出，再在合法指向域和真实覆盖候选中筛选。N在同N轨来自共同强初解；可变N应用轨再单独按预先冻结的增束/并束准则搜索N，不能让OT质量格点数量冒充实际束数，也不能把固定N的平方目标直接跨N比较。

| 阶段 | 具体执行 | 单独记录 |
| --- | --- | --- |
| 连续分区 | 对固定N和中心，以射线可达边构造有限支撑OT；建议正则化迭代最多100次、数值容差先固定 | 软目标、总残差、计算时长；无收敛也保留日志 |
| 整机化 | 按软份额、需求残差及可覆盖性给每架飞机选唯一束；相冲突处用小规模二元归属求解 | 软分割机数、原始整数归属及需求偏差 |
| 几何修复 | 对每束候选整组真实射线验收，必要时移中心、交换整机；同N轨必须保留N个实际非空束，全景重算 | 原提议覆盖率、修复步数、修复后质量与耗时 |
| 回退发布 | 修复失败、N越界或承载/目标退步则保留共同强初解 | 原OT可行率、修复可行率、最终发布可行率分别报 |

OT代价可由卫星指向角、离轴惩罚和初解迁移代价组成，但权重与归一化尺度需在开发集冻结；需求不均另写成列质量的惩罚，不能同时强制每列等质量却又声称优化列间不均。首轮建议保留每行Σ_b q_ib=d_i，以λΣ_b(Σ_i q_ib−μ)²软惩罚偏离μ=Σ_i d_i/N，熵正则只加在允许边上；这是带软目标的运输松弛，不能直接使用要求固定双边缘的普通Sinkhorn迭代而不修改求解器。严格等配额版本只作诊断：稀疏覆盖图下，即使初解整机覆盖可行，也未必存在等配额软解，必须记录不可行/残差，不能给不可覆盖边大罚分后允许其入解。保留原中心和原归属边，可给软配额问题提供一个可行质量初值；中心改变后要重新建立覆盖图。

真正的约束是整机归属x_ib∈{0,1}、Σ_b x_ib=1、每束至少一架飞机，真实F(c_b,0.5°)覆盖所有归属飞机。严格配额下连续问题可能可行而整数问题不可行；软配额下则应比较整数后的目标退化，不能把无法精确平衡说成覆盖本身不可行。零需求飞机在q中整行是零，软分区不能决定其去向：另保留其合法整机归属，并参与非空与几何约束；全零需求场景跳过OT平衡，保留布局并按总览单列指标。中心由单位卫星射线重心提出，归一化、与地表求交并转回Layout经纬度后再核可见域，不能直接平均经纬度而宣称为球面最优中心。

中心更新后可行边可能变化，需要重新整机化与全景核验，最多两轮；两轮后无改善或在线预算耗尽即停。同N轨不得通过拆束或删除空束救场，局部失败回退原完整N束布局；应用轨才允许有界拆合。报告连续目标、整数化目标和修复后精确CV，只有同目标、同候选域的有效松弛界才能用于最优性差距。OT输出始终是启发式；必须与不用OT、使用同整机化和修复器的规则对照，不能等到修复成本占多数才补此归因。

建议在线同N预算先按2秒统一起步：每景至多3个中心初始化（共同初解、需求加权中心、轻扰动），每初始化最多100次OT迭代、2轮整机化和几何修复；每轮二元局部问题不超过64机×6束且0.10秒，最多128次真实射线/全景候选收费。数值迭代不是免费计算，模型/规则、修复和最终核验分段计时；初解与固定一次下游核验另列并进端到端总时间。开发前先用4母×三档工程核真实吞吐和数值残差，再统一冻结实际可完成上限。无神经训练；建议最多20开发母×三档×3组代价权重/正则参数＝180次配置试算，20新验证母定版，100新母×三档独立考核。所有数字是候选预算而非授权，既有历史考核只作诊断。

开发闸门包含一个“连续可平衡而整机不可平衡”的反例、一架大需求机只能被一个足迹覆盖的例子、覆盖可行但严格列配额不可行、中心移动后原可行边失效、零需求飞机不能消失、N=200边界、修复未得解必须完整回退。20开发母中要求至少12母的软分区与整机可行问题都能在时限内结束，且至少8母的**OT+整机化+修复完整流程**比强初解得到超过1%同N全体束CV改善；同时，OT在相同整机化、修复上限及完整在线预算下须比“不用OT”对照多至少3母获得改善。三档先归母，全部方法承载均须不过共同下降容差；达不到净贡献门槛则保留“修复器有效，未见OT增益”的结果，不把它记为OT成功。此门槛专门检验连续分区是否给整机布局提供有用方向。验证集锁定参数后才可入新共同考核，不在考核集挑修复程度最轻的样本。

首轮冻结现有`variable_downstream.evaluate_layout`分配器、天线和逐机TDMA实现，全景调用费用归入各候选与修复阶段；这只是模型估计，尚非完整第二阶段学习加第三阶段连续功率优化。独立对照至少包含共同强初解、需求加权Voronoi分区＋**同一个**整机化/修复器、均匀最近中心＋同修复器、仅整数分配＋同修复器，以及OT软分区未修复的诊断行。未修复行只可展示软指标与失败，不能混入可行布局排名。与[06](06_需求约束聚类与归属重分配.md)比较时，分别说明连续松弛和整机整数分配的计算量；候选中心数、修复上限、几何实现和总时间均对齐。最终同N质量／效率门槛沿用总览：平均CV至少降5%且逐机承载平均下降不超过0.5个百分点，或CV不劣于2%、逐机承载平均下降不超过0.5个百分点且完整总时中位数减半、P95不增；两支都要求全部发布布局可行，逐景展示原提议、修复和回退、全体/正需求束CV、带内率、束数、模型估计逐机TDMA承载及耗时。可变N轨须另冻结束数成本与承载权衡，不用单一固定N质量指标选冠军。

已有[报告08的R06运输松弛与整数修复](../../实验报告/08_可变波束全覆盖与负载均衡十二路线对照.md)是本路线必须保留的历史参照：300景LP成功不等于整数化无损，报告已记录软分割、归属修复和较大的负载偏差。本篇新增同N归因、中心更新及软配额设计，尚未实施；不能把旧R06改名为新OT成果，也不能删除其失败和退步记录。既有`_transport_lp`使用线性软过载，不等于本篇建议的平方偏差与熵正则求解器，后续若实现应单独冻结版本和比较。

后续扩展角宽时，每个候选c,θ须有合法载荷范围并重算增益、干扰和真实F(c,θ)；动态业务需对时间块重配置收费，软分区随需求变化也不保证布局平滑。本篇先不声称实现。代码应另建OT软分区、整数化、几何修复三个可审计模块，复用项目Layout/射线/下游验证；短测试分别核质量守恒、每机整需求唯一归属、数值残差、真实足迹、N上限与完全回退。工作台正式接入要呈现路线08、N模式、正则/权重、迭代与修复上限、软/硬/修复阶段日志和结果，服务端校验并冻结参数；目前未改前端。依据：[Ni 等的容量约束运动聚类与OT分区](https://arxiv.org/abs/1602.08156)、[Honnaiah 等的GEO需求自适应足迹](https://orbilu.uni.lu/handle/10993/49263)及[GeoClust的可行中心思路](https://www.mdpi.com/1424-8220/26/8/2384)。Ni等以OT和幂图处理移动终端与基站容量约束，本篇的熵正则、软配额和GEO几何修复是另行提出的适配，不能写成该文原算法或已被其验证；后二者也不证明OT离散化后可行或更优。
