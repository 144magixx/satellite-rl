# 11 大邻域搜索与局部整数规划

日期：2026-10-12。状态：非学习路线的独立设计，尚未实施或获新实验预算。共同比较轨道、指标与数据划分按[专题总览](00_专题总览与共同比较约定.md)。本研究关心现有强初解是否陷在一次只改一小处的局部状态：从合法布局中拆除相邻多束，联合重建整片飞机的归属与中心，再用全景核验决定是否接受。

## 输入、动作与完整输出

输入为逐机坐标和不可拆需求、共同强初解、合法指向域、首轮0.5°全宽、冻结的真实几何和下游评价器。设当前实际波束集合为`B`，一次动作选择相邻的2–6束作为区域`R`；区域内全部飞机可以重新分配，区域外飞机、束中心与归属保持固定。区域边界若有需跨区转移的飞机，应在选择阶段把涉及的束一并纳入R，不能偷偷修改区域外而省计算。输出包括所选区域、拆前状态、局部求解的原始候选、修复记录和最终全景布局。每景所有飞机仍要唯一归属、完整覆盖，N≤200，并核所有束非空。

可变N应用轨允许区域内束数相对原来增减，但全景束数遵守上限；同束数机制轨必须在区域内保持相同实际束数。区域菜单事先固定：重载束＋相邻轻载束、两高负载相邻束、边缘覆盖困难区、随机同规模区域等。每项菜单定义候选的几何半径、最多包含束数及排序；不按某方法结果临时增补。这样[05 学习区域选择](05_学习区域选择与大邻域重建.md)未来能在**完全相同区域菜单、相同重建器和同样预算**下只替换“选哪一区”，把学习选择的作用隔离出来。每轮由当前最好完整布局通过同一确定性生成器产生最多12个区域；菜单生成规则事先冻结。不同选择历史会产生不同当前布局，因而不要求后续区域实例仍相同；只在同一状态的配对选区审计中要求区域ID、顺序和内容完全一致。

## 拆除、重建、接受

1. 从共同初解开始，每次接受完整新布局后更新每束负载、需求带内偏差、几何余量、邻接及全景承载。非AI选择器按冻结规则在菜单上打分，例如区域内最大/最小负载比、可转移边界机数和可移动中心面积；可加入均匀随机参照。仅选择区域的开销也计在线时限。
2. 原子复制完整布局，删除选中区域内束与其逐机归属，但不让中间状态作为可发布解。为区域内飞机生成合法候选束：原中心、需求重心、边界机方向及少量扰动；按真实足迹只建立覆盖关联。固定N轨约束区域束数不变；应用轨可试`k-1、k、k+1`，但不得影响全场200束上限。
3. 建局部整数问题。二元选束和逐机唯一归属同10稿，区域外负载作为常数。固定N时局部目标最小化全景负载平方和的变化，区域外平方和为常数；可变N时须重算全场CV与正需求束均值，按统一跨N规则比较，不直接沿用固定N的局部目标或临时加束数罚项；若用平方负载，应采用MIQP或共同冻结的线性分段，不把非线性平方称MILP。子问题只对所建候选池求解，限时可行解需记录gap，未得解不能宣称区域物理无解。对局部求解结果按真实中心域做小幅调整和核验，中心变了就重新核全部区域飞机。
4. 将完整候选替换到原子副本上，重算整个场景的覆盖、唯一归属、总束数、全体/正需求束CV、需求带内、资源和干扰影响。只按验证前冻结的接受规则保留新完整布局；即使局部代理改善，若全景承载明显下降或硬约束失败，也拒绝。没有可接受解、超时、中断或序列化失败时完整回退到原版，包括原中心、宽度和归属。记录每一步的选区、求解、拒绝和回退原因，避免用最终可行率掩盖大量失败提案。

首轮与05统一：只接受在冻结的全景目标与承载门槛下更优的完整可行布局，连续两次区域重建无全景改善、菜单耗尽或共同预算到达即停；05模型不另行学习STOP。失败提案也计为无改善，接受改进后计数清零。在同一当前布局下不重复已试区域，当前布局改变后由同一规则重建菜单。允许接受较差可行态或自适应扩大区域属于后续共同扩展，必须对05与11同时启用，不能作为首轮隐藏差异。ALNS的“自适应”若按搜索中的历史收益更新菜单权重，需在开发集设定更新公式和种子，不能在考核上调参。最简首轮可先固定菜单权重，以降低和学习选区的混淆。

## 建议预算与公平评价

首轮同束数轨建议最多40次区域重建提案、每次局部求解至多0.1秒、每景在线墙钟仍以共同2秒作起点；若两项上限不相容，以总时限优先，真实核验与选择器耗时都包含其中。区域大小建议2–6束、候选束每个原束最多8个、局部求解线程数与其它求解路线统一。上述数字都是短工程验证后待冻结建议，不自动构成正式计算授权。另账记录共同初解、各次选区/候选生成/求解/修复/核验、最终一次下游核验与完整总耗时，报告单次与同景多次合计、均值/中位数/P95。

公平对照至少包括共同初解、现有单步贪心、同菜单均匀随机选区、非AI规则选区，以及未来05学习选区。与05配对时，同一状态下区域菜单的身份与顺序、共享初解、局部候选生成、整数模型、求解器线程/时间、真实几何/承载核验、每景总时限都保持一致；只允许选区决策器变化。若学习模型推理使实际可执行重建次数减少，也按相同**完整总预算**比较，同时提供固定候选检查数的消融。重建器的收益不能记成学习收益。可变N轨另在验证集冻结束数与CV/承载取舍，不拿同N的CV改善直接压过较少束方案。

首轮下游统一冻结`variable_downstream.evaluate_layout`的分配器、天线与逐机TDMA版本，每次全景调用计入搜索成本。神经训练为0；非AI选区规则、区域权重及接受参数调参建议仅开发集最多6组配置、合计2小时离线墙钟，失败与重试计入，不因零训练而忽略调参成本。

开发20母正确性闸门是零已发布硬违规且任何失败都有原子回退。小例：四束排成链，第二束超载、第三束轻载，区域选2/3束后局部模型把两架边界机重分配；程序必须检查邻区1/4的干扰和所有飞机唯一归属。再造一个局部CV改善但新增中心让区域外承载下降的例子，应拒绝整步并恢复原中心、所有归属与N。若开发中至少4/20母出现配对全景CV改善且承载未显著退步，可进入固定验证；若只在局部代理改善或多数场景耗尽时间无可接受解，则停下复查目标与候选构造。正式质量/效率门槛以总览预先锁定，不能在独立考核后修改。

## 工程入口与来源

未来工作台需提供方法枚举、固定/可变N、区域菜单及顺序、区域大小、候选中心规则、局部整数目标/求解器、每提案节点/时间、全景总时限、重建次数、接受阈值和种子；服务端校验并冻结，进度展示区域尝试、局部gap、全景拒绝、回退及分段耗时。现有工作台未接入本路线；只写文档不更改前端。

[Ropke与Pisinger的ALNS（2006）](https://pubsonline.informs.org/doi/10.1287/trsc.1050.0135)提供拆除—修复和算子选择思想，原问题是带时间窗取送货，不是卫星物理。[Neighborhood based heuristics for a Two-level Hierarchical Location Problem（2011）](https://optimization-online.org/2011/05/3031/)提供设施选址局部邻域动机，不能把其容量约束直接当波束覆盖。[FlexBeamOpt（2023）](https://onlinelibrary.wiley.com/doi/10.1002/sat.1481)展示GEO布局中的启发式与整数方法组合，论文性能不直接迁移至本项目飞机场景。适用性登记见[文献附表](../../../../outputs/research/beam_coverage_routes_20261012/文献与适用边界.md)。


**统一验收补充：**本篇主比较对象固定为总览定义的同N贪心BH；与05比较只改变选区，不能同时改重建器或停止规则。 在线承载容差始终相对共同初解I0，正式均值门槛相对上述比较方；详见[共同约定](00_专题总览与共同比较约定.md#正式主比较对象)。
