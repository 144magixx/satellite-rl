# 06 需求约束聚类与归属重分配

日期：2026-10-12。状态：独立设计建议，没有新的正式训练或评价。[专题总览](00_专题总览与共同比较约定.md)规定共同初解、几何和指标。本研究从“飞机怎样分到束，才可覆盖且负载更接近”入手，交替改动逐机归属与波束中心。路线没有神经网络，不把聚类本身叫作AI成果；它可以成为学习路线的强参照或教师。与[07 足迹约束聚类](07_足迹约束聚类与中心投影.md)不同，06 的核心是**异质 Mbps 需求的不可拆分组与均衡目标**，中心更新服务于分组；07 的核心是给定分组时中心的足迹可行域。

## 变量和规划口径

输入为每架飞机的ID、地面位置、非负业务需求、卫星几何、合法0.5°全宽与共同强初解。输出为实际 N≤200 个束的中心、宽度、每机唯一归属、束负载与完整可行性记录。二元量 x_ib 表示飞机 i 是否归属束 b，L_b=Σ_i d_i x_ib；中心 c_b 是卫星可指向域内的方向。约束是每机恰归一束、归属飞机全被对应真实射线足迹覆盖、无空占位束、N上限及项目已有资源/干扰检查。先在同 N 轨固定初解实际束数，跨母场景 N 可以不同。正需求束的目标区间可取正需求束平均负载的0.8—1.2，但这只是均衡观察带，不是每束物理容量；旧600 Mbps为规划尺度，绝不能当逐束真实硬容量。零需求飞机仍必须覆盖并归属，零需求服务束及全零需求场景按共用边界规则记录。

| 步骤 | 实际计算 | 失败处理 |
| --- | --- | --- |
| 1 初始化 | 保存共同强初解的中心、归属、N及哈希；另可从需求加权聚类生成候选起点 | 新构造起点未全景可行时退回强初解，不删飞机 |
| 2 固定中心重分配 | 只列射线几何覆盖的机束边，优先尝试边界高负载飞机的单机移动与成对交换；小区域可用二元整数模型优化Σ(L_b−目标)^2的分段近似 | 任一赋值不可行则沿用旧归属；记录未改善原因 |
| 3 固定分组移中心 | 在合法指向域与覆盖交集内求需求加权单位卫星射线候选，转回地表经纬度，逐候选核真实射线覆盖，再全景评价 | 未找到合法候选、越界或承载不合格则恢复；搜索失败不等于证明交集为空 |
| 4 循环与发布 | 最多8轮、每轮不超过32次真实候选核验；两轮无全景改善或2秒在线算法预算到即停 | 仅发布全景核验过的最好布局 |

普通最小费用流适合可拆连续流或每机一单位的计数平衡。这里一架飞机的需求可能比数架之和还大，飞机又不能拆给多个束；流量松弛后四舍五入会改变 L_b，甚至造成几何或带内失败。若使用流作松弛下界，必须与整数问题使用同一目标和覆盖边；附加距离项或换用容量惩罚的流值不能直接充当CV下界。最终仍需二元归属与真实几何可行求解，报告松弛值、整数差距、修复量和耗时，不能写成“最小费用流已解决不可拆需求”。若某机需求高于带内上界，所有束均落入0.8—1.2带可能数学上不可达；“高于平均”本身还不足以证明不可达。开发闸门区分已证明下界与启发式未找到改善，质量报告不把不可达带内率当程序错误。

同N首轮以全体实际束均值 μ=Σ_i d_i/N、Q=Σ_b(L_b−μ)^2 为整数分配目标。在总需求和N固定且μ>0时，CV²=Q/(Nμ²)，因此最小化精确Q与全体束CV一致；正需求束均值只用于带内诊断，不在搜索中换目标。采用MIQP可保留Q；采用MILP则须公布共同分段断点、误差和求解间隙，发布仍重算精确CV。每束约束Σ_i x_ib≥1，避免求解后删空束使同N失效；零需求服务束不能删除。中心单独移动不改变负载CV，故固定分组时只把可行的中心候选作为联合分组更新的内部状态，完整一轮以CV改善、承载不过共同容差作为接受条件；不能一边要求每个移中心步骤CV严格改善，一边宣称中心搜索已有效。跨N时须另定束数、承载、耗时准则，不沿用固定N平方目标等价关系。

建议参数为每束最多8个最近合法可转移飞机、每轮最多16个高失衡相邻束对，局部整数问题最多64机与6束、每题0.10秒，整景真实候选核验最多256次，在线算法暂以2秒为统一起步值。这些数是可复算的搜索上限，短工程核若达不到2秒应在正式比较前对所有方法一起冻结公平时限，不能只给本法额外计算。无神经训练或教师标签预算；开发最多20母×三档×3组参数候选＝180次独立路线配置试算，计入调参成本，验证20新母选择一个冻结版本，最终新100母×三档考核。已看过的历史考核只能诊断，不再次称独立样本。

正确性小例至少含两架需求极不相等但位置相近、一个需求超过目标均值的飞机、零需求边界机、两中心射线重叠和覆盖图因移中心而变化的场景。开发闸门建议20母中至少12母可形成同 N 改善机会，且所提方法在同2秒预算中相对共同强初解至少8母的全体实际束CV下降超过1%；若几何可达性或不可拆下界说明机会不足，则保留“不适用/无改善”的记录，不能追加无上限试算。独立对照应含共同强初解、纯需求加权聚类后修复、只换归属不移中心、只移中心不换归属、相同候选数的简单贪心，并与[07](07_足迹约束聚类与中心投影.md)比较其不同目标。确保每条使用相同N、相同场景、完整几何与时间预算；可变N扩展另作应用轨，允许按事先冻结的拆合规则调N≤200并报告真实束数。

首轮冻结现有`variable_downstream.evaluate_layout`分配器、天线和逐机TDMA实现，所有新归属/中心候选的全景调用计入搜索耗时；这是模型估计评价，不是完整第二阶段学习与第三阶段连续功率优化。正式成功条件按总览同 N 质量分支：相对事前指定强参照，平均CV至少下降5%，逐机TDMA承载平均下降不超过0.5个百分点；或在CV平均不劣于2%、逐机承载平均下降不超过0.5个百分点时，完整总时中位数至少减半且P95不增。无论哪支，全部发布布局须可行，逐母三档配对展示退步，分列全部束CV、正需求束CV、需求带内率、中心链路与逐机承载、束数、初解/重分配/中心更新/最终核验/总耗时。修改指向必须全景重新估计干扰，不以局部几何合格冒充通信性能。现有[报告09](../../实验报告/09_R04引导的DRL覆盖A阶段对照.md)的均值只属于其冻结场景和方法，本路线尚无实测成绩。

代码可复用当前 Layout 和几何函数，另建需求约束分组器、受限中心更新与详细提议/修复日志；短测试核需求总和守恒、每机唯一归属、零需求边界、不可达带内、整数与松弛区别、回退后布局完全一致。正式工作台需显示路线06、N轨道、邻域与时间上限、目标口径、模型估计承载及逐步失败原因，服务端验证并冻结参数；本篇仅评估，未改页面。方法依据：[Honnaiah 等的需求自适应GEO足迹](https://orbilu.uni.lu/handle/10993/49263)、[Bennett 等的受限K均值](https://www.microsoft.com/en-us/research/publication/constrained-k-means-clustering/)及[卫星波束布局聚类与MILP研究](https://www.sciencedirect.com/science/article/pii/S0360835221001327)。这些研究的终端、形状、容量或目标不等于本项目逐机不可拆Mbps加真实射线的约束，引用支撑方法，不支撑预期收益数值。


**统一验收补充：**本篇主比较对象固定为总览定义的同N共同贪心BH；仅移动中心/仅重新分配等属于额外机制消融。 在线承载容差始终相对共同初解I0，正式均值门槛相对上述比较方；详见[共同约定](00_专题总览与共同比较约定.md#正式主比较对象)。
