# 强布局保护下的局部重构价值学习草案

2026-10-14｜S1-AI17-R9｜结果前设计v3待根接受与执行源冻结；本文件没有启动新的准备、求解、前向或训练。[机器合同v3](../../../outputs/experiments/first_stage_ai_search_20261013/design/round9_design_v3.json)明确RULE三指标保底、确定性容量流、排序、计数、特征及阶段闸门，并补齐单束特征、共同准备/方法计时和首更新证据；[v2](../../../outputs/experiments/first_stage_ai_search_20261013/design/round9_design_v2.json)与[最初草案](../../../outputs/experiments/first_stage_ai_search_20261013/design/round9_design_draft.json)原件保留。用户已授权整体持续探索，本轮仍按有限阶段和事实门槛准入，不要求再次确认相同授权。

## 从历轮证据收窄研究问题

R1证明可变N和宽度可以产生新折中点，却未在共同资源切片证明负载优势，还存在不同限时造成初始档案不同的问题。R2修复共同起点后确实找到局部改善，但固定热点重分已经覆盖同样成功集，oracle对强规则的主成本中位节省为0%，因此不训练八槽选择器。R3的有限整数补全未通过教师资格；这只否定当时的接口和预算，不证明所有整数优化无效。R4/R5显示精确分组可表达，但有错分组的修复质量仍不足。R6的异质标签成立，因统一请求要求关闭其学习后继。R7统一标签合格，实际集合模型仍19/20未完成补全。R8提供全覆盖骨架后20/20合法，但AI对同景较好对照仅2/20达到质量门槛。

这些结论不组成跨数据、跨资源的成绩排名，参见[报告12](../实验报告/12_可变束数与束宽联合搜索首轮开发对照.md)、[14](../实验报告/14_共同强初解与可变束宽重构完整开发对照.md)、[15](../实验报告/15_多宽度候选构造与整数补全先导对照.md)、[16](../实验报告/16_离散分组与共同几何修复先导对照.md)、[17](../实验报告/17_锚点域成员修复与同输入对照.md)、[18](../实验报告/18_异质请求教师标签与统一请求改制归档.md)、[20](../实验报告/20_统一请求集合模型开发评价与机制停止.md)及[21](../实验报告/21_保覆盖局部引导完整开发对照与停止.md)。下一步不再让模型直接猜整套布局，也不复用旧owner分数作同收益次序调整。拟学习的是：**在一个已知好解附近，哪个具体区域、目标束数和锚点组合值得花有限预算进行完整重构？**

R8给出额外线索：全部局部终点都消耗了更多Ω，随后53/60条D5拆分阶段触及候选上限；原RULE初始槽数却与Wenv相同。本轮据此采用“从强原点独立尝试、完整候选一次比较”的方式，避免预处理先改变公共起点和耗尽角域余量。它是新假设，不能预先认定Ω就是R8失败的原因。

## 方法选择及明确不继承的部分

局部重写和学习邻域选择已有方法基础：[NeuRewriter](https://arxiv.org/abs/1810.00337)将区域选择和改写规则交给学习策略；[Learning a Large Neighborhood Search Algorithm for Mixed Integer Programs](https://arxiv.org/abs/2107.10201)研究学习选择邻域，再由求解器完成邻域搜索。本方案只借鉴“学习决定搜索位置、确定性方法负责可行性”的分工，不移植其成绩或宣称本卫星问题已具有效率优势。

本轮选择轻量监督候选价值模型，而非重新训练一个全局owner模型或追加PPO。这样可以先用真实候选终点检验标签有没有可学差异，再用固定训练终点检验实际排序贡献。拟采用候选对的排序损失；不是学习在RULE与RANDOM两个成品间二选一。若强几何规则已经穷尽可用收益，则停止本方向，不因模型尚未训练而自动加大预算。

## 强公共起点与合法候选

每景仍用原完整飞机、稳定ID及每机21.6 Mbps；同原prepared的实际Ncap、Ωcap，不将N≤200改写为每景均可使用200束。候选都满足全部覆盖、唯一归属、整数请求守恒和全宽[0.3°,1.0°]，不调用PHY、SI、SGM或服务指标。

开发20景的Wenv、R7 RULE＋D5和T已有原件。**RULE是三项负载质量保底：Wenv、T只有在峰值、上尾、CV均不劣于同景RULE（原容差）时，才加入原点候选。** RULE自身保证集合非空；随后按峰值、上尾、CV、N、Ω、固定来源名RULE/T/Wenv的原值字典序选一个共同incumbent，记录各来源资格及历史成本，不能按后续候选效果选择原点。训练母的RULE若未曾计算，则按原RULE builder＋原D5各一次新生成并计费；失败、未发布或不合法的RULE使该母资格不完整，保留原96分母，不以T或Wenv替代RULE保底。T仅复用原有合格终点，缺失T如实标注，不能补做新T或换母。

所有候选从该同一incumbent独立出发，局部外的飞机、锚点和归属保持不变。候选失败便保留原点。发布时峰值、上尾、CV须分别不劣于原点和原RULE（原bit/s、CV容差），防止连续两次容差比较累计放宽；按同一原值字典序选较好者，完整目标相等时保留原点。原点的全布局和三项质量因此始终受保护。这是新的研究设计，不追溯更改R8终点。

候选池计划最多32项，来自最重8个非空束及各自最近邻束的具体区域，每个源束各有四个描述：单束拆成两束；相邻两束重构为两束；两束重构为三束；两束合为一束。不是只学四个算子编号，输入含当前区域的真实几何、占用、资源余量和目标结构。以稳定束ID、飞机ID解平局；缺邻居、超Ncap、成员超过128或数量不足的项保留为明确不可用槽，不靠删除困难成员满足上限，不追加替代区域。池顺序先按源负载降序、稳定ID，再按上述四类型，生成后不变。

确定性局部内核从区域成员射线均值的最近飞机及最远点规则产生目标1/2/3个同景飞机锚点，具体次序见v2合同。每个锚点飞机固定归属于自身目标束，先计入一人；剩余m−k架飞机的源边容量为1，目标剩余容量为q−1，保证全部k组非空。覆盖边采用原审计的平方弦距离及10⁻¹⁴容差；按稳定ID插入边，Edmonds–Karp按固定邻接顺序BFS增广。先检查q=m，再在ceil(m/k)…m二分整数容量并缓存成功分配，最多8次可行流调用，不额外重跑最终容量。累计残余边扫描最多1,048,576，达到计数上限记unknown，不冒充不可行。

实际归属决定外扩nextafter最小包络，中心始终是真实飞机位置。完整检查Ω、N、全宽和所有飞机身份后才能发布；即使覆盖图可匹配，真实包络或整景Ω超限也拒绝，不偷偷裁宽。它是固定锚点、强制锚点自归属下的确定性有限修复，不是区域或全局联合最优。内核、图次序、几何计数与浮点公式已在v2给出结果前唯一选择，实现与独立审核仍须在首次真实候选前冻结。

区域外不变按飞机ID→稳定beam ID的实际关系核验，原锚点、中心、宽度、成员及整数需求保持原值；删除区域束后压紧数组造成owner数字序号变化，不算实际改归属，须保存ID到新序号的映射。新束ID由case、原候选位置和锚点稳定产生，不含arm，记录原区域与新束的关系。新内核若nextafter后超过1°就拒绝，包含外扩前恰为1°的边界；原因标为保守内核的envelope_over1，不能宣称原覆盖问题数学不可行，也不借旧D5的边界分支裁成1°。新RULE获取所用的原D5行为保持不变。

本轮没有候选之后再跑D5或多轮搜索。选择候选的质量全部来自完整重构终点，因此不存在先消耗Ω再由另一过程补救而无法归因的问题。该单步试点只验证增量机制；不代表最终动态覆盖算法已完成。

候选每项至多8次容量流可行性调用、4次确定锚点候选选择、32n射线对含终审、零连续求解；图至多133节点（128飞机、3锚点、源汇）、384条飞机到锚点边，n为该景完整飞机数。**新候选池取消30秒名义中止，仅按固定工作量执行，另设原生60秒/RSS2GiB硬护栏。** 触发硬护栏使该池保留partial和费用，不能将未计算项当不可行或0收益。开发每法8项同样最多60秒硬护栏，所有实耗时间另报，不预定速度优势。原RULE获取用到的旧D5仍完整保留其原5秒名义/15秒硬规则，不在本轮改写。拟合总1000更新与30分钟GPU活动限额同时生效；未到固定终点则报告未完成，不用早停权重替代。

共同准备另设30秒硬护栏及2GiB父子RSS上限，时钟从本母输入与已完成源布局读取前开始，包含原点审核、选取、最多N(N−1)/2锚点对距离、32候选描述及24维特征，计入实际成本，绝非免费的外部几何。训练RULE获取在此前独立计费。共同产物完整并逐SHA确认后，M/L全池的60秒批次才开始；D则每法在评分/排序前启动自己的60秒批次，因此A推理也在其中。准备超时或方法硬中止均记partial、原分母保留；不能自动重跑补齐。物理总账只计一次公共准备，逐方法冷费用视图各计一次，避免遗漏或重复叠加嵌套计时。

规则对照分为两个预定、无需真实候选终点的次序：Hq按**完整场景峰值下界max(区域外最大束人数, ceil(区域人数/目标束数))**升序，再按最小必要Ω占用升序；HΩ按最小必要Ω占用升序，再按同一全景峰值下界升序。相同键都按原候选位置解平局，不以浮点epsilon重排。这里最小必要Ω只用目标束数×floor束立体角加区域外实际Ω计算，是下界，不冒充真实修复后的Ω。两法均各用8个候选预算，独立记录；主质量参照取Hq/HΩ/R三个终点中按原负载字典序较好者，属于更严格的多基线比较，不能把事后择优组合称为只花8候选的实际算法。

候选价值模型为24→64→32→1共享MLP，隐藏层ReLU；24项求解前特征及定标见机器草案，零删减、无开发归一化。Adam学习率0.001、无权重衰减，每更新64个同母严格有序候选对，最小化softplus(−较优分数＋较劣分数)，seed51001同时固定初始化与采样，1000更新不选中间最好点。标签先按有无合法改进，再按完整负载字典序；全部失败或等质的对不制造随机优劣。不得把真实终点、真实可行性、实际修复费用或T的候选标签作为在线特征。内部16母只看固定1000终点，不据此调网络或学习率；若未过则停止，不换成较好的中间模型。固定模型候选批次前向最多36次（16内部母＋20开发母），开发推理一次评分32描述、仅执行前8项。

单束1→2描述的partner人数、partner宽度及源—partner距离三项特征（第9、14、15维）固定为0；最近邻只供同源的其余三种双束描述使用。所有身份排序均用原稳定ID字符串，先检查类型和唯一性，不作数值转换、大小写变换或重复去除。模型只在M、L及F实际准入后初始化；F的第1次更新须保存实际批次、有限loss、有限非零梯度和更新前后参数变化，核实后以同一状态继续其余999步。这是既定1000的第一步，不另加工程更新或种子；架构与损失不会因内部16结果而更改。

## 反证、费用和存储

oracle只看已计算全池、是有限候选上界，不是学习模型或全局最优。M先对强规则和固定候选位置作反证：若像R2一样某个固定位置就覆盖收益，则没有证据支持该选择问题需要AI。学习后保留A对每个H和R的全部逐景差，不用只赢随机来过关；达到变化门槛也不能单独证明学会调宽。

原点中包含教师T的获取成本须披露；本阶段只回答共享高质量原点上的增量问题，不宣称能低成本从零部署。若未来移除T，需另立相同起点条件的部署研究，不能将本轮成本摊销当作已证结论。原先未知历史费用保持null，所有新准备、特征、推理、候选、审计和IO另计，不相互重复相加。

预计新标签、逐候选终点与模型新增上限512MiB，制作/传输临时上限256MiB，峰值新增768MiB，每执行盘保留至少8GiB恢复余量；实际冻结前按成员数估算并核真实所在盘。共同输入只引用原件；保存候选描述、状态、实际动作、全飞机归属、全束宽度与请求、失败及计数，静态数组只存一份、候选保存差量与恢复索引。规范位置为round9独立目录和models/runs下新模型目录，本地与获准远端各一套必要原件，校验完成后清理无用途传输镜像。若超过上限先调整存储表示并验证，不能删飞机、降指标或悄悄扩空间。
