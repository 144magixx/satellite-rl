## 3. 公共几何原语与严格计量

本轮**最终发布中心**的可执行集合是该景原飞机位置。每个束保存一个飞机锚点ID，其位置决定最终中心；锚点可以不属于该束，但必须属于同一输入景。不同束允许共用同一锚点，不能因此去重、合并或互斥。重新拟合时仅以组单位射线均值为方向，选择该组中距均值最近的飞机为新锚点，稳定飞机ID解平局。这是确定性的有限中心拟合，不称连续中心最优。指向扰动诊断允许非飞机中心的初猜和修复中间态；所有方法最终统一执行第6节的固定锚点回投，禁止以保留连续扰动中心扩大最终表达域。

给定中心和成员，宽度为max(0.3°,两倍最大真实射线夹角)，向上取一个float64可表示数并重新核覆盖；真实所需角宽超过1.0°则不合法，不裁成1.0°冒充覆盖。若原计算恰为1.0°，仅在1.0°独立覆盖核验通过时保持该边界值，不因nextafter机械溢出拒绝。射线平方弦距容差1e−14；宽度边界不放宽。需求守恒rtol=1e−12、atol=1e−6。Ω容差1e−12 sr，N无容差。负载按原单位；top10取ceil(0.1N)个最重束，CV用总体标准差/均值。

一次proposal是一个明确的整机转移、分裂、合并、重新拟合或孤立机插入候选；在构造该候选状态及核验其几何前扣账，几何不合格、空束、资源拒绝也消耗一次。公共距离缓存与INSERT排名估计不是候选状态试算，按第6节单独预扣射线/排序账，不能免费计算。一次center_refit是对一个非空成员组计算上述均值最近锚点，提前扣账；分裂采用原成员位置不暗记额外拟合。所有中心—飞机射线比较按实际数量计，排序、哈希、均值输入数、数组/RSS另记。teacher射线对最多4096n（预留最终核验n），decoder最多2048n（预留固定锚点回投包络n及最终独立核验n）；到边界不再试候选。回投不搜索中心，不消耗或增加8次refit额度。

指标接受键固定为(峰值,top10,CV,N,实际Ω)，逐项容差为1e−6、1e−6、1e−9、0、1e−12，再加1e−12相对容差。合法优化候选只有字典序严格改善才接受，不先按某一有利指标挑点。资源修复阶段另用明示的违规量减少规则，不能把未合法中间态发布。

## 4. 唯一有界教师T

教师只从Wenv开始，保留最后合法布局，执行以下固定阶段，不循环到预算耗尽、不转用未使用额度：MOVE512 → SPLIT512 → MOVE512 → MERGE240 → REFIT16 → MOVE256，合计最多2048 proposals；总center_refit≤16、30秒名义护栏。每阶段在入口快照生成候选序列，接受后仍按原序列前进，不反复从最优候选重新开始；被删束或成员已换组的过期项记skipped而不作几何计算。候选序列按需生成，不先物化O(n²)表。

- MOVE：源束按负载降序/稳定beam ID，源成员按请求降序/飞机ID，目的束按负载升序/beam ID。只移动整架飞机，源最后一机不移动；固定两束中心，重算两束包络，核所有硬约束及接受键。目的不预先仅限旧宽度覆盖，所以可扩张宽度至1.0°并消耗真实Ω。
- SPLIT：入口束按负载降序，每个至少两成员束至多试两个分法。锚点a为离当前中心最远成员，b为除a以外离a最远成员，按ID解平局。分法一先将a/b各留自身组，其余按最近a/b分组、平局取a组；分法二先各给a/b自身，其余按请求降序依次给累计请求较低组，平局取射线更近、再a组。中心为a/b位置，计算最小包络；两组非空、N及Ω合格且接受键改善才整体接受。每个分法是一proposal，不额外搜索锚点对。
- MERGE：入口束对按中心角距升序、beam ID对排序，先按需维护最多240个最近对。合并成员先后试原两个中心；每个中心试算各算一次proposal，预算合计240，不能一proposal试无限中心。合法及字典序改善才接受；合并新ID取两旧ID较小者。
- REFIT：束按负载降序/ID，至多16束各一次均值最近锚点拟合，每次同时消耗proposal和center_refit。宽度包络及所有约束通过、接受键改善才替换。

分裂新ID为`原ID/s{全局已尝试split编号}/a或b`，不以数组位置维持身份。MOVE不改ID。资源或时间达到限制返回最后独立核验的合法点，状态`bounded_complete`及截断原因；不是全局最优。每次已接受完整快照与成本保存；未知中断不得自动重做并隐去原消耗。

教师资格是合法终态、正总请求、同资源、完整来源/成本及有界过程闭合，不要求一定优于W；另设非平凡标签门槛，防止全W也进入训练。教师没改W不冒称新改善；未知中断或核验失败为`teacher_unavailable`，不得返回一个看似ready但缺字段的字典。

## 5. 提议接口与四种输入

唯一`ProposalV1`为判别联合类型。`status=ready`必须含case/input/role SHA、来源方法、K个稳定slot ID、K个同景anchor_aircraft_ID、K×3单位direction_offset（通常零）、n×K有限float32分数、n×K布尔score_mask及实际构造成本；K≤200，数组次序按固定飞机ID和slot ID绑定。`status=unavailable`只有reason/provenance/cost，不含可误读的布局数组。解码先判status再读字段；None视`unavailable_missing_payload`。SHA/角色不匹配、重复ID、NaN或形状错误是hard_error并停止本任务后继调度，不按普通无标签掩盖。

ready但K=0、K>Ncap、不可见扰动中心或全部有效分数缺失等记对应typed失败并回退Wenv；不静默截前Ncap束。上段“重复ID”仅指输入scene的飞机ID和提议slot ID各自必须唯一；`anchor_aircraft_ID`允许重复，多个query指向同一架飞机也是合法输入，不做中心互斥。教师精确和扰动都必须先有合格TeacherResult；无教师时生成两份`unavailable_teacher`结果槽、0提议/0解码科学计算，保留case分母及真实已消耗教师成本。不能把它们暗换成RULE。

四种提议固定如下，W及原始位置/请求是公共输入，教师信息只给后两种离线诊断：

| 方法 | 提议生成 |
| --- | --- |
| RULE | K=Nw，anchor为W中心对应飞机；score=−平方射线弦距，全部mask=true；分数相等先近中心再slot ID |
| RANDOM | K=Nw，从所有飞机按`SHA256(51001\|case_id\|anchor\|aircraft_id)`排序取前K；score由`SHA256(51001\|case_id\|score\|aircraft_id\|slot_id)`前8字节大端整数映射[0,1)，全部mask=true；不多随机挑最好 |
| TEACHER_EXACT | K=教师实际N，anchor及slot为教师终态，真实owner的score=1、其它=0，全部mask=true；不传教师结果作为解码捷径 |
| TEACHER_PERTURBED | 与EXACT同K、score；每slot独立固定方向扰动0.01°；恰floor(0.1n)飞机的原teacher-owner score mask置false，其他项保持；不得删飞机或拿教师真归属作修复后门 |

上表竖线是字段示意。实际哈希唯一编码为JSON数组，例如`[51001,case_id,"anchor",aircraft_id]`，UTF-8、ensure_ascii=false、无空格分隔符、原字符串不作Unicode归一化；数组第一项整数，其余字符串，不混用Python随机hash。定向扰动：原中心单位射线r，e取与r绝对内积最小的坐标轴（x/y/z顺序解平局），u=normalize(e−(e·r)r)，v=r×u；hash数组`[51001,case_id,"direction",slot_id]`首字节模4选{+u,+v,−u,−v}，r′=cosδ r+sinδ t、δ=0.01°。投到原GEO几何的近地球交点，不可见则typed失败，不能改用零扰动。mask飞机按哈希数组`[51001,case_id,"mask",aircraft_id]`排序取前floor(0.1n)。被mask的真实槽视分数不可用；其余零分平局按距中心近再slot ID，这只使用公开几何。模型日后默认offset=0，不另学连续方向扰动。

## 6. 四法共用的有界解码D

每次解码最多512 proposals、8 center_refits、2048n射线对及5秒名义护栏。提议生成/读取时间单列，并计完整成本；解码内所有初始几何、修复及核验计入5秒。固定阶段为INITIAL → RESOURCE_MERGE64 → INSERT256 → RECENTER8 → SPLIT64 → MOVE120，proposal合计512；未用阶段额度不转移。执行统一代码，不能为teacher精确输入直接拷贝终态或额外给预算。

INITIAL：中心由anchor位置和offset确定。每机在mask=true的槽中取最大score，平局按距中心角度、slot ID；无可用槽则暂列orphan。删除空槽，不修改飞机数组。将每槽内距中心>0.5°的飞机移入orphan，对余下成员算最小包络；再次删除空槽。归属初始化和包络是一次有界批处理，不按单机扣proposal，但逐射线、排序和时间全部计账。该中间态可能缺覆盖或Ω超限，不能发布。

RESOURCE_MERGE64：仅当N>Ncap或Ω>Ωcap才执行（K>Ncap已经typed拒绝，N情况保留作校验）。按教师MERGE次序与两个原中心试算；允许中间Ω仍超上限，但每次须不增加orphan且严格减少`max(0,N−Ncap)`，再`max(0,Ω−Ωcap)`，并保持所有已归属飞机覆盖/唯一性。最多64试算。资源仍超限则直接回退，不执行后续有利修复来隐藏规模失败。

INSERT256：orphan按请求降序/飞机ID处理。目的槽按该机可用score降序（masked排最后）、增量Ω升序、当前负载升序、slot ID。处理一架orphan前，仅对当前K≤Ncap个槽构造一次排名向量：从以“飞机ID＋中心实际float64坐标”为键的已计费缓存取距离；每个cache miss在计算距离前扣一射线对，逐项计rank_geometry_pairs与cache_hits。用缓存距离和各槽当前已核验包络宽度，计算`ΔΩ=Ω(max(w_b,2θ_ib,0.3°))−Ω(w_b)`，若所需宽度>1°则排名估计为+∞。这些是O(K)标量排名估计，不复制成员组、不调用完整包络/约束核验、不暗试接收状态；排序输入数K另记。缓存只在中心实际坐标相同时有效，refit/回投后不得沿用旧中心距离。排名准备也受总raypair、时间及RSS上限，到限直接保失败，不为排好序越界。

按上述固定排名逐目的实际试插入：先扣一次proposal，再构造整机归属候选、核验新包络与资源，取第一个合法目的；排名信息可复用但不免除proposal或完整合法性检查。全部现有槽尝试后仍无处，允许一个新singleton飞机中心/0.3°槽试算，消耗一次proposal，N及Ω必须合法。到256或时间/射线上限仍有orphan则回退，不额外逐机强塞；失败前成本保存。

全部飞机已归属且资源合法后，后续为与教师相同接受键的合法优化：RECENTER8对最重束作最多8个均值最近锚点拟合，SPLIT64用教师两分法，MOVE120用教师转移序列。每阶段入口快照排序；每接受点合法。随后四法统一执行`FINAL_ANCHOR_PROJECT`：不改归属，对每个存活束将中心置为其**当前记录anchor ID**的原输入位置（refit/分裂/合并时同步维护该ID），消去剩余direction_offset；原本已在anchor的束也走同一包络批处理。固定中心全量重算最小包络、实际Ω，再作独立全机核验。该步骤只应用一个既定位置，不尝试其它中心、不算新增refit或proposal；其n射线包络、n射线独立核验、中心构造、时间和RSS完整计入原decoder限额。投后所需宽度>1°、Ω超限或核验失败直接回退，**不再修复或尝试别的锚点**。

成功保存`proposal_derived`；失败返回已独立核验Wenv，标`fallback_W`及原因。保存回投前后中心、宽度、资源和状态，所有G1/G2只读取回投后的实际发布点。因此TEACHER_PERTURBED即使使用连续方向中间态，其最终分组/飞机锚点/宽度仍在所选学生可表达域，不能靠保留域外连续中心过门槛。合格ready提议若解码改成与W物理等价仍属derived但须另记`same_as_W`；几何同点和slot改名不能冒充新布局。

核心核验/序列化可以结束名义时间后完成，超时如实记录，不称5/30秒严格墙钟保证。不能为“必须返回”在后台无限修复；进程硬保护另设准备20秒、teacher45秒、decoder15秒及2GiB父子总RSS，强杀/未知状态只记录unpublished及实际/未知成本，不伪造W已发布。合法W资产存在不等于本次方法已完成发布。

## 7. B0门槛、全分母与预算

24教师及96解码结果槽预定不变。G0要求来源/操作计量正确，所有实际发布点几何/归属/需求/资源合法；全部24有W，否则停止本轮可达性分支。缺教师、普通解码失败可按如下统计保留，不套用R3的旧G2；这是不同的新合同，不能回写旧失败。

G1要求合格教师≥22/24；TEACHER_EXACT在≥22/24例非回退，且最终峰值≤教师1.02倍、上尾/CV≤1.05倍；TEACHER_PERTURBED同条件至少18/24。教师未改W可以算合法资格，但不能单独证明标签有用。

## 8. 唯一后续学习结构与建议阶段（B0不执行）

选定一个“离散启用＋锚点指针＋整机归属”集合模型，**不另训连续中心/宽度回归网**。每机10维：相对全景平均射线的3分量/1°弧度、请求份额、log(1+请求/Mbps)、16近邻角距均值与最大值/1°、16近邻请求份额和、最大单机请求份额、log(1+n)。16近邻按射线角距/稳定ID；图构建分块，不免费忽略n²距离工作量。训练归一化只用训练输入。

10→128→128 ReLU编码，三层残差近邻均值聚合（拼接自身与邻均值256→128→128），200个128维learned queries，两层4头交叉注意力＋FFN256，dropout0。每query一存在logit、一组对全部飞机的锚点pointer logits；每飞机对200query点积给归属logits。推理按存在概率≥0.5保留，超过Ncap则按概率/slot序取前Ncap，全部低于阈值则只取最大者；这是模型输出处理而非解码器默默截断输入。anchor取pointer argmax/飞机ID，offset=0，归属score为logits，mask全真。N最终仍以解码非空束计，宽度由几何包络连续决定，网络不是已证明的最优束数器。

教师slot用成员集合排序定义稳定身份但训练用Hungarian匹配：存在正标签成本−log p、成员归属平均负log概率成本、教师锚点pointer负log成本三项等权，匹配在stop-gradient成本上求；未匹配query存在目标0。总loss=存在BCE(负类权重0.1)+整机归属CE+已匹配query锚点CE，各项按自身有效计数平均、等权。教师锚点非唯一时仍用其冻结一个锚点，不用开发结果调整匹配权重。几何拟合/修复不反传，质量靠完整后端评价，不由loss下降推断。

后续建议只在原192训练母×4=768候选case上生成同一教师，不复用未经审计的R1教师。至少692/768标签合格，至少154/768在相同W资源下峰值比Wenv低≥1%且上尾/CV≤1.02倍，且实际标签中的N和逐束宽度变化均有完整例证，才训练。比例不足不重抽母或填负标签。1模型seed51001、FP32、AdamW lr3e−4/weight_decay1e−4、clip1、batch16/microbatch4×4、最多6000更新，2000机制节点包含其中；固定6000是唯一最终主模型，2000不用test选终点。

2000节点仅在冻结24开发案例作完整AI/RULE/RANDOM同修复比较：必须至少18/24非回退，且至少6/24达上述质量分支，或真实AI完整成本相对两法均满足≥20%同质量节省，才能接续至6000；失败保权重/成本、test不动。CUDA工程资格、768教师、2000节点与后续完整80验证/160test的计算预算、确切训练源码和最终统计合同须在B0后另冻结执行；本方案先选定结构与条件，不授权B0顺便启动。单seed结果不证明跨seed稳定性。
