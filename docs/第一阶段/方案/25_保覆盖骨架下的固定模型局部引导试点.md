## 研究问题与取舍

[报告20](../实验报告/20_统一请求集合模型开发评价与机制停止.md)中，固定2000更新模型在原20开发景仅1景非回退、0景达到质量门槛。此前[R4报告16](../实验报告/16_离散分组与共同几何修复先导对照.md)和[方案21](21_锚点域内归属修复与单模型验证.md)已经说明完整分组修复对提案误差敏感。[方案22](22_冻结修复器下的直接监督学习试点.md)的真实模型试点现已得到结果；本轮不再延长同一学习任务，不复演教师扰动压力试验，也不训练一个只在RULE/RANDOM中二选一的选择器。

[原20景只读诊断](../../../outputs/experiments/first_stage_ai_search_20261013/round7/learning/node2000_mechanism_diagnosis_01/root_cause_counts_and_evidence.json)显示，19次AI回退全部停在INSERT的unrepaired_orphans，未形成第一次完整合法状态Q0，且19次终点精确回退原Wenv。17景初始Ω超限后EVICT已经修复资源，随后仍有未补全孤机；原日志没有记录每次fit/legal的细分失败，因此不能断言某一个约束是唯一原因。选中query存在重复锚点，但唯一成功景反而重复最多，不能将重复数单独当根因。20份原NPZ均保存完整owner(n,200)，适合不新增前向的有界试点。

本轮只问：**已经训练的owner分数中，是否仍有可用于合法局部负载调整的结构信息？** 以已核Wenv的全部飞机归属和实际锚点为起点，保持覆盖，每步只提交经过几何与资源检查的整机转移；模型仅帮助选择相同负载收益候选的尝试次序。随后各方法各调用一次原D5。模型无需再独立猜出一套能覆盖全部飞机的锚点和分组，预测锚点或启用头本身不参与本轮决策。

这是新的“固定模型分数＋局部搜索＋D5”推理适配方法，不是原AI直出，也不是新训练成果。单机21.6 Mbps、全部飞机覆盖、唯一归属、整数需求守恒、非空N≤200、实际逐束全宽[0.3°,1.0°]及原Ncap/Ωcap均保持。预处理仅移动飞机、不增删束；最终N和宽度可由共同D5改变，但必须从实际终态报告，不用保底异宽冒充AI贡献。第一阶段不引入PHY、SI、SGM或服务目标。

## 三个同条件方法

| 方法 | 共同负载收益相同时的候选优先次序 | 所读模型信息 |
| --- | --- | --- |
| G：几何排序 | 目的锚点方向距离减来源锚点方向距离，较小优先 | 无 |
| A：AI排序 | owner共归属亲和增量，较大优先；再按G解平局 | 固定2000模型已保存full200 owner logits |
| R：固定随机排序 | 原身份和转移元组的SHA256升序；再按G解平局 | 无 |

三法从相同Wenv开始，使用相同固定候选池、负载优先级、接受规则及预算。R用于检查任意改变次序是否也能带来同样效果；不能把A对弱随机的收益单独当AI有效。原R7 RULE/D5和T结果只作探索性配对参照，不再执行，原RULE是额外的强参照。新方法有额外局部搜索，不能声称它们与原RULE具有相同总计算预算，尽管D5预算相同。

## 唯一缓存与AI分数

逐景引用原R7 AI envelope、full200 owner数组、原飞机顺序、case/shared-case/源资产身份及2000权重。全部实际NPZ形状应为n×200、float32、有限，文件与数组SHA都须闭合。只复用原20次已完成前向；本轮新增forward、参数更新、W准备和T教师均为0。缺失缓存使数据资格失败，不补前向或换子集。所有原20景保留分母。

将owner logits逐行转float64并减行最大值，按全部200个query作标准softmax，温度固定1，不截断、取top-k或调温。令p_i为飞机i的200维概率向量。对于当前实际束b，以其实际成员概率向量的算术均值mu_b定义亲和p_i·mu_b。转移i从s到d的AI次序分数为p_i·mu_d − p_i·mu_(s去掉i)；来源只有一架飞机不产生候选。去除自身项避免来源天然获得自相似优势，目的非空。该数学定义不依赖query标签，不把某个query强行配成某个W束。实际计算固定采用原缓存200列顺序；FP64归约不承诺共同置换后逐bit同分、同排序或终态等价。纯合成置换检查仅以abs(a−b)≤1e−12+1e−12×max(|a|,|b|)核数值相符，此容差不得用于候选排序、平局或科学接受。概率仅用于排序，不宣称已经校准或具有因果语义。每次接受转移后更新成员和均值；不重新运行模型。

## 有限局部候选与接受规则

先读原Wenv实际稳定beam ID、锚点、owner和宽度，完整独审。以本景全部飞机对全部W锚点的真实卫星方向角构建一次距离表；按距离及beam ID选每机最近的4个非所属目的束，不足4取实际数。初始来源至少2架、初始目的飞机数严格少于来源飞机数减1才入池；此筛选只用均匀请求下的整数负载。元组为(aircraft ID, original source beam ID, destination beam ID)，去重后按“来源人数降序、目的人数升序、目的方向距离升序、飞机ID、来源ID、目的ID”固定取前512个。池对三法完全一致，生成后永不增加；不按AI分数筛池。

每次选择前，用当前整数飞机数计算每个剩余元组在转移后的共同键(max人数,最重ceil(0.1N)束的人数之和,全束人数平方和)。本局部阶段N与总飞机数固定、每机请求相同，该精确整数键与峰值、上尾、CV的顺序等价，避免浮点误差决定是否进入次序分支。主要键完全相同才使用各法分数：G按方向角差升序；A按亲和差降序、方向角差升序；R按固定hash升序、方向角差升序；最后均按(飞机ID,来源beam ID,目的beam ID)升序。浮点分数以实际float64值排序，无round/epsilon/温度搜索。已离开原来源、来源变成单机、或负载不满足接受条件的元组置于所有有效项之后，按稳定ID排序，取出时记拒绝并消耗名额，不能暗中新增替代元组。每法最多处理128个元组，每个最多一次，最多128次实际几何尝试；不得扫描超过128后只把接受数当预算。

候选只有同时满足下列条件才提交：相对当前状态的精确整数负载键(max人数,最重ceil(0.1N)束人数和,人数平方和)严格字典序改善；转移后的上尾人数和与人数平方和均不高于起始Wenv值（无数值放宽）；来源和目的束仍非空、锚点与中心不变，真实最小包络全宽在[0.3°,1.0°]，覆盖、整景Ω及N资源均合法。使用原float64 nextafter包络规则，不截宽伪装可行。不再附加浮点峰值/上尾/CV的第二道字典序条件，Ω仅为硬资源约束，不作为局部排序或接受目标。锚点飞机不要求仍属于该束，不擅自禁止其合法转移；锚点和中心自身保持不变。一次改动失败即保留上一合法状态；到限也发布上一合法状态并标明截断。所有飞机始终有唯一owner，不建立待修孤机池。

必须澄清实现中的计数：每次从池中取出元组即占一个128候选名额，包括过期、负载拒绝和几何拒绝。每次排序对剩余池的标量负载评分另计工作量，至多512×128项；预计算射线对≤200n，整个局部阶段含初始/终末独审射线对≤512n，最后独审预留3n。无连续优化、无refit、无新锚点搜索。候选池生成最多4n元组、一次至多4n项排序；距离表至多200n个float64元素。A行softmax恰200n个exp，初始束概率和累积至多200n项，候选亲和至多2×200×512×128个乘加项，每次接受更新至多400个和向量元素，不形成n×n相似度矩阵。每法每轮负载评分至多512项、最多128轮，每项至多扫描/排序200个整数束计数；包络检查只访问已缓存的距离，至多128n项成员距离扫描，另存该读账，不能因不新算射线而不报工作量。到任何上限先停；局部初终独审的实际射线计算同样计入512n。单法局部阶段名义10秒、硬15秒、父子RSS2GiB；触及任何限制保存合法点与原因。硬终止未发布不得当正常成功。

固定随机键为SHA256对UTF-8、sort_keys=true、无空白的JSON [51001,case_id,"r8_transfer_order",aircraft_id,source_beam_id,destination_beam_id]计算的十六进制值；列表元素保持原身份字符串。无新随机种子或重复采样。

## 冻结门槛与停止条件

本轮是重复开发上的机制试点，不作独立显著性检验。以下全部成立才支持另立下一轮，而不自动训练或开放heldout：

1. 20景×3法全部来源、身份、调用及数值预算闭合；发布点全部硬约束合法，任一缺失/未发布使完整机制证据不足，不能删除该景。局部起始状态均为原Wenv，已完成旧输出不覆盖。
2. A至少15/20经D5非回退；至少5/20相对同景G/R较好终态峰值下降≥1%，上尾与CV各不超过同一参照1.02倍。参照按原峰值、上尾、CV、方法名排序，所有回退保留。
3. A对G、R分别报告全部20配对、均值、胜平负与最坏退步。原R7 RULE与T仅作描述性强参照，不进入本轮主归因或隐藏追加门槛；如新方法仍弱于原RULE，必须明确写出，不据新门槛通过称已有最优方法。
4. A至少5景实际接受了非零局部转移，且至少5景最终较原Wenv同时改变N和逐束宽度分布并存在非floor异质宽度。后者必须从实际布局核验，不能以默认字段、换ID或原Wenv异宽代替。

若三法均相同或A没有增量收益，如实说明固定模型分数未显示作用，不把合法骨架的共同收益归给AI。若合法初始提案仍频繁D5回退，则先定位后端接口/预算问题，不增加训练。门槛未过即冻结本轮、报告负结果；新假设另轮登记，不改温度、候选数、阈值、数据或预算追求过关。
