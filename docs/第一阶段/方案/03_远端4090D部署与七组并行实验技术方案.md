## 2 七个比较组与预算

| 组 | 布局与决策 | 是否训练 |
| --- | --- | --- |
| R0 | 现有需求加权覆盖规则，不微调 | 基线评价 |
| R1 | 与R0相同基础布局＋普通局部搜索 | 基线评价 |
| R2 | 与R0相同基础布局＋PPO局部微调 | PPO训练 |
| C0 | 需求加权聚类，不微调 | 基线评价 |
| C1 | 与C0相同基础布局＋同一局部搜索 | 基线评价 |
| C2 | 与C0相同基础布局＋PPO局部微调 | PPO训练 |
| P0 | 无基础布局，从空布局由PPO逐束选择中心 | PPO训练 |

三模型各409600次环境交互，总1228800次；种子51001、固定预算终点模型，不增加51002/51003。共用512并行环境、16步采集、每批8192条轨迹、小批量1024、4轮更新、学习率0.0003、gamma1、GAE0.95、clip0.2、entropy0.01、value0.5和梯度范数0.5。每模型预期50批轨迹、1600次实际优化更新，最终以实际日志核对，不套用第二阶段SAC更新数。

R/C一回合100束×2轮微调，共200步，409600交互对应2048个完整规划回合。P0从空布局一次放置一束，100步完成，共4096回合。相同交互步数不等于相同回合数或计算量，报告同时列出动作数量、候选数量、更新次数、耗时和显存。

P0的可选波位来自原始正需求航空器的全部唯一可视经纬度，稳定字典顺序；集合本身不是基础布局，PPO独立选出100个不重复中心。起始真实激活束为0，不把随机100束局部微调冒充纯PPO。数值停车坐标不参与覆盖、归属、负载或策略输入，有明确的未激活掩码。三分区最大正需求唯一位置1886，2048上限足够，无裁剪。

R2/C2对同初始化的基线评价用于检验学习贡献；P0对R2/C2是完整路线对比，必需的全局放置与局部动作、回合长度差异单列，不能把全部差值纯归因于有无基础布局。P0不存在已有波束移动，移动指标标不适用，不用数值0宣称其比微调节能或少移动。

## 3 共用输入和PPO结构

三模型共用964维输入：原508维布局/初始布局/负载及全局概要，加初始/当前激活束掩码各100维、16×16全部原始业务需求份额。P0空布局需要直接知道业务分布，故这一输入升级同时应用R2/C2。栅格和摘要是压缩信息，不宣称已给策略全部逐机信息或任意场景泛化。

共用候选打分网络：同256×256主体、候选4维编码、共享64维位置打分以及独立价值网络。候选特征为归一化位置、所在格需求份额与最近其他激活束的几何覆盖重叠近似。重叠仅是观测信息，不能当作同频干扰或实际容量。R/C每步9个局部动作，P0最多2048个候选；打分权重与参数量不随候选数增长，避免只给纯PPO更换大输出头后称单因素对照。

原始终态评分使用全部波束负载和原始需求覆盖，不调用第二阶段T-SAC的SI、SGM或回报。训练共用评分差分×0.01，gamma1保持与终态评分改善成正比例；模型选择和最终考核看独立的原始覆盖、负载与可行性，不能跨不同初始布局排名累计回报。P0无移动项，微调组保留实际移动代价并明确这项配套差异。

所有用户唯一关联、未覆盖业务和空束保留。每次动作全局重算归属和需求账；GPU float64距离缓存只更新变化列，再对完整100束判断最近归属，重置/恢复分块重建。原始需求分别直接求和覆盖/未覆盖量，避免总量减负载的浮点抵消；参数和候选特征在采样时保存，PPO更新复用原特征/掩码/动作概率。
