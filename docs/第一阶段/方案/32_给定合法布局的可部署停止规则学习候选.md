# 给定合法布局的可部署停止规则学习候选

S1-AI17-R14候选v2｜2026-10-15｜仅设计，根尚未接受执行合同。没有新数据读取、求解、拟合或评价；原R13失败与关闭预算保持。[v1原文](../../../outputs/experiments/first_stage_ai_search_20261013/design/round14_plan32_v1_published.md)保留，v2按源码预检修正审核和存储预算。

## 问题与依据

[报告26](../实验报告/26_强顺序重构的保质截断机会分析.md)发现，在12个已见开发母场景中，预定规则族的逐母事后包络可将384次历史尝试降为211次，而最早保质前缀再少35次，未达原20%额外空间门槛。这个包络需要未来教师，不能上线。本候选改问：能否从当前合法初始布局的因果特征，训练一个小树选择既定规则，并在严格保质下超过强可部署因果规则的实际处理时间？它不是挽救R13原门槛，也不宣称已发现可测加速。

在“学习规则选择”与“重训几何候选排序”两条候选中，优先选择前者。报告20/21暴露整体归属输出及旧分数局部排序的限制，报告22/23/25的有限质量选择又被强规则覆盖；继续相似候选排序仍缺新依据。报告24审核不完整不用于效能判断。新路线在数据/工程正确性通过后实际训练一个候选，不再先做一轮oracle收益筛选。

## 数据与任务边界

当前可追溯来源只有已暴露旧域，不承诺不存在的“新160母”。候选训练取Jan08原训练索引0、3、…、285共96母，校准取Jan09原训练索引288+12k（k=0…23）共24母，锁定后评价用Jan12原20母全部。140母已在项目历史研究中暴露，只有前瞻角色划分，没有独立确认资格。Jan15历史test不打开。新原始日期或合成数据须另做有限来源资格和新合同，当前确认预算0。

每母完整ID、位置及21.6 Mbps/机不变，唯一归属、请求守恒、实际非空N≤200和逐束0.3°—1.0°真实宽度保持，不用PHY/SI/SGM。140母全部新生成W/RULE/D5的合法B，各一次；旧R10只有12母B不能泛化为现成140母。B必须D5成功且独审合法，任一母缺失/回退不换母，模型前停止资格不完整的研究。

主要效率问题明确为给定合法B的改进服务：从B字节获取和验证至输出审核、必要IO与退出计时，B生成另计完整准备费用；不能把这个边界写成从原始飞机开始的总体规划加速。

## 学习、对照与真实评价

八动作固定为尝试上限0/4/8/16/32、连续未接受窗口2/4/8。AI只在起点选择一次，不改变SH-C核、候选或排序。输入为B的12个人数/负载/束宽/资源标量，禁止未来教师和母索引。训练96条完整SH-C轨迹共享八规则标签，标签操作数是代理；真正时间在新执行中测量。

拟合一次深度≤3、叶母数≥8的成本敏感小树；每叶在训练母全部保质的动作中选累计次数最少者。强基线用相同特征与训练数据，在至多2024个常量/单分叉因果表中选择全训练保质且次数最少者；不是只拿完整32步作弱基线。两策略在24校准母上只允许将失质叶/分支永久回退cap32，不重训或调阈值。

锁定后20母三臂为AI、强因果基线、完整SH-C，每臂三次新执行，同机串行、循环换序，按母中位完整请求时间比较。必须全母全重复完整可核和严格保质；强基线也须全母保质，才能宣称同质量比较。AI至少12/20母更快，累计母中位时间较强基线低至少20%，且不慢于完整SH-C。失败如实保留；全部通过仍仅是旧域开发候选，不是独立泛化或最终最优。
