# 几何约束负载重分组与可变波束实验

实验组：S1-G16；设计日期：2026-10-12。用户已授权在20424、20473并行实施至结果交付，中途不重复确认。本文件规定科学范围；实际端口、任务、冻结提交和输入SHA由主任务核验后登记。当前设计合同为候选，不能将写成方案等同于正式计算已经开始。

## 1. 研究问题和阶段边界

本研究先检验在完整几何覆盖条件下，联合调整飞机归属与波束中心能否减少热点重载，再检验学习建议是否提高同预算解的质量或达到同质量的效率。既有09的单机转移可能无法跨过需要同时交换或重分多束才能改善的局部限制；旧MLM的有限收益也不能直接归因于网络能力。先建立可改空间和教师质量的证据，随后完成新MLM的独立贡献验证。

输入只包含飞机位置、请求需求、稳定飞机ID和固定覆盖几何。全部飞机必须覆盖且唯一归属，请求需求守恒，非空有效束数不超过200，束宽固定0.5°。合法指向、覆盖角距和数值容差统一使用冻结几何内核；候选筛选与最终独立复算不得使用不同判据。不得调用下游承载、资源分配、TDMA、PHY、QoS、SI或SGM作为指标、奖励、接受条件和教师筛选条件。第一阶段不评价业务是否被满足。

旧ND12的结果和下游保护保持历史原样。本组重新运行去掉下游依赖的对照；两组的总时间不能直接用于宣称布局算法加速。本轮不扩展波束宽度学习、真实动态业务或新随机种子。

## 2. 主目标、接受和正确性

对一个非空场景，令总请求为D，非空波束数为N，束请求负载为L_b，平均负载为μ=D/N。冻结同N目标为字典序最小化：

1. P=max(L_b)/μ，即归一化峰值；
2. T=最大的ceil(0.1N)个L_b的平均值/μ，即重载上尾；
3. Q=mean((L_b/μ)^2)，即归一化二阶负载。

不用可调加权和。三分量逐级绝对容差均为1e-9；前级差在容差内才比较后级，首个超容差差值决定优劣，完全相同时不接受。每次候选相对当前完整可行解比较，另保存全程最好可行解。Q=1+CV²，CV只作为诊断和第三级信息，不能替代峰值和上尾。0需求场景单列且不进入改善率分母，不给除零目标任意常数；负需求或非有限值属于输入错误。报告同时给原单位峰值/上尾、P/T/Q/CV、N、规划耗时和候选计数。

09-CV对照保留CV严格下降（绝对容差1e-9），其余主实验均使用上述目标。临时联合重构可经过未完整分组的内部状态，但不得把它发布为解；最终须重新独立检查每机覆盖、唯一归属、所有输入ID保留、需求总量及1≤N≤min(200,飞机数)。硬约束任何一次违反均属正确性失败，相关任务修复后同ID接续，不当作科学效果差而跳过。

## 3. 输入划分和局部需求场景

先追溯旧32个空输入是原始时刻、过滤规则、几何范围还是转换造成，并保存逐层数量和原因。旧数据不按成绩换样。复用Jan08/09既有576训练母场景与Jan12的20开发母场景；加载前核实际位置、日期、过滤、ID和SHA。不把先前见过的68个非空测试母场景继续作为独立test。

新验证20母、独立考核40母，按官方可用性和非空性预定顺序读取Feb13、14、15、16。先用Feb13取验证；后续首个可用日期取test，若数量不足按顺序补足且验证/test不共享日期。每日期按UTC时刻升序、固定等间隔候选网格取样，不按任一算法负载或性能选择。根任务须在算法运行前冻结年份、候选网格、官方入口及实际划分；若四日仍不够，报告不足，不重复母样本凑数。空输入保留独立清单和过滤账，正式母场景数与实际非空数均报告。

每母输入产生四个请求需求profile，位置和飞机集合保持不变，总请求重新归一到该母原D：

| profile | 只由输入确定的变换 |
| --- | --- |
| base | 原请求需求 |
| one_hotspot | 取固定几何角距0.5°内飞机数最多的输入飞机作中心，ID打破平局；圈内需求乘4，其余乘1 |
| two_hotspots | 第一中心同上，第二中心取距其最远的输入飞机，ID打破平局；两0.5°圈并集需求乘4，其余乘1，不对重叠重复放大 |
| edge_heavy | 取距所有输入位置单位向量均值方向最远的ceil(0.05n)架飞机，按距离再ID排序；这些飞机需求乘8，其余乘1 |

归一化系数为D/变换后总需求。单位向量均值范数小于1e-12时，以最小稳定ID飞机方向作为边缘排序参考；零总需求不执行需求归一化，单列。中心仅用于定义需求，不强制算法在该处放束。单飞机、小场景、两圈重叠造成profile相同也照记，不临时替换。它们是静态局部需求异质性试验，不冒称真实时序或改变位置分布的试验。全局倍率不再单独扩成实验臂。

## 4. 同N消融与几何可达参考

每场景先由只使用位置、覆盖角距和稳定ID的纯几何可行覆盖构造得到非空束数N_geo，取N0=N_geo，并冻结初解和候选生成输入。不得使用旧600Mbps阈值、请求需求容量阈值或下游容量确定N0；几何构造超过200或未找到可行解照记，不删场景或放松覆盖。同N主矩阵保留六法：BH、07几何聚类、09-CV、09-LEX、09-SWAP、JOINT。BH和07须保留其各自真实构造机制，再按同N完整可行合同评价，不能改名为09。09-CV与09-LEX只改接受目标；09-SWAP在09-LEX上增加两机联合交换；JOINT再加入相邻2–4束联合重分和中心交替更新。每步固定按稳定ID、负载和空间距离排序并记录算子类型，不按test反馈变更菜单。联合重分候选上限与中心搜索规则须在源码冻结前写入机器合同，不用无限穷举。

在线共同预算为每景2秒且最多4096次完整候选评价，先到者停止；包含候选生成、几何检查、解码、网络推理和接受检查。统一初解生成另列但计入端到端时间。所有方法保存实际候选数、几何检查数和最佳解时间轨迹，不能将快速法补时空转。固定候选预算对照用于说明硬件争用限制，不替代实际时间账。

开发20母×4profile共80景，六法均跑。JOINT另运行一条最长30秒/61440候选轨迹，嵌套记录2秒/4096、10秒/20480、30秒/61440检查点，任一预算先到即截取对应节点；并行会影响时间检查点，必须记录当时争用。不额外执行三次相互独立搜索。参考是预算内最好可行解，不是连续指向全局最优，也不是认证最优性差距。当前首轮不增加MIP实验臂；若实现需要有限候选整数子问题，其求解计入原JOINT预算，超时返回已知可行解。

教师可达门槛：30秒参考相对09-LEX在至少20%的80开发景上，P下降至少1%；或P差不超过1e-9且T下降至少1%。前10母与后10母各自至少10%达到同条件，全部发布点硬违规为0。改善率分母为所有预定有效开发景，不只算发生改变者。保存全部确定性候选轨迹可重放最终解与接受判断，禁止靠反复试seed挑通过。未通过则不启动新MLM训练，明确“本预算下教师可改空间不足”，完成非学习和变量N部分；通过则必须继续下节训练及共同评价，不以非学习报告提前结案。

## 5. 新教师、MLM及增益识别

教师通过后，576训练母×4profile至多2304景，各用JOINT最多10秒/20480候选一次生成（候选耗尽或达到确定停止条件时提前结束，不强制耗满墙钟），单独保留初解、原候选、改进标签和几何证据；未改善样本也保留。教师总上限23040秒、47185920候选，不把多次失败重采算成新数据。可复用同输入、同冻结代码、同预算且来源闭合的记录，不重复科学计算。

训练新MLM一个，seed51001，从头训练10000次参数更新，有效batch32，microbatch4并按8次梯度累积；保持既有网络结构，输入只保留第一阶段合法字段。单次更新数、训练抽样顺序、梯度累积含义和mask种子固定保存。最终只评价第10000更新终点；2500/5000/7500只记录损失和开发诊断，不挑权重。不得悄悄使用旧MLM权重或训练不足的节点冒充终点。损失非有限等属于工程失败，可修复后恢复完整优化状态，不能以无限重训规避失败。

推理在同初解、候选池、mask问题、几何解码器及优化器中比较MLM建议、规则建议、seed51001随机建议和无学习同优化器。无学习同优化器即JOINT，复用其主矩阵记录，不再计成一套额外算法。三种建议法均服从2秒/4096总在线预算，优化器只使用剩余预算，不能只给MLM加求解时间。候选池由输入和共同初解产生，教师专有中心不能只提供给学习法。记录候选有效率、改善标签占比、关键飞机预测、联合解码可行率、接受率及相对初解变化，并分别核对预测—解码—接受损失。

预定学习效果：独立test上相对rule、random及JOINT分别报告配对P/T差和改善/退步占比。可称质量贡献须对每个对照平均P相对改善≥1%且母级配对95% bootstrap区间下界>0；若P等效（平均相对差绝对值≤0.1%），可用T同条件判定，必须注明层级。效率贡献须达到同一参考目标、成功率不低且达到目标时间中位数减少≥20%；未达目标计为删失/未达，不只比较成功者耗时。速度隔离不足则只报告观测时间。单seed不证明跨seed稳定；离线教师、训练和数据准备成本单列。

## 6. 可变N与同N热点配额

这条分支不依赖新监督模型，数据正确性通过后与教师/MLM并行。每母、每profile使用Nlow=ceil(0.8N0)、N0、Nhigh=ceil(1.2N0)，截断到[1,min(200,n)]并去重。低N不保证可行；构造失败如实列“本预算未找到”，不删边缘飞机、不称物理不可行。

在N0上增加QUOTA：将可几何合并的稀疏束合并，并联合拆分热点束，最终总N保持不变；全过程完整候选满足相同lex接受规则。在Nlow/Nhigh各保留共同目标N构造初解和QUOTA结果，QUOTA同为2秒/4096；目标N构造上限2秒/4096另账。最多新增5个结果/场景（N0配额、两个N各初解与配额）。基准N0的JOINT及初解直接复用。

画每母N—原单位峰值、上尾、CV和规划时间曲线，另画同N配额前后差。跨N时P的分母变化，不能仅据P升降选N或混排质量冠军。展示Pareto关系而不自动选满200；本轮不为达到200而扩场景或扩束。仅在共同可行的同N点配对比较，失败点和缺失点同步显示。不冻结虚构的容量阈值，不把N0附近的实测推广为整个1–200范围验证。
