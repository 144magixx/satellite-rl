## 1 研究问题与范围

在相同初解、参考目标、拆合动作和几何约束下，检验DRL是否真正产生布局改进，或以较低在线成本取得相当质量；同时区分R04示范与后续强化学习的贡献。R04作为执行器与强对照，不替代开题的DRL主线。

固定欧洲GEO几何、0.5°全宽、最多200束。每景全部飞机唯一归属并处于合法足迹内，需求守恒。第一阶段使用原R04参考过载/方差/束数目标J，600 Mbps只作规划尺度。真实承载由共同冻结分配器及原物理/TDMA核验，不能把J改善直接称为业务容量改善。

本轮只有两个正式PPO：P0目标对齐从零学习、P1先BC预热再同目标PPO，均seed51001。BC检查点是共享预热产物和非RL对照，不算第三个PPO；I0/H1/H2是非学习评价。旧S1-V10全部结果、权重、源码和已暂停跟进保持。

## 2 冻结的算法与预算条件

| 项目 | 本轮执行条件 |
| --- | --- |
| 目标 | J=参考超载平方均值＋0.1归一化负载方差＋0.02N/200 |
| 奖励 | 100×前后最好可行解J的下降；gamma=1；STOP无额外奖；无旧几何收费/拒绝/覆盖终止奖励 |
| 搜索状态 | 当前布局、最好布局/评分、候选身份、已用/剩余提交、试算、几何额度；拒绝后布局不变而预算状态更新 |
| 动作 | STOP、split、merge；当前合法解可暂时变差，发布自己的最好可行解，另存原终态 |
| 每景上限 | 32次提交、256次真实候选试算、8192几何收费；实际矩阵调用、射线对数、请求与缓存命中另账 |
| H2 | 一级保留2状态、深度2，所有分支共享真实试算账；路径最好J与STOP比较，同分短路径，预算耗尽不冒称查尽 |
| 示范 | 只用训练集，最多20000标签；最多1728个母景倍率组合×256=442368次候选试算，记录实际成本 |
| BC | 最多20轮、batch256、最多1600更新；共享终点同时用于BC对照和P1起点 |
| PPO | 两组各最多262144真实决策；65536是内部试点，不额外加算，累计上限524288 |
| PPO更新 | 32场景流×64时刻=2048决策/批；minibatch64、epochs4、lr0.0003、GAE0.95、clip0.2、entropy0.01、value0.5、max_grad_norm0.5 |
| 验证与恢复 | 每16384决策固定验证；每2048边界完整断点，场景流/菜单/缓存/RNG/优化器/预算全部可恢复 |
| 模型选择 | 预定预算终点；科学停点明确实际预算，不用独立考核挑保存节点 |

同一场景/布局/配置的缓存复用只减少真实计算，不增加虚假交互；缓存命中、原始请求和实际调用均记录。PPO推理不调用教师，也不能读所有候选精确试算结果当便宜特征。BC教师标签的离线计算和额外梯度更新与RL交互、在线推理分别计账。

短供给测试建议16个常驻CPU进程，每个持有2个场景流，主进程做批量CUDA推理/更新。每步只传动作与紧凑观测，完整流状态只在2048边界取回保存；保持32×64采样结构和更新预算不变。该选择在正式冻结前须核实际远端资源、吞吐和恢复等价；不为填满GPU新增模型、种子或无意义计算。

## 5 科学门槛与自主接续

1. 正确性先过：同初解SHA、合法覆盖、唯一归属和守恒、N上限、奖励望远镜恒等、STOP零、循环不刷分、H2共享预算、真实参数更新、终止/截断和恢复一致性。
2. 开发可达性：H1或H2在至少10/20母场景（按三倍率成组）有可测J改善；阈值用1e-8排除纯浮点噪声。未通过先诊断当前菜单与预算，不直接启动长训或称DRL原理失败。
3. 在事先由固定H1/H2验证确定的可改进子集中，若连续两个验证节点全部首步STOP且无最好解改善，该组科学停止并留完整记录。异常停/计划停与完成分开。
4. 两组分别到达65536或明确科学停止/失败终态后做机制检查，不能死等已在32768等节点科学停止者。65536的进展门槛为：至少6/20验证母场景的三倍率平均最好J相对初解下降超过1e-8，存在真实采用的非STOP动作刷新最好解，且有限值、覆盖、守恒、预算、更新和恢复检查通过。两组均无进展不补满；至少一组有进展时，另一组仅在尚未触发科学停止且正确性通过的条件下，作为必要同预算参照同ID续到原上限。已经触发连续零进展科学停止者不绕过停止；工程故障按真实断点处理。判据与审计回执保存，不热改worker或另建模型代替失败。
5. 正式结果按方案12质量或同质量效率门槛分别报告；H2强对照、逐景退步、单种子和物理假设保留，不用换指标、删失败或无限追加预算制造成功。
