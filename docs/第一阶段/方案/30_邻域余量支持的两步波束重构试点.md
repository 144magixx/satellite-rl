## 邻域支持与两个动作

在每个当前合法状态X中，以整数人数确定全部并列峰值束P，p为峰值人数，s=|P|。必须包含全部P；不截取最重几个束。支持候选j须在P外且cⱼ<p，并满足s≤30、sp+cⱼ≤128。

还须通过固定覆盖接触筛选：j的当前锚点飞机与P中至少一个锚点飞机的单位射线满足

\[
\|u_j-u_i\|^2\le4\sin^2\!\left(\frac{\operatorname{deg2rad}(0.5)}2\right)+10^{-14}.
\]

0.5°来自原允许最大1.0°全宽的半宽，沿原覆盖图数值容差，不是新物理参数。此条件保证原当前中心域存在至少一条跨峰值/支持区域的可覆盖锚点边，排除纯全局最低载但几何隔离的支持束。**它不保证重新选择锚点后的图连通、锚点自归属下全流可行、实际Ω或负载保护通过。** 这些仍由唯一内核及真实审核决定。

先筛覆盖接触，再从合格集合中按以下升序键选唯一支持束：ceil((sp+cⱼ)/(s+1))、cⱼ、到P的最小中心角距、稳定beam ID。所有键只使用动作前信息；弦长与角距共享同一已计费中心距离缓存。没有低载/域内候选时记`unsupported_no_slack_support`，有候选但无接触时记`unsupported_no_contacting_support`；保留原点和12分母，不退回v1问题、不改接触阈值重试。

令R=P∪{j}，r=s+1，m=sp+cⱼ。两动作共享同一完整区域：

| 动作 | 目标束数 | 作用 |
| --- | ---: | --- |
| J0 | k=r=s+1 | 同N联合重分，借助低载邻束余量改变成员、中心及真实宽度 |
| J1 | k=r+1=s+2 | 同一区域增一束联合重分，受Ncap、非空最小宽度Ω和质量保护约束 |

J0立即将峰值降低一架的必要人数条件为cⱼ≤p−s−1。**这只作诊断，不作剪枝。** 不满足时仍可能减少峰值重数、上尾、CV或真实Ω并改变下一步区域，允许按原保护尝试；满足时也不能证明几何可行。例如(5,5,1)有同N人数下界4，但具体位置与Ω可能阻止实现。

每一步重新确定P、接触候选与唯一支持束。不同于v1，J0可改变负载多重集和下一步成员并集，原支配证明不再直接成立；但本方案没有一个已验证的合法几何反例证明O₂必胜G，也不保证固定J1/J1不再包办收益。

## 通用核、保护与精确内部排序

原R10局部核仅支持k≤3、m≤128；新独立核保留m≤128并支持k≤32。k≤3保持旧锚点规则；k≥4按相同前3锚点继续farthest-first，以到已选锚点最小角距最大、飞机ID打平，每次只更新新增锚点的距离缓存。最终锚点稳定ID排序。BFS最小容量搜索、锚点自归属、完整成员归属保持：先求容量m，再二分ceil(m/k)…m，每核最多8流。没有新全景SSP、费用族、warm start或中心连续优化。

若k>m、目标N超过原Ncap或区域外Ω＋k个0.3°束Ω已越界，记录已知不可用，不调用核。否则计算唯一匹配、实际成员包络及外扩nextafter；超过1°或真实Ωcap便拒绝。区域外beam ID、中心、宽度与逐机归属精确不变。原三项负载保护同时比较当前X和共同B，避免累计容差放宽；合法候选还须严格改善内部目标才接受，否则保留X。没有额外D5或公共后处理。

内部排序须排列不变。设n为完整飞机数，整数非空人数为cⱼ，t=(N+9)//10，T为最大的t个整数人数之和，U=Σcⱼ²，则

\[
K=(\max c_j,\ T/t,\ N U,\ N,\Omega_{key}).
\]

T/t用整数分子/分母保存、交叉乘法比较，不先转浮点。因CV²=NU/n²−1，同n时比较NU与比较CV等价，**可变N时不能只比较U**。Ωkey先规范排序宽度，以原float64逐束Ω表达式生成各项，再对其二进制浮点整数比作精确求和；这只消除排列求和误差，不增加物理精度或改变Ω目标。相同counts/widths多重集不能因CV/Ω末位误差成为“严格改善”。真正宽度变化的Ω改善可在前四项相同后接受，但不因此算峰值命中。

节点接受、G、O₁/O₂及新Q比较使用K；显示CV/Mbps/actualΩ、硬Ω约束、当前/B保护和最终命中容差继续原定义。它是对同一目标语义的确定排序，不是以另一指标替换门槛。每节点保存counts/T/t/U/NU/Ωkey、原显示指标及保护谓词，内部值与显示值不混用。

S的旧端点和旧S2/SH-C选择不倒写；新Q排序所需精确键从S已保存的完整owner或已核整数counts推导，不能从舍入CV反解U。缺少闭合引用就资格失败，不调用旧solver或新GEO补齐。旧控制指标和命中容差仍保留原值。

## 深度二的小树、强参照与门槛

在B先做J0/J1，再在两个结果状态各做J0/J1，顺序遍历得到00、01、10、11；共享前缀最多2＋4=6核/母。拒绝时状态回到原点，等语义节点按完整状态、成员、k和新recipe引用一次已完成结果；不重复求解或随机重试。每序列使用末状态，O₂只是有限树的事后最好点，不是执行模型或全局最优。

| 参照 | 固定定义 |
| --- | --- |
| S | 旧同B的S2/SH-C按原已定字典序取较好终点，平局S2；不重跑 |
| H | 每层按动作前峰值下界、−qB超载减少、人数平方和下界、Ω下界、N、动作码选一个；qB=max(B人数)−1 |
| G | 每层看两动作真实保底终点，以K取较好者，平局J0；最多4核逻辑费用 |
| F00/F01/F10/F11 | 全母固定同一两步序列，禁止逐母换固定策略 |
| Q | S/H/G以K取较好者，完全相同按S、H、G打平 |
| O₁/O₂ | 原点及两首层终点的最好/四两步序列终点的最好；平局保原点或较小序列码 |

H的峰值下界为max(区域外最大人数,ceil(m/k))；超载减少为Σ_R max(cⱼ−qB,0)−max(m−kqB,0)；平方和下界为区域外平方和＋(k−b)a²＋b(a+1)²，其中m=ka+b。这些是人数/资源下界，不能当求解结果。H/G/F均与O₂共享新核；相对B的共同改善只记数学收益，未来AI必须相对同核强非学习参照另证增量。

命中仍要求峰值≤同一参照0.99倍，上尾/CV均不恶化，沿原绝对容差10⁻⁶ bit/s、CV 10⁻⁹及10⁻¹²相对项。全12身份、硬约束、树引用、source、预算/退出完整后，原四项门槛保持为且：O₂对S命中≥3；O₂对Q命中≥3；O₂对Q成功数减最佳固定序列对Q成功数≥3；O₂对O₁命中≥2。最佳固定序列按全12相对Q成功数择优，平局00、01、10、11。

F11必须作为强反证。若它或其它固定序列覆盖收益，停止选择学习；若两步不胜一步，停止两步分支。不得以变N、变宽或优于随机代替门槛。unsupported、拒绝、退步与unknown全部保留12分母；只有工程/科学完整时才能判限定有效负结果，unknown保持不完整。报告每母原值、配对差、最坏退步、拒绝原因和实际N/宽度，不作独立test、多种子稳定性或显著性主张。
