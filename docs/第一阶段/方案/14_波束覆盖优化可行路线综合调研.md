# 14 波束覆盖优化可行路线综合调研

日期：2026-10-12。范围：第一阶段；AI、传统优化及两者组合。性质：路线调研，**没有启动新实验**。

## 先读这一页

**还有很多路线可以走。当前最值得做的，是把可靠的覆盖优化与合适的学习模块组合起来。** 下面整理32类做法；它们包括完整算法、可组合部件和已有参照，不是32个必须训练的模型。

现有证据只说明当前PPO未取得预设优势。报告09中，BC的负载CV为0.476、模型估计逐机承载84.72%，均优于两组PPO；它是继续研究模仿学习的起点，不是所有AI路线都有效的证明。[已完成结果](../实验报告/09_R04引导的DRL覆盖A阶段对照.md)

优先看以下五种组合，按你的目标选择；排序是研究建议，不是实测排行榜。

| 你想先解决什么 | 建议组合 | 为什么值得先做 |
| --- | --- | --- |
| 找到可靠的强参照，判断到底还有多少优化空间 | **合法候选波束＋整数规划**，规模大再按需增候选（06、07） | 能把每机覆盖、归属与200束写清楚；已有直接GEO论文 |

## 所有路线共用的底线

- **覆盖是每景全部飞机覆盖，不是只覆盖一个区域或大部分需求。** 每机唯一归属、束数不超过200；求不出可行布局就如实报告，不用奖励罚项冒充保证。
- **覆盖、均衡、承载分开看。** CV低不等于通信需求满足；600 Mbps只是旧规划尺度，不是真实束容量。波束变宽后，增益和干扰也要重新算。现有承载来自冻结模型估计，逐机离轴RF未独立重算；不称实测吞吐。
- **学习输出只是提案时，要核算修复贡献。** “神经网络提出＋规则修好”要与同预算纯规则对照。GNN、Transformer是网络结构，不各算一种优化路线。
- **场景要真的变难。** 统一把全部需求乘0.75/1/1.25，只测总量变化；固定归属时CV不随同倍率缩放改变。还应设计热点迁移、需求不均和稀疏边缘，但这些测试本轮未执行。
- **200束是上限，不是现有实证。** 本组实测40–111束；112–200、可变宽度与真实动态时序仍需另验。相同GPU利用率也不是公平算法预算。

## 怎么把路线真正接成一套方法

**当前静态问题，建议先走两条主线：**

1. **纯优化主线：** 可行初解 → 找最差区域 → 多束重建／局部求解 → 覆盖与资源核验 → 只保留最好可行布局。对应09、12，必要时引入06、07作参照。
2. **AI辅助主线：** 教师示范形成网络 → 同一初解和候选 → 网络排序或挑区域 → 受约束搜索 → 同一核验器。对应15、18、19；优先回答“是否少算了还一样好”，再追求质量超越。

**宽度和动态放在明确的扩展层：** 宽度需要有载荷依据的范围/档位及天线模型；动态需要连续飞机轨迹、独立业务序列和重配置代价。先建立传统参照，再检验学习模块，不能把静态三倍率叫成动态适应。预测、温启动和滚动规划是拟移植组合，目前没有同条件GEO飞机HTS的直接实证。

不要一开始把32条全部铺开。先用少量开发场景确认：能全覆盖吗、是否还有可改进空间、算力主要花在哪里。再固定目标和预算选择少数路线；新考核集不得回流为教师标签或反复挑模型。本次已看过的独立考核只能作为历史证据。

## 哪些名字先不要追

| 名字或做法 | 为什么不单独当主线 |
| --- | --- |
| 换GNN、Transformer、扩散就算创新 | 结构或生成方式不自动解决目标不一致和硬约束；要说明它实际改变什么决策 |
| 把GA、PSO、DE等各跑一遍 | 可以作搜索家族中的参照；不要用名称数量代替不同研究机制 |
| 跳波束、预编码、阵列权重优化 | 分别解决照射时间或信号形成；只有明确连接指向/宽度/归属时才算覆盖布局路线 |
| 联邦学习、迁移学习、元学习 | 是训练/复用方式；除非真有分布变化、跨地区或数据隔离需求，否则先不增加复杂度 |
| 大模型直接在线给波束坐标 | 输出仍需几何与物理校验，稳定性和耗时依据不足；优先28的离线规则发现 |
| 量子退火等特殊硬件路线 | 仍需离散编码与大量约束处理，当前没有胜过经典强基线的本项目依据；不列首批 |
| 再换一种DRL继续堆训练量 | 原结果没有证明DRL普遍无效，但在目标、动作和评价问题未厘清前，不作为默认下一步 |

## 后续比较，只抓这几项

**先检查全部飞机覆盖与200束上限，再并列负载CV、需求带内比例、实际束数、全需求分母的逐机承载，以及SI/SGM和资源约束。** 覆盖失败景也要保留。低、中、高总需求之外，区分空间分布变化。

时间包含初解、搜索/推理、修复和最终核验，报均值、中位数及P95；离线教师、训练与调参另账。AI方法和非AI方法用同一母场景、同样的可行域；质量比较控制计算预算，速度比较控制质量。三档同母不当三个独立样本，单训练种子不当稳定性证据。

若加入第二三阶段反馈，保持“学习处理离散频率结构，数学优化处理连续功率”的分工；比较布局的作用与下游求解的作用，不能把后者全部归给第一阶段。

## 文献与调研范围

这是截至2026-10-12的**宽范围路线调研**，覆盖原始论文、出版社/作者机构页和arXiv；通过主题检索、旧方案参考文献及相邻方法追查形成。不是穷尽式系统综述，没有把搜索命中数当研究数量，也没有复算论文实验。全文可访问的核心卫星论文核到方法/约束章节，其余明确记录摘要或片段阅读；没有全文的地方不推断证明细节。

完整题名、年份、来源和阅读深度放在[文献附表](../../../outputs/research/beam_coverage_routes_20261012/文献与适用边界.md)；机器可读[路线清单](../../../outputs/research/beam_coverage_routes_20261012/route_catalog.json)、[检索范围](../../../outputs/research/beam_coverage_routes_20261012/review_protocol.json)、[核心DOI核对](../../../outputs/research/beam_coverage_routes_20261012/core_doi_verification.json)可追查。DOI登记只核身份，不证明算法适合本项目。

写作按用户要求使用短表和简明说明；采用项目写作技能和改动验证技能的纯文档分支，无前端配置变化。文献检索与证据边界检查参考了Scientific Agent Skills工作流程，方法说明及其原始引用列在附表，未把工具能力当作学术效果证据。
