# 欧洲六组实验：独立日期共同考核与状态空间对照

日期：2026-09-30。**六组40万步训练、各自终点评价，以及G07加六个新模型的七项01-18共同独立考核均已完成。** 最终结果已逐场景、逐束和逐步资源账独立复算；本报告没有新增训练、扩大预算或另选模型。

主要结论：**A在平均需求满足率、供需匹配和功率方面最有优势；B的全体基本服务比例和频率槽使用更好。四档扩展状态在本轮训练设置下均未超过G07的平均满足率，且存在明显学习不稳定；C4在四档内部的SI最高，但有SGM取舍。** 不能用一个指标把这些取舍合并成“全面最优”。

## 1. 范围、数据和模型选择

- G07为已完成参照；新增A、B、C1–C4共6组，均训练种子51001、400000次环境交互、398001次参数更新，以预先指定的40万步终点权重评价。没有增加51002/51003，没有用考核集选中途最佳节点。
- A关闭dropout；B每轮打乱训练场景；C1–C4分别开放少量全局信息、资源服务概况、全布局需求、进一步加入当前分配和干扰。保留旧奖励和联合动作掩码。
- G07/A/B为204维、13令牌。C1–C4共用2946维封装、32令牌骨干、同一结构与初始化，未开放字段归零。因此C内部可用于比较信息档位；C与G07之间还包含编码结构变化，不能全部归因于增加状态。
- 数据来自欧洲航空ADS-B位置与已保存的合成通信需求假设。训练为2024-01-08/09，固定验证为01-12，原历史考核为01-15；本轮新共同考核为此前未用于G07诊断的2024-01-18，场景集`scenes_20260929_022130_6c00e5a6`。
- 七模型在完全相同的100个冻结场景上各随机动作3次，合计2100次模型分配；固定和贪心原规则各100次，只在G07共同评价任务中执行一次。总计2300次分配；100场景×3动作不是300个独立场景，更不是3个训练种子。
- 主SI按全部100束的最终`min(容量/需求,1)`平均，包含后续干扰与未服务波束。SGM为独立的0–1匹配评分。“基本服务”指达到本束需求10%，不等于完全满足业务需求。

七评价的有序场景SHA、每束身份/位置/需求/组、模型输入文件SHA、动作重复规则均已核验；逐束SI/SGM、请求到实际分配、槽占用前缀、功率账和奖励分项均复算一致。[独立核验汇总](../../outputs/experiments/europe_ablation_20260929/analysis/final_audit/summary.json)。

## 7. 结论和下一阶段建议

1. 当前可保留A作为平均满足率、匹配和功率方向的候选基线；B作为全体基本服务和频率槽方向的候选。两者在新日期上均延续了优于G07的主要服务结果，但优势并不完全相同。
2. 扩展状态组应先解决训练稳定性，再讨论更多状态能否带来可靠收益。C4相对C1有明确SI改善，但存在匹配评分取舍；不能把C3失败直接解释成布局需求信息没有价值。
3. 后续可考虑在统一稳定设置下比较C1/C4，或单独验证关闭dropout与打乱场景的组合；这些**仅为建议，未启动、未追加预算**。本轮不追加种子，不延长表现较差组的预算。
4. 所有结论仍基于一个训练种子和一个额外日期；航空位置来自数据，通信需求依旧合成。支持的只是本实验条件下跨日期表现，不是任意业务/卫星/地区的普遍泛化。01-18被本报告使用后，后续若据此调参，应预先另定新的最终考核日期。
