# 异步采集与训练提速验证

日期：2026-09-29。**当前为核验进行中的记录，尚未宣称正式提速或切换G08。** 设计与验收口径见[设计报告](../方案/08_异步采集与训练吞吐优化设计.md)。正式六组仍使用原冻结提交继续训练。

## 当前已核验

- 异步FIFO写入、可变对象捕获、无丢行、写出屏障、I/O错误回传、队列反压、关闭超时和TensorBoard关闭线程归属通过CPU检查。
- CPU/GPU短更新中，SAC（含联合掩码）、DQN和PPO相关指标、权重、优化器、回放与随机状态逐位一致；这是工程等价检查，不是新模型效果。[原始证据](../../outputs/verification/async_telemetry_20260929/compute/update_equivalence.json)。
- G08指标/TensorBoard只读副本，旧全量读取约1.5–1.7秒，新版首次约1.56秒、后续约0.05–0.07秒；非动态诊断输出一致。这是读端提速，不能当作训练提速。[读取计时](../../outputs/verification/async_telemetry_20260929/monitoring_profile.json)。
- 原13令牌首对500更新稳态试测：原版93.969秒、仅异步88.688秒，耗时下降5.62%；权重、优化器、回放、RNG、日志和场景核对一致。**单对、存在正式作业竞争，尚不满足部署门槛。** [试测证据](../../outputs/verification/async_telemetry_20260929/bench/pilot_old13_original_vs_async.json)。
