## 1. 两个环境怎样区分

| 项目 | 中国版 | 欧洲版 |
| --- | --- | --- |
| 配置标识 | `china_legacy`，也是旧配置缺省值 | `europe_v1` |
| 环境版本 | `china_legacy_v1` | `europe_geo13_v1` |
| GEO经度 | 122.2°E | 13°E |
| 位置范围 | 原城市与原校验语义保持 | 25–80°N，40°W–50°E，且仰角至少10° |
| 地理输入归一化 | 原范围 | 独立欧洲范围，并写入模型语义 |
| 未导入数据时 | 原100城市＋随机需求 | 可见网格抽样＋随机需求，仅合成参考 |
| 资源与主要近似 | 100束、8组×100槽、默认3000 W、0.5°全宽、中心代表用户 | 同左；本次未改变奖励、学习公式、资源动作 |

欧洲卫星经度及外包范围参考调研论文，10°最小仰角是工程约定，均记录在版本化元数据；不是已经标定的真实卫星。高纬或远离星下点的部分欧洲位置会被过滤/拒绝，不能把地理矩形内所有点都当成可服务区域。

几何参数属于环境实例，中欧交错运行不会通过修改共享卫星经度相互影响。欧洲坐标、距离、干扰方向及位置归一化使用同一地区配置。为保持兼容，中国旧CSV仍沿用原全球坐标范围校验，没有新增欧洲式仰角条件。

原中国权重继续可加载；由于位置归一化等语义不同，不能给旧权重换一个欧洲标签后直接当欧洲模型。任务、场景和模型会进行地区与版本核对，跨环境成绩不直接配对。

## 2. 前端操作

1. 在“配置实验”选择“训练环境 → 欧洲版（航空业务）”。各配置页均显示此项；原默认仍是中国版。
2. 在“模型测试 → 欧洲航空场景”填写本地航空数据路径、格式、明确UTC时刻及用途（训练/验证/最终考核）。这里生成和保存数据，不会启动训练。
3. 填写参考人数、接入比例、活跃比例、每活跃用户业务速率、机载基础业务、额外波动及依据。页面初值只是工程假设，不能当作实测参数。
4. 查看场景来源和过滤结果，核对保留、过期、地面、不可服务航空器及未覆盖需求。导入仅说明文件被接受，不认证位置真实性。
5. 返回“配置实验 → 训练参数”，分别选择训练、验证与最终考核场景。列表按环境和已声明用途筛选；选择验证/考核集会同步数量。欧洲导入训练集在对应评价数量大于0时必须明确提供验证/考核集，不会默默退回原城市。
6. 配置校验通过后按批准的预算提交。任务冻结实际场景文件；浏览器关闭不会影响正式工作台的后台任务。

场景通用生成/CSV-NPZ导入也可选环境；模型详情、任务监控和评价结果显示环境标识。欧洲默认生成器只是几何/接口参考，航空研究应选取导入航空场景。

## 3. 航空输入与需求含义

首版支持：

- 航空快照CSV：`aircraft_id,timestamp,lat,lon,altitude_m`，可选`persons`；时间为带时区的UTC格式，位置为度、高度为米、人数为整数。
- ADSB.lol/readsb逐机历史`.json`或`.json.gz`：按原schema读取基准UTC秒加轨迹偏移，英尺高度换算米，过滤地面和陈旧位置标志。
- 目录按格式选择文件；一次最多1000个文件、每文件不超过100 MB、合计不超过512 MB；一次最多1000个显式时刻。原始大型归档需先解压/按日期与空域准备所需文件，不会自动下载或申请数据。

每个时刻仅使用该时刻之前、最大记录年龄范围内的最新观测，不插入未来点。相同飞机同一时刻的冲突观测拒绝处理；晚出现的无效/地面记录不会退回旧的有效飞行位置。

需求近似为：

\[
d_u=\left(N_u p_{\mathrm{access}}p_{\mathrm{active}}r_{\mathrm{person}}+r_{\mathrm{aircraft}}\right)\times10^6\quad[\mathrm{bit/s}].
\]

人数可按期望计算，也可按二项抽样；额外乘性波动可选，默认0。活跃比例只用一次，参数及随机种子完整保存。统计窗口声明其为静态平均请求速率近似，不自动创建包级业务、积压队列或跨时刻策略；改变窗口字段本身不会把同一速率当作字节重新缩放。

暂用需求加权的最远点代表位置法选100个中心，再按最近波束唯一归属；按卫星视角0.25°覆盖半径汇总，覆盖外的航空器及需求保留。最终波束需求稳定降序排列，所有物理字段同步，保留原簇身份到处理顺序映射，组别仍为处理序号%8。该规则只是过渡覆盖器，**不是开题报告第一部分DRL算法的实现或结果**。

需要至少100个能形成非空束的不同有效位置；需求为零、位置重复或有效点不足时不填假需求凑100束。覆盖聚合检查“总需求＝覆盖需求＋未覆盖需求”。每个飞机只归属一束，重叠覆盖不重复计数。

本版以地表投影计算几何，高度只用于航空筛选和记录；链路仍把每束中心作为代表用户，尚未计算每架航空器实际离轴吞吐。100个逐束动作也不对应100个真实时间点。

## 4. 场景、模型与考核隔离

- 场景记录保存环境版本、来源SHA、UTC观测/快照日期、需求参数、覆盖归属及未覆盖量。重导入工作台场景目录保留其来源，欧洲记录缺失地区元数据会拒绝。
- 提交时按train/validation/test把实际数组复制到任务内并核对SHA；恢复核对这三组来源。航空源日期和快照日期均检查交叉，跨午夜使用同一旧观测也不能绕过。
- 独立评价同时核查模型实际加载元数据中的训练/验证来源；模型登记信息过时也不能绕过日期/哈希隔离。
- 评价权重也在任务公开给调度器前冻结，防止排队期间`latest`被更新后评价另一版模型；任务内冻结文件被修改会拒绝启动。
- 旧中国配置与旧模型缺省字段继续兼容；新欧洲场景、模型和断点需要明确版本。通用CSV本身没有航空日期来源时不能自动认证其划分独立，使用者仍需保存完整来源。
