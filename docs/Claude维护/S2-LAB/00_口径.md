## 2. 数据集（`data/v1`，`s2lab/scenes.py`）

- 布局：FLOW-AO v2，单机 43.2 Mbps 下求解（每束上限 K=26、150 束预算、热点叠放），**冻结**；第二阶段只改需求。与开题"覆盖方案隔一段时间更新、资源逐时隙分配"一致。
- 场景：欧洲 ADS-B 5 分钟快照。训练 1/8、1/9、1/12（约 860 景）；开发 1/15；确认 1/18 ＋ 2/23、2/24 官方 40 景。
- 需求：每束需求 = 飞机数 × 单机需求。单机需求**在 30—80 Mbps 区间抽样**：训练每回合抽一个值；开发/确认集每景固定一个值（写在 splits.json）。
- 负载比 ρ = 总需求 ÷ (800 槽 × 25 MHz × 5.5) = 总需求 ÷ 110 Gbps。分层：ρ < 0.35 宽裕、0.35—0.6 勉强、≥ 0.6 不够。
- 开发集每档 20 景（共 60）、确认集每档 100 景（共 300）；训练抽样按 15/40/45 重采样三档。夜间场景只能落在"宽裕"档。
- 处理顺序：按需求从大到小。

## 3. 标定（决定 §1 预算与 §2 区间的依据）

本机 12 景（6 忙 6 闲）规则直出扫描（`calibration.md` 远端重跑后以远端为准）：2000 W 下容量感知贪心在忙时场景 30/45/60/80 Mbps 的满足率为 0.97/0.84/0.63/0.47，功率用满 85%—99%，干扰吃掉 1%—5%；固定分配干扰吃掉 11%—15%。取 2000 W、30—80 Mbps，使"勉强"档贪心约 0.85—0.95、"不够"档 0.45—0.65。

## 4. 评价口径（全部直出，不接第三阶段）

| 指标 | 定义 |
| --- | --- |
| SGM（主指标） | 论文公式：r=容量/需求，real = r−1（r≥1）或 1−1/r，imag=(容量−需求)/平均需求，SGM = 1−(1−e^{−|z|})³；容量 0 记 0；场景内各束等权平均 |
| 满足率 W | Σ min(容量,需求) ÷ Σ需求（业务量加权）；束平均 SI 只作参考 |
| 最差10%飞机 | 按飞机展开后最低 10% 的平均满足率 |
| 功率 | 直出总功率（W） |
| 用槽 | 总槽数、同极化重叠槽数 |
| 干扰程度 | 1 − W ÷ W(无干扰)；另报占用槽上的平均 I/N (dB) |
| 躲干扰能力 | 相邻（夹角<1°）同极化异组波束对的实际共槽数 ÷ 随机预期（c_i·c_j/100），<1 为在避让；场景内汇总 |
| 单景用时 | 批量为 1 的逐景推理秒数，同机 |

评价用确定性动作（每头取最大概率）；学习方法每种子一遍；规则一遍。配对差与 95% 区间按场景自举，按三档分别报告。

## 5. 方法与训练（`s2lab/agents.py`、`matrix.py`）

- 动作：组×起点（800 选 1）、槽数（10 选 1）、功率档 {0.5,1,2,5,10,…,50} W（13 选 1）。
- 掩码（主表）：起点只能选允许组内空闲槽；槽数 ≤ 空闲连续段且给后续每束留 1 槽；功率 ≤ 剩余预算 − 预留。无掩码副表：不限制，同组重叠者 0 槽，超预算即终止。
- 奖励（已发表）：±1（本束满足与否）＋ 本束 SGM − max(|容量−需求|−50 Mbps,0)/1 Gbps。对照 delta：场景目标 Σ(SGM+min(SI,1)) 的增量。
- SAC 核心（所有 SAC 运行共用，取自历史最好版 T-SAC）：固定温度 0.01，γ 0.99，τ 0.005，批 256，热身 2000，actor lr 1e-5，critic lr 1e-4，回放 20000，每环境步 1 次更新，梯度裁剪 10。
- 网络主体：Transformer 宽 128 / 8 头 / 2 层 / FFN 512 / ReLU / 后置 LayerNorm。
- 步数：20 万环境步（每步一个波束决策）；64 个场景并行；每 1 万步在开发集评一次，按 SGM+W 选 `policy_best.pt`。

### 实验矩阵（45 个训练运行 + 规则 + 文献）

| 组 | 运行 | 种子 | 说明 |
| --- | --- | --- | --- |
| 主表 | T-SAC（80 块令牌、自己选组）、历史最好版 T-SAC（本组 10 块令牌、贪心定组、老超参）、CNN-SAC、MLP-SAC、PPO、DQN | 3 | 全掩码 |
| 无掩码副表 | 同上五种学习方法 | 1 | 与论文协议衔接 |
| 消融 A 参数量 | d32L1、d64L2、d128L4、d128L8、d256L2、d256L4、d512L4 | 1 | d128L2 即主表 |
| 消融 B 令牌 | 每束一令牌；块指针头 | 3 | |
| 消融 C 组自由度 | %8 定组；贪心定组 | 3 | 主表为自己选组 |
| 奖励对照 | delta | 3 | |
| 规则 | 容量感知贪心、固定分配、合法随机 | — | 评价时直接跑 |
| 文献 | 模拟退火 Cocco2018、遗传 Paris2019（贪心起点，32/320 次评价） | — | `s2lab/metaheuristics.py` |

队列顺序：主表 T-SAC → 历史版 T-SAC → 奖励对照 → 其余主表 → 令牌 → 组 → 参数量 → 无掩码。
