来源：cc。口径见 [00_口径.md](00_口径.md)，全部训练运行清单见 [03_训练清单.md](03_训练清单.md)。本文件上半部分是手工维护的操作手册与阶段记录；下方"自动生成"一节由 `python scripts/s2lab/remote.py status` 刷新（每个运行的状态、步数、开发集分数、所在卡、排队器剩余时间、标定表）。

## 接手者先做三件事

1. 在 `D:\paper-s2lab`（分支 `s2lab`）执行 `& 'C:/Users/Admin/anaconda3/python.exe' scripts/s2lab/remote.py status`，看自动区：哪些运行 done / running / paused / failed，排队器还在不在（"结束"列）。
2. 看 `outputs/experiments/s2lab_20261024/window.json`：上次启动的窗口何时结束。窗口过了排队器会自己退出、训练已存盘。
3. 用户给新窗口后：`remote.py launch --window-hours <可用小时−2> --parallel 2 --keep-queue`。排队器只认领 new/paused 的运行，done 不重跑，failed 不自动重试（看 train.log 后把 status.json 的 state 改成 paused 才会重排）。

## 命令速查（本地用 base anaconda 的 python，远端口令在环境变量 BUPT_PASSWORD）

| 目的 | 命令 |
| --- | --- |
| 远端环境与进程 | `remote.py check`、`remote.py ps` |
| 同步代码（先 git commit） | `remote.py sync` |
| 建数据集 | `remote.py build-data --port 20654 --workers 16 [--extra "--dates 2024-01-15"]`，全部日期完成后 `remote.py sh --port 20654 --cmd "<PY> scripts/s2lab/build_data.py --dataset-dir ~/s2lab/data/v1 --splits-only"` |
| 标定扫描 | `remote.py calibrate --port 20654 --extra "--split dev"` |
| 启动四卡排队 | `remote.py launch --window-hours 19 --parallel 2`（首次会写 matrix.json/queue.json；续跑加 `--keep-queue`） |
| 暂停全部 | `remote.py pause`（训练先存后退，约 1 分钟内全部 paused） |
| 看进度 | `remote.py status`（刷新本文件自动区）、`remote.py tail --port P --run-id X` |
| 评价 | `remote.py evaluate --port 20654 --split confirm --extra "main-tsac-s1 main-tsac-s2 ..."`（空列表＝全部 run；规则 greedy/fixed/random 自动带上；文献方法加 `--meta sa32 sa320 ga32 ga320` 需直接用 evaluate.py） |
| 下载结果 | `remote.py fetch` → `outputs/experiments/s2lab_20261024/` |
| 训练过程图 | 每个运行结束自动生成 `runs/<run_id>/training.png`（奖励、损失、SGM、SI，滑动平均＋开发集点）；批量重画与分组开发集比较：`python scripts/s2lab/plot_runs.py --runs-dir <runs>`（远端无中文字体会自动用英文标签，正式图在本地 fetch 后重画） |
| 结果汇总 | `python scripts/s2lab/report.py --root outputs/experiments/s2lab_20261024 --split confirm` → `02_结果汇总_confirm.md` |
| 训练清单 | `python scripts/s2lab/list_matrix.py` → [03_训练清单.md](03_训练清单.md) |
