## 一、开题报告对第三阶段与全流程的承诺

| 承诺 | 原文要点 |
| --- | --- |
| 问题建模 | 给定一套固定、可行的频率分配方案，只对功率做精细优化；约束包括容量匹配率和供需匹配程度的阈值；对公平性未达标的波束再分配一次功率 |
| 方法 | 以T-SAC给出的频率与功率方案为起点，用凸优化、逐次凸近似（SCA）、加权最小均方误差（WMMSE）、凸松弛等方法求近似全局最优、收敛快的功率分配；形成"强化学习粗分配加数学优化精细调整"的两级框架 |
| 目标效果 | 在强干扰、业务不均的条件下严格满足公平性、信干噪比和容量匹配率要求；可解释、可控、收敛稳定 |
| 全流程集成仿真 | 搭建"覆盖规划—频率功率分配—功率精细优化"三阶段流程，验证整体框架的性能提升 |
| 性能对比 | 与启发式、凸优化、经典强化学习（DQN、DDPG、PPO）比较容量、信干噪比、干扰、公平性、收敛速度 |

### 3.3 可直接引用的结论

1. **"学习给初始分配、数学优化精细调功率"的两级框架已有原型并有同场景证据。**以固定温度T-SAC模型的分配为起点、固定频率槽后，逐次凸近似在3000 W下把需求满足率从89.79%提高到93.78%、供需匹配从0.708提高到0.940，每次约3.9秒；以贪心起点改进模型为起点时，优化后满足率达97.33%。
2. **连续优化的主要作用是修正"给多了"和"给少了"**，也就是第二阶段留下的供需匹配差距；需求满足率的提升相对较小，而且不是每个场景都提高。
3. **继续细调的收益已经很小：**在同一次逐次凸近似结果上再追加优化，满足率只多不到0.003个百分点，耗时却增加到1.4到2.9倍。
4. **放宽单波束功率范围是改善的一部分来源**：一半以上的波束功率超出了原来5到50 W的范围；加上实际单波束限制后的效果还没验证。
5. **"每个波束都必须达到公平性要求"还没有作为必须满足的条件来求解**，目前只有最低保护和分步目标；逐次凸近似和加权最小均方误差式方法也没有证明收敛到了最优点。

## 四、三个阶段如何衔接

### 4.1 统一要求（2026年10月13日确定）

- 所有飞机使用相同的固定请求21.6 Mbps。这个数取自原第二阶段训练数据中约60万条飞机记录的平均值；同时补回了旧数据中漏掉的2028条飞机记录，补回后平均总请求约22.49 Gbps，比旧数据高0.23%。
- 三个阶段使用同一批飞机：编号、位置、请求值都一致；第二阶段每个波束的需求必须正好等于第一阶段分给它的飞机请求之和，并承接第一阶段实际的波束编号、中心、宽度和数量（最多200个）；第三阶段承接同一布局、同一需求，以及第二阶段实际分配的频率槽和功率起点。
- 如果数据不一致，必须在训练前说明并修正，或者明确另作他用；不能用缩放、截断、删飞机、重新抽样来掩盖。

## 五、主要瓶颈与原因分析

一句话概括：**连续功率优化确实把"给多给少"的问题大幅修正了，但继续优化的收益已经很小；同时它用的功率范围比实际载荷宽松，也还没有和第一阶段真正连起来。**分六点说明：

1. **不知道还剩多少提升空间。**

   现象：在同一个优化结果上再追加一轮更精细的优化，需求满足率只多了不到千分之三个百分点，耗时却增加一倍多。

   原因：这说明在"频率槽固定不动"的前提下，单独调功率已经接近能做到的程度。但如果改动频率槽安排或换一个起点，结果可能还会更好。目前没有算过"最好能做到多少"的参照，所以不能说已经到了物理上限。

2. **平均变好了，但个别波束、个别场景仍会变差。**

   现象：平均需求满足率和供需匹配程度都提高了，但880个场景中有2个变差，第一轮实验中达到基本服务门槛（容量至少为需求的10%）的波束数也略有下降。

   原因：现在的优化目标是"先把平均需求满足率提上去，再改善供需匹配"，对每个波束只设了最低保护，没有把开题中"每个波束都必须达到公平性要求"写成硬性条件。所以只能保证平均改善，不能保证每个波束都改善。

3. **允许的功率范围比实际载荷宽松。**

   现象：优化后有一半以上的波束功率落在原来5到50 W的范围之外，最高的单个波束超过2000 W。

   原因：按照当前设定，连续功率只受总功率限制，不限制单个波束的上下限。这让优化有更大的调整余地，提升中有一部分来自"放宽了限制"而不完全来自算法。加上实际单波束功率限制后效果会如何，还不知道。

4. **分不清提升来自"好的起点"还是"好的优化方法"。**

   现象：从学习模型给出的频率安排出发再做优化，结果比从贪心规则出发更好。

   原因：没有做过"同一套频率安排、分别用规则功率和不同优化步骤"的对照，所以说不清这部分提升有多少归功于学习模型选的频率安排，有多少归功于功率优化本身。

5. **耗时比较的条件不统一。**

   现象：各方法的运行时间是在不同设备、不同并行条件下分段测出来再相加的。

   原因：这样能看出大致快慢，但不能严格回答"在同一台机器上谁更快"；模型每个场景跑三次时的总时间也要另算。

6. **三个阶段还是分别验证的，没有连成一条完整流程。**

   现象：第一阶段给出的波束数是38到111个，第二阶段模型训练时见过的是50到200个，只有部分重叠；第二、三阶段用的场景也不是第一阶段实际输出的布局。

   原因：三个阶段是先各自研究、再逐步统一接口的。接口格式已经定好并在合成例子上核对通过，但还没有用真实场景从头跑到尾。因此不能把三个阶段各自的平均提升相乘或并列，当作整个系统的效果。

## 六、后续研究方向

以下为建议，不构成实验授权。

### 6.1 中期答辩前可完成的工作

1. **在同一套频率安排上拆分各部分的贡献。**以贪心起点改进模型的频率安排为准，并列四种做法：规则给的功率、只做一次逐次凸近似、两段连续功率优化、加上实际单波束功率限制的两段优化。这样能分清学习和优化各自贡献多少，也能回答放宽功率范围的影响。
2. **补一张逐波束的公平性统计表。**对已有三轮实验和880个场景的结果，统计每个场景中满足率低于阈值的波束数、基本服务变差的场景数，让开题"严格公平"有可以核对的现状描述。
3. **估算还剩多少提升空间。**对少量场景在频率槽固定的条件下用更多计算量或多个起点求解，给出剩余空间的大小，判断第三阶段是否还值得继续改进算法。

### 6.2 论文主线方向

4. **把公平性写成必须满足的条件来求解。**以每个波束的容量匹配率或供需匹配阈值作为硬约束，用逐次凸近似或凸松弛求解，与当前分步目标比较可行比例、需求满足率、供需匹配和耗时，兑现开题的问题建模和目标。
5. **全流程集成仿真。**第一阶段真实布局→统一请求下的第二阶段分配→第三阶段功率优化，按每架飞机最终得到的服务报告覆盖情况、逐机有效承载、全部波束的需求满足率和供需匹配、基本服务、约束和全流程耗时；先核对接口数据以及波束数、宽度的范围，再做小规模同场景对比。
6. **补齐对比方法。**在相同计算量下加入更强的搜索方法；给出加上实际单波束限制后的凸优化结果；说明DDPG不适合离散动作的理由；把信干噪比和干扰水平作为补充指标输出。
7. **随时间变化的场景。**以相邻时刻的功率结果为起点，计入调整代价，检验"收敛快"在业务变化时是否成立。
8. **新日期和多随机种子。**第三阶段本身不训练，但它的起点来自只用一个随机种子训练的模型；主要结论需要在新种子模型给出的起点上复验。

### 6.3 风险与边界

- 加上实际单波束功率限制后，连续优化对供需匹配的改善可能明显缩小；届时要如实报告，并区分"算法的贡献"和"放宽范围的贡献"。
- 全流程集成依赖第一阶段恢复研究、第二阶段在统一请求下重新训练，时间上可能赶不上中期答辩；中期报告应把它写成明确的下一步，而不是已有成果。

## 七、中期报告写作建议

1. **按开题顺序论述。**研究内容保留"给定固定频率方案、只优化功率"的问题形式，补充当前的分步目标、最低保护和功率范围的更正；方法部分先写逐次凸近似，再把序列二次规划、启发式算法、加权最小均方误差式方法作为对照。
2. **把三个阶段写成一个框架，但如实标明衔接状态。**用框架图说明：第二阶段到第三阶段画实线（已有同场景对比）；第一阶段到第二阶段画虚线（接口已定义、数据格式已核对、真实场景还没连通）。
3. **分清已完成和拟开展。**已完成：固定频率槽的连续功率优化三轮、七种方法的效果和耗时、继续细调收益很小的证据、贪心起点改进模型加功率优化的同场景结果、三阶段数据格式和合成核对、统一请求要求。拟开展：公平性硬约束、实际单波束功率限制、全流程集成、更强的对比方法、随时间变化的场景。
4. **不能写的说法。**"逐次凸近似实现了近似全局最优"（应写"在有限计算量内找到的可行解"）；"严格满足公平性和信干噪比约束"（目前是分步目标加最低保护）；"三阶段系统整体提升了多少"（没有全流程数据）；"连续优化比档位调整更快"（设备和并行条件不同）；把放宽功率范围带来的改善全部归功于算法。
5. **术语对照。**开题"容量匹配率阈值、供需匹配阈值"对应当前"分步目标加基本服务保护"；"功率精细优化"对应"固定频率槽后的连续功率优化"；"粗—细两级"对应"学习负责离散安排、数学优化负责连续功率"；"全流程集成仿真"对应"三阶段同场景连通评价（待做）"。
