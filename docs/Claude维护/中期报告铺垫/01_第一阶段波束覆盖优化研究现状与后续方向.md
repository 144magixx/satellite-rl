# 第一阶段：基于DRL的自适应波束覆盖优化——研究现状与后续方向

**用途：**学位论文中期报告的铺垫材料。按[开题报告](../../资料/01_开题报告_导出1212最终版.docx)第一子课题"基于DRL的自适应波束覆盖优化算法研究"的承诺逐项对照当前证据，给出可直接引用的结果、不能宣称的边界和后续方向。

**整理日期：**2026-10-17。第一阶段研究自2026年10月15日晚起处于暂停状态，本文只整理已有正式报告，不含新实验。

**阅读约定：**每轮实验用各自的考核场景，表中数字只在同一轮内比较，不跨轮排名；所有学习方法都只用了一个训练随机种子。场景日期均为2024年ADS-B航班数据的日期。"负载离散程度"用变异系数CV表示，即各波束负载的标准差除以平均值，越小越均衡。

## 一、开题报告对第一阶段的承诺

开题报告第二至四节对第一阶段的表述可归纳为五点，后文完成度对照均以此为基准：

| 承诺 | 原文要点 |
| --- | --- |
| 问题建模 | 单颗HTS分时隙系统，波束覆盖区域内用户总业务需求为波束负载；定义负载离散度与负载均衡指标、覆盖满足率、离散波位集合；在覆盖率约束下求负载均衡的最优覆盖策略 |
| 决策变量 | 自适应调整**波束指向**与**波束宽度** |
| 算法形态 | 在灵活载荷数字处理单元部署**单智能体**，把覆盖优化建模为马尔可夫决策过程；状态含业务分布、波束覆盖和波位占用，动作含指向与宽度调整，奖励兼顾覆盖率和负载均衡；用ADS-B航空数据训练 |
| 目标效果 | 动态业务下保持全覆盖、负载均衡、干扰受控；方案稳定、鲁棒、能适应不同场景，为频率-功率分配提供均衡可控的空间基础 |
| 创新点 | 用强化学习替代几何、整数规划、聚类等静态方法，解决大规模时变环境的全局协同，并考虑频率复用与干扰 |

开题工作计划把第一阶段排在2026年1月至3月，要求"提出并实现性能更好的自适应波束覆盖优化算法"。

| 开题要素 | 当前做法 | 为什么这样改 |
| --- | --- | --- |
| 用户与需求 | 用ADS-B真实飞机位置（欧洲上空、静止轨道卫星视角），每架飞机固定请求**21.6 Mbps** | 2026年10月13日确定三个阶段必须用同一套飞机和同一请求值。21.6 Mbps取自原第二阶段训练数据中约60万条飞机记录的平均值，不是随意指定；热点由飞机扎堆自然形成 |

| 波束数量 | 实际使用的波束数可变，最多200个 | 早期固定100个；用户明确最终版本必须支持波束数可变 |
| 干扰受控 | **不在第一阶段计算**，干扰、需求满足率、供需匹配程度都放到第二、三阶段 | 2026年10月12日用户明确：业务是否被满足是第二、三阶段的事，第一阶段只管覆盖、归属、负载分配和波束数 |
| 算法形态 | 2026年10月12日起**不强求强化学习**，可用模仿学习、学习辅助搜索、学习与数学优化结合；规则方法作为起点、工具、老师和对照 | 仍须在相同条件下证明学习对布局质量或计算速度有实际贡献 |

**三个阶段之间传递的数据格式**已经定好，并在合成小例上核对通过（[第一阶段报告19](../../第一阶段/实验报告/19_统一请求教师标签与三阶段接口核验.md)）：第一阶段输出每架飞机的编号、每个波束的中心、宽度、所含飞机及需求总和；第二阶段每个波束的需求必须正好等于第一阶段分给它的飞机请求之和。

### 3.2 可直接引用的结论

1. **覆盖和均衡必须一起看。**首轮纯PPO的负载离散程度更低，却只有82个场景能覆盖所有飞机；此后所有比较都先要求全覆盖，再比较负载。
2. **规则修补和几何调整贡献了主要改善。**覆盖修补把完全覆盖的场景由35个提高到92个；热点拆分与轻载合并在波束数可变时兼顾了均衡和承载；多波束联合重分在160个案例中143个变好。
3. **学习方法有个别正例，但没有稳定胜出。**区域重构PPO在1月31日的场景上平均胜过同工具搜索，模仿学习在2月8、9日优于两种PPO；但在波束数和宽度都可变的主线上，图网络分组模型、模型引导调整、候选排序模型都没有超过强规则。
4. **当前最好的已验证方案是规则方法**：12个时刻诊断集上是强顺序结构重构，20个时刻开发集上是规则分组加几何修补。两者用的场景不同，不能互相排名，也还没有在同一批场景上正面比较。
5. **随时间变化的布局调整只试过一次**，后续时刻全部退回重新建立。宽度可变已经进入算法和老师数据（多数场景波束数和宽度都在变化），但"模型学会了调宽度"还没有证据。

## 五、主要瓶颈与原因分析

一句话概括：**现有规则方法已经把容易找到的改进都找到了，学习模型在它们之上很难再多做一点；而且我们还说不清"负载完全均衡"这个目标本身能不能达到。**下面分六点说明，详细分析见[学习收益不足的原因分析](../../第一阶段/实验报告/29_学习收益不足的原因分析与分层优化研究建议.md)和[三阶段瓶颈分析](../../资料/04_三阶段研究瓶颈与关键问题分析.md)第3节。

1. **不知道"均衡目标"到底能不能达到。**

   现象：早期设定的"主体波束负载离散程度足够小、且绝大多数波束落在合理负载范围内"这一目标，所有方法在100个考核场景里一个都没达到。

   原因：飞机位置是给定的，每架飞机的需求不能拆给两个波束，波束宽度和数量又有上限，这些条件合在一起，可能让某些场景本来就做不到完全均衡。但也可能是算法没找到好布局。目前没有对任何场景算出"最好能做到多少"的参照，所以分不清是目标太高还是方法不够好。

2. **规则方法已经很强，学习模型没有额外的信息可用。**

   现象：热点拆分、轻载合并、多波束联合重新分配飞机等规则方法，已把负载峰值和离散程度降到较低水平；在规则方法基础上再让模型挑选调整动作，几乎找不到规则方法漏掉的机会。

   原因：现在每架飞机需求相同，热点只由飞机扎堆形成，规则方法看到的信息和学习模型完全一样。学习通常在"规则想不到的复杂规律"上才有优势，而这里的规律相对简单，规则已经能抓住。

3. **模型学的东西和最终要比的东西不一致。**

   现象：让图网络模型一次性给出"哪架飞机归哪个波束"的整套方案，模型的训练误差下降了，但交给几何修补程序整理成合法布局后，20个场景里只有1个没有变差，质量上没有一个胜过规则方法；其中19个场景卡在给零散飞机补波束这一步。

   原因：模型训练时只学"模仿老师的分组"，没有直接学"最终负载峰值要低"；而一整套分组中一处出错会连带影响其他波束，修补程序只能保证合法，不能把错的分组改成好的分组。

4. **让模型做的决定太小，发挥空间有限。**

   现象：改成让模型只在规则给出的候选调整里排先后顺序，20个场景中4个变好、10个持平、6个变差。

   原因：候选范围和"是否接受这次调整"都由规则决定，模型只能排序；而且排序沿用了为另一项任务训练的打分，并非专门为这件事训练。

5. **训练是否充分说不清。**

   现象：图网络模型实际只做了2000次参数更新，原计划的后续训练没有进行；训练误差的下降比较的是不同批次数据上的值。

   原因：没有做"训练不够"还是"模型学偏了"的区分，因此目前不能说学习方法本身不行，只能说"这种训练方式在这个训练量下没有效果"。

6. **考核场景被反复使用，且只用了一个随机种子。**

   现象：同一批12个或20个场景被多轮实验拿来挑方法、调方案。

   原因：反复用来改进方法的场景已经不能再算"没见过的新场景"，在它们上面的好结果可能偏乐观；所有训练也都只用了一个随机种子，无法判断结果是否稳定。另外没有统计从头到尾的实际运行时间，也不能说某种方法更快。

**另一个需要注意的问题：**第一阶段只看"每个波束分到多少需求"，但两个需求一样大的波束，后面能分到的频率和功率可能差好几倍。所以第一阶段负载更均衡，不一定意味着用户最终得到更好的服务。要回答这一点，需要把第一阶段的真实布局交给第二、三阶段，算出每架飞机最终得到的服务，这一步还没做。

## 六、后续研究方向

以下为建议，不构成实验授权；实际执行需要用户明确恢复研究，并事先定好场景划分、计算量和判定标准。

### 6.1 中期答辩前可完成的工作

1. **做"规则打底、学习调度"的分层试验。**[第一阶段方案33](../../第一阶段/方案/33_非学习骨架与学习调度的分层优化实验设计.md)已经设计好：先用规则方法得到合法布局，再由学习模型决定下一步调整哪片区域，最后用同一套规则工具执行；与"由规则决定调整顺序"在同样计算量下比较。它直接回答"在规则方法之上，学习还能多做什么"。
2. **在少量代表场景上算出"最好能做到多少"。**对10个左右场景做限时精确求解或估计上下限，结论分为"找到满足目标的布局""证明达不到""限时内不确定"三种，为均衡目标提供参照。
3. **统一最好的规则方法。**把强顺序结构重构与规则分组加几何修补放到同一批场景上正面比较，让中期报告能给出一个明确的"当前最好规则方案"。

### 6.2 论文主线方向

4. **把学习的角色定为"决定调整顺序和何时停止"。**在合法布局上学习选择调整区域、先后顺序和停止时机（[第一阶段方案32](../../第一阶段/方案/32_给定合法布局的可部署停止规则学习候选.md)的停止规则是最简单的形式），与同样工具下的规则搜索、随机搜索比较峰值、最重一成波束平均需求、CV和耗时。
5. **为宽度学习找到真实证据。**纳入大于0.5°的宽波束，检验"调宽度"能否在同样覆盖下少用波束或降低峰值；注意第二阶段模型训练时只见过0.5°以下的宽度。
6. **随时间变化的布局调整。**从上一时刻布局出发并计入调整代价，比较每个时刻重新规划和在原布局上小幅调整；这是开题"动态业务"承诺中目前最弱的一环。
7. **三阶段连起来评价。**把第一阶段真实布局交给第二阶段分配频率、第三阶段优化功率，按每架飞机最终得到的服务评价，回答"负载更均衡能否带来更好的服务"。
8. **稳定性证据。**至少增加两个训练随机种子和新的日期；把训练、调方案和最终考核的场景分开，不再把反复用来改进的场景称为考核。

### 6.3 风险与边界

- 如果分层试验中学习调度仍然胜不过规则调度，论文应如实把第一阶段的贡献写为"满足全覆盖的可变波束数、可变宽度覆盖构造方法"，学习部分作为负结果和方法反思。
- 增加随机种子和数据会增加计算量，需要另行安排。

## 七、中期报告写作建议

1. **按开题顺序论述。**立题依据沿用开题第一节的问题提出；研究内容按"场景—变量和指标—问题模型—方法—作用"展开，把第二节的"当前做法"作为建模的更新，并说明全覆盖改为前提、负载用多项指标、统一请求值的理由。
2. **历史实验按研究问题整合，不逐轮罗列。**围绕三个问题组织：覆盖和均衡怎样一起评价（首轮覆盖规划、覆盖修补实验）；规则方法有多强（十二种方法对照、非强化学习对照、多波束联合重分、可变宽度探索）；学习在规则之上能否带来增益（区域重构PPO、规则引导的DRL、图网络与模型引导实验）。完整明细引用第一阶段综合报告和方法指标分组对比。
3. **分清已完成和拟开展。**可以写"已完成"的：问题建模、数据格式、三阶段接口、强规则方法、多轮同场景对照。只能写"拟开展"或"待验证"的：学习调度的增益、宽度学习的收益、动态调整、多随机种子、三阶段连起来的评价。
4. **不能写的说法。**"已实现基于DRL的指向与宽度自适应覆盖优化"；"强化学习优于几何或聚类方法"；不同轮次之间的CV排名；"100个场景都没达到说明目标不可达"；把只更新2000次的训练写成完整训练；把规则方法的成绩写成学习成果。
5. **术语对照。**开题"覆盖满足率"对应当前"全部飞机覆盖（前提条件）"；"负载离散度"对应"峰值需求、最重一成波束平均需求、负载CV"；"离散波位集合"对应"连续中心加宽度菜单"；"用户业务需求"对应"统一单机请求21.6 Mbps"。
