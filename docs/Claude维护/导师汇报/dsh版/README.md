## 算法实验台（19）

`19_三阶段算法实验台.html` 是独立教学页，不替代 `18_近期工作导师汇报网页.html`。它把汇报里出现的算法家族拆成 14 个可逐步播放的小实验：第一阶段 4 种布局、第二阶段 6 种频率分配/搜索算法、第三阶段 4 种功率分法。第二阶段卡片按“T-SAC 主方法、贪心＋禁忌搜索最强搜索基线”标注，避免把基线当成论文主线。小实验用固定玩具数据（36 架/6 束、7 束/3 频段、4 束/100 W），每个算法卡片底部另列“汇报里”的真实数字，避免把教学数字当实验结论。PPO 动态重排未单列，页面“口径与说明”里注明原因。

## 讲解时的一条主线

第二阶段主线不变：SAC/T-SAC 是论文主体，直出式在已发表协议下把 SGM 从 0.44 提到 0.86；压力协议下基线变强，改用"小步改进"（I0），SGM 回到 0.858、追平 320 次搜索。主指标是 SGM，满足率作辅助。第一阶段已到理论下限、学习没有空间；第三阶段只调功率、替代不了第二阶段；整条链比传统三段式高 25 个百分点。
