状态：全局上下文

s_b = (D_b, φ_b, P_rem,b, O_b, I_b; w_b, m_b)

D是本束需求，φ是位置，P_rem是剩余功率，O是频率槽占用，I是逐槽干扰；w和m分别为实验中加入的束宽与余量摘要。

动作：逐束联合选择

a_b = (f_b, n_b, p_b)，A = {a_1,…,a_N}

每次给一束选择频率起点f、连续槽数n和离散功率p，逐束构成完整方案；频率组沿用既定分组。

奖励：论文原型

论文原型：r_b = Λ_b + χ_b + Ψ_b

Λ为供需匹配，χ为容量/需求，Ψ为槽冲突、超功率等惩罚。论文原型与本轮实际训练奖励分别列出。

本轮实际训练奖励与论文原型怎样对应？
ΔS_b = Σ_{i≤b} min(C_i/D_i,1) − S_{b−1}

新动作会改变已分配波束的干扰，ΔS统计它对已处理波束累计满足程度的净影响。

r_b = R(ΔS_b) + Λ_b − max(|C_b−D_b|−50 Mbps,0)/(1 Gbps)

R在ΔS_b≥1时为+1，否则为−1。动作掩码处理冲突与剩余资源；评价统一看最终满足率和SGM。

有了第三阶段，为什么还需要第二阶段？

第三阶段把频率槽固定，只能连续调功率；它不能交换频段、改槽数或改变哪些波束共用频率。功率又会改变同频干扰，因此T-SAC先做联合折中，SCA在既定结构中细化。第二阶段学习离散联合决策与快速生成起点，第三阶段在该结构内提高精度。

相同SCA后贪心为92.5% / 0.973，改进式SAC为94.9% / 0.990，说明前面决策仍影响最终服务。是否必须用DRL、能否超过强规则，继续由同耗时对照检验。
