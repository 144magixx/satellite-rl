# 欧洲六组训练机制与状态对照

日期：2026-09-29。实验组G08，目录`outputs/experiments/europe_ablation_20260929/`。用户先要求三个方向各做实验，随后明确第三方向保留旧奖励，并扩大为多档状态；本轮共6个新模型，原G07作已有参照。用户关机暂停后已明确恢复。

**目标：分清关闭dropout、改变场景顺序和补充不同程度的状态信息，哪种更能提高需求满足率、基本服务和学习稳定性。** 各组独立从头训练，不把改动逐项累加到下一组。

## 1. 六组分别改变什么

| 组别 | 改动 | 其余关键条件 |
| --- | --- | --- |
| A 关闭dropout | dropout由0.1改为0 | 原204维/13令牌、固定场景顺序 |
| B 随机场景顺序 | 每轮576场景无放回随机排列，独立顺序种子51001 | 原204维/13令牌、dropout0.1；束内需求排序不变 |
| C1 少量全局信息 | 原信息外，只开放平均业务需求、处理进度、剩余需求 | 下述共同32令牌骨干、固定场景顺序、dropout0.1 |
| C2 资源服务概况 | C1基础上开放其余全局概况和8组资源服务汇总 | 与C1共用结构和参数量 |
| C3 完整布局需求 | C2基础上开放全部100束的位置、需求、组号和处理顺序 | 与C1共用结构和参数量 |
| C4 布局分配干扰 | C3基础上开放已执行动作、逐束当前服务、全部组逐槽占用及历史干扰 | 与C1共用结构和参数量；不输入未来动作/最终容量 |

六组均保留`legacy_repaired`旧奖励、`joint_feasible`联合掩码和最低资源预留。训练种子均51001，每组400000步，约4000回合；共240万新交互步，不增加训练种子。前2000步预热，batch256、经验池20000，策略/价值/温度学习率1e-5/1e-4/1e-4，其余参数复制G07。

A/B与G07的对照分别改变dropout或场景顺序。C1–C4内部为同结构的信息可见范围对照，初始化共有参数已逐位核验一致。**C组与G07相比还包含必要的编码结构变化，不能把跨骨干差值全部归因于信息增加。** 同种子也不意味着六组动作与经验逐步相同。

## 2. 四档状态怎样保持可比

四档都使用2946维固定封装，未开放字段严格置零；32个输入令牌由原13个、1个全局令牌、10个波束段令牌（每段10束）和8个频率组令牌组成。四档Transformer尺寸均128维、8头、2层、前馈512，每个策略网络461560参数，SAC五个网络及温度合计2307801参数。增加信息档位不会改变网络参数量。

| 内容 | 固定字段与单位 | 哪档开始可见 |
| --- | --- | --- |
| 原204维 | 当前束位置/需求、剩余功率、本组逐槽干扰与占用 | 所有档 |
| 全局10项中的前3项 | 平均需求/600 Mbps、处理进度、剩余需求/(100×600 Mbps) | C1 |
| 其余全局7项 | 剩余束数、当前组、每束可用功率、已服务平均欠供/达标比例/最低满足率、本组最长空槽 | C2 |
| 每组4项概况 | 已占比例、最长连续空槽比例、已用功率/预算、已服务束当前平均SI | C2 |
| 每束11项中的前5项 | 区域归一化纬度/经度、需求/550 Mbps、组号/7、处理序号/99 | C3 |
| 每束后6项 | 已处理标记、实际频点/99、槽数/10、功率/最高档、当前容量/600 Mbps、当前截断SI | C4 |
| 每组200项逐槽量 | 100槽真实占用、100槽在当前束视角下的历史干扰 | C4 |

字段来自动作前的环境状态。未处理波束的动作和容量为零，并带已处理标记；已服务容量包含截至当前时刻受到的干扰。终态没有“下一当前束”，当前束专属概况和潜在干扰置零。相同极化的组共用经数值核对的干扰计算。

完整布局中的未来需求属于当前场景已知业务，不是未来采样结果。C4比C1信息充分，但网络仍会压缩输入，也未模拟连续航迹和业务会话，不能称已证明数学上的完全可观测环境。

## 3. 使用什么数据和考核

- 训练：复用G07的2024-01-08/09共576场景；验证：01-12的20场景。训练数据和需求数组保持原SHA，只有B改变每轮出现顺序。
- 训练内置终点评价：统一复用01-15的100个历史比较场景，各3次随机动作，参数与G07原训练终点评价一致。该日已参与开发诊断，报告明确标“历史固定比较”，不再冒充全新考核。
- 独立考核：预先选定01-18，沿同一ADSB.lol实例、288个日内候选时刻中的均匀100个预选位置，沿用最大年龄60秒、seed51001及原合成通信需求/覆盖规则。100个预选时刻均成功，不按模型成绩筛选。
- 新原包1,663,856,640字节，SHA-256为`bf7b473755f4af70cada5aacde1980fb46734bc25105eaa2dbd6bf011b724241`。原包、100 CSV/NPZ/逐机明细的SHA、日期及需求守恒已核查；位置来自公开观测，通信需求仍为工程假设。
- 待6组固定终点权重全部形成后，G07与6个新模型在同一01-18场景集上通过工作台评价。固定/贪心规则只需在该共同场景评价一次并复用，所有方法使用一致指标。模型每场3次随机动作，报告每场均值及300次分配中的基本服务比例。

## 4. 怎样判断提升是否明显

主模型预先固定为40万步终点，不用最终考核挑最好节点。每1万步在同一20场景上验证，验证最好权重另存；12万步作诊断节点，不根据偶然高分擅自提前选模型或扩大预算。

主要比较全部100束最终需求满足率、达到本束需求10%的束数、每次100束全部达标的比例；SGM单独报告，同时报告功率、零容量、越界、裁剪和完整分配。给出相对G07及C1的逐场景配对差、改善/下降场景数和按负载分层结果。相邻航空快照有相关性，单训练种子不能证明跨种子稳定性；若不同指标有取舍，直接展示，不强行选唯一赢家。

训练曲线同时保留原值和标明窗口的平滑线，包括回报、SI、SGM、基本服务、功率/槽数，以及Critic误差、Q/目标Q、温度和梯度裁剪。新增每个断点的轻量学习快照，保存五个网络、温度和最多128条独立分层抽样经验；不含完整经验池或优化器，不改变训练随机流。由此可以在训练后检查终止TD和同权重训练/评估态差异，避免只能看到最后一个Critic。
