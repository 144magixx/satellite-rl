## 历史模型的保留原则与下一批候选

中间检查点并非必须全部常驻。可以优先清理已经完整归档、不用于正式模型选择或科学复核、也不承担当前续训的普通中间权重副本。清理时保留指标日志、来源、模型选择记录和可恢复的原始归档。

必须保留可访问、可核验的版本：

1. 论文正式成绩使用的终点或验证集所选模型及其配置、来源记录。
2. 被单独用作历史对照的中间节点。例如报告12中的J0/J1 150000步快照，不能因它们不是训练终点而丢弃唯一副本。
3. 用户指定的G11 T0 150000步终点，第三阶段已用它提供初始分配。
4. 当前训练的完整续训状态，包括网络、优化器、经验池及随机状态；仅有推理策略权重不能替代完整续训断点。
5. 支撑修复前后、失败或迁移来源结论的关键历史断点。
6. 用于未训练起点对照的初始模型；普通初始快照是否可清理须按用途核定。

本地旧工作台8组 `learning_snapshots` 共313个权重、3.764 GB。其中6组在历史状态记录中为completed，共3.117 GB；排除其初始和最终节点后有237个普通中间快照、约2.981 GB。这是候选规模，不是已经批准可删的数量：尚须逐文件核归档覆盖及科学引用，另外两组stopped的关键节点不能默认删除。状态文件的历史记录不替代当前远端API状态。
