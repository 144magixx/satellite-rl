# 19 超越贪心的频率槽局部改进与学习排序方案

日期：2026-10-07。研究编号：**S2-P19（建议，尚未执行）**。

本方案回应“综合调研下一步怎么做，目标要超过贪心”。依据包括现有源码、冻结实验的原始结果和十篇相关一手论文。**推荐主线是：保留贪心初解，先验证频率槽局部调整是否有改善空间，再训练模型选择最值得做功率细调的候选。** 首轮采用监督排序学习；PPO/从零SAC重训作为后续条件路线，未纳入本轮预算。本次只完成调研、保存结果复算与方案，未连接远端、实现算法、启动训练或新评价。

## 1. 目标与当前事实

### 1.1 “超过贪心”分清三件事

1. **直接分配胜出**：新方法产生的离散分配，与同场景贪心直接分配比较。
2. **完整方法胜出（本方案主目标）**：新方法＋固定第三阶段功率细调，与贪心＋同一功率细调比较。不能再用模型＋SCA比较未细调贪心。
3. **模型有贡献**：在相同候选池、完整细调调用上限和实际时间条件下，学习选择超过规则选择。只赢原贪心而输同预算非学习搜索，只能说明局部搜索有效，不能宣称学习有效。

主目标是全部目标波束的最终平均需求满足率SI；SGM、基本服务、有效承载、可行性和时间一起报告。不是以多占频率槽、累计训练回报或总容量代替SI。本方案接受“带学习的混合优化方法”这一研究定位；若只达第2项，不写成单次神经网络直接分配已胜出。

### 1.3 代码所支持的机制，及尚未证实的部分

- **贪心不是逐候选搜索最终SI。** 场景按需求降序排列；规则选跨组占用较少的频率起点，请求1–5槽，按需求阈值给20/25/30 W，再经共同合法动作投影。不能把它描述成求出了最优频率方案。见[greedy.py](../../../src/satellite_rl/baselines/greedy.py)、[工作台基线适配](../../../src/satellite_rl/workbench/baselines.py)。
- **现有SCA锁定频率起点和槽数。** 因此它能修正功率，却不能把已分错位置的槽重新安排。见[固定槽核验](../../../src/satellite_rl/power_refinement/runner.py)。这支持研究频率布局，但没有证明频率是唯一瓶颈。
- **旧逐束奖励不等于最终全束SI。** 它混合逐束阈值、供需匹配与占槽惩罚；后来干扰会改变先前波束的终值。V2增加吞吐/频谱奖励也不是把目标直接改成最终SI。见[奖励与状态实现](../../../src/satellite_rl/workbench/environment.py)。
- **G0不是显式干扰图模型。** 它已包含逐束几何、需求和分配上下文，但未显式编码每对波束的物理干扰关系。已有G11固定100束图组件带来0.615百分点SI改善，属于相关证据，不能外推为本轮变束数必胜。见[报告12](../实验报告/12_温度记忆与干扰图独立场景对照.md)。
- **“优先高需求”“槽越多越好”都不是SI目标的充分条件。** 在未封顶时，每增加单位容量对平均SI的直接贡献是1/(N×该束需求)，还要扣除对其它束的干扰损失。因此必须核全部目标束，不能只凭需求排序或总槽数推断正确方向。

代码行号、实际冻结参数与推测的区分见[本地实现审计](../../../outputs/verification/s2p19_research_20261007/local_audit.md)。

## 3. 推荐算法：贪心初解＋局部频率槽改进＋候选排序

### 3.1 首轮限定为一次候选选择

每个场景先生成原B1合法初解，保存不可修改的副本。由固定候选生成器提出至多16个**互异、完整、合法**的频率方案。模型给候选排序，只把前3个送入原有完整B路线；另对原B1做一次相同B细调。最终在这至多4个真实结果中选择通过共同保护条件且SI最高者，保留原B1＋B作为回退。

首轮只有一次局部候选选择，不在测试中反复重采样、重新生成候选或无限迭代。这样能固定开销，也避免“只在贪心状态训练，却在多轮自己修改后的状态使用”的分布偏移。后续多轮改进须另有轨迹数据和预算。

保留初解只能在**同一已核验物理场景、同一真实评价规则**下保证返回值在规定数值容差内不劣于该基准，不能保证严格改善、全局最优、真实世界性能或同样时延。严格超过仍由第6节判据按保存原值检验。

### 3.2 候选做哪些改变

固定波束ID、需求、位置、宽度、排序、复用组、总功率和物理公式；不改变第一阶段布局。

| 操作 | 怎样调整 | 需要核验 |
| --- | --- | --- |
| 移动连续块 | 长度不变，把某束的频率起点移到本组其它合法空档 | 对其它组的同槽干扰可能改变，须全束重算 |
| 相邻块边界移动 | 同组相邻两束之间转移1槽，保持各自连续 | 每束仍满足原1–10槽边界，组内无重叠 |
| 同组块交换/小窗口重划 | 联合释放2–4束的连续块，在原窗口内重新安排其起点和长度 | 先释放再原子提交；失败完整回滚，不能依次裁剪破坏意图 |
| 局部长度再分配 | 有空槽时增减1槽，必要时连同同组供给方一起移动 | 不增加100槽/组预算，不用非法扩宽获得收益 |

N=200贪心可能已用完8组共800槽，所以**必须包含联合释放与重排**；单束“找空位再加一槽”可能根本没有动作。跨组干扰仍统一计算，不能把8组当成物理上独立问题。

候选生成采用固定配额（每类至多4个），按欠服务程度、潜在干扰、组内相邻关系及固定种子53001的覆盖项选取；排序、去重与并列处理在开发闸门前冻结。不足16个就记实际数，不复制初解凑数；全无候选返回B1。候选ID由场景、操作、束ID、实际动作及配置哈希确定。

候选的**直接分配功率保留B1对应束的离散功率**，频率调整后按新槽数重新计算功率谱密度与全束容量。第三阶段才允许非负连续整束功率、仅总功率≤3000 W、空槽束为0；不增添5 W下限或50 W上限。若将来加入离散功率动作，属于另一个处理因素，本轮不混入。

### 3.3 模型学什么

训练样本为“场景＋B1初解＋一个合法候选”。离线对候选执行完整B，保存其相对B1＋B的**实际最终SI变化**、SGM、基本服务、最差束及可行性。用于排序的标签按第3.4节同一保护谓词生成：合格候选使用实际SI增益，被拒候选单独标记为不可接受，不让它以较高原始SI赢得排序。学习同时预测接受资格和合格后的增益；成对损失优先区分可接受与不可接受，再排序合格候选。负收益、失败和超时均保留，原始多指标不被标签处理覆盖。

首轮两组，训练种子均51001：

| 编号＋组合 | 作用 |
| --- | --- |
| L0 贪心初解＋集合编码候选排序＋B | 逐束共享编码和全局/组内聚合，不使用逐对物理消息传递 |
| L1 贪心初解＋物理干扰图候选排序＋B | 在相同节点/候选信息上加入有向物理关系和候选引起的重叠变化 |

节点含需求、未封顶C/D、功率、频率起点/长度、组号及剩余资源；物理边含实际方向增益、频率重叠与干扰关系，使用现有物理核心，不凭几何距离另造传播公式。所有方法可访问相同场景物理信息。L0/L1的差异解释为**显式物理关系组件的整体贡献**，不声称已经剥离全部信息压缩和参数量影响。

候选特征只允许用**SCA前**已知物理结果：每个完整候选做一次全束固定功率重算，最多16次，H1/L0/L1使用相同输入副本。候选实际C/D、干扰、特征构造的开销均计入在线方法时间。完整B结果/接受标签只作训练监督或实际被选候选的终核，不能进入考核排序输入；缓存键必须区分直接物理特征与完整B标签。

建议共享编码宽128、两层、候选级回归/成对排序损失；超参数正式前冻结，不开大规模搜索。每个训练批次按母场景采样，归一化只用训练集，补零不参与池化。全束身份置换时同时置换需求、组号、动作和图边，不重新按序号取模改变物理组。

**每次梯度更新只读取保存标签，不调用SCA。** 两模型用同一训练/验证母场景、候选、标签、更新上限和保存节点。模型预测仅决定评价顺序，最终成绩来自原物理核验；不拿预测SI当结果。

### 3.4 共同接受与回退

对原B1＋B建立统一参照。候选经B后必须资源合法，并相对该参照满足：SI不下降超过1e-8、SGM不下降超过1e-8、原已达到10%基本服务的每个束不新增严格跨下。数值边界独立核算并同时报告严格值，不用扩大容差提高成绩。满足保护的候选中取SI最高者；SI数值等同时依次用SGM、较低功率、固定候选ID破同分。规则搜索、随机搜索和学习搜索全用同一保护。

原SCA的基本服务保护是相对**每个候选自己的初解**，不足以保护原贪心；因此上述跨候选保护必须额外实现。超时、失败或无改进均回退，不删除场景，并累计失败尝试成本。

若基准B未正常结束，沿用共同冻结的失败规则，保存最后已核验的可行结果（无此结果则用原B1），标明该景为基准求解失败。所有方法仍计入该景与耗时，另列基准正常完成子集的敏感性分析；不能把胜过失败回退解解释成胜过正常完成的贪心＋B。

直接结果保存所选候选在SCA前的真实分配，与其SCA后结果保持相同候选ID。它可能直接SI不如B1而细调后更好，必须如实报告；**不得偷偷用另一个候选的最好直接值拼成“同一方法前后提升”**。池内直接SI最好结果可另作非学习诊断，不算排序模型的直接成绩。

## 4. 分阶段执行与硬停止条件

### A：先查可改善空间，不训练

从既有Jan12的12母场景按时刻排序，奇数位6母为开发、偶数位6母留作学习验证；先冻结名单。开发使用N=50/100/125/150/175/200、两档负载，共72景。新增125/150/175若原验证文件没有，须由对应原始母场景重新生成并审计，不能拿Jan29补齐。

每景生成至多16候选＋B1，最多17次完整B。比较候选池内真实最好结果、直接SI前3规则、固定随机前3；每个可部署选择器只能用B1＋3候选的成绩。池内17次全评仅是**候选池内的诊断上界**，不是全局上界，也不是4次调用算法的可部署成绩。

进入学习阶段须同时满足：资源账/回滚/终态核验无未解决错误；池内最好最终SI对B1＋B总体平均提升≥0.5百分点，大N平均≥1.0百分点；至少三分之一母场景有超过0.1百分点的提升；与规则前3之间仍有总体≥0.2百分点的选择空间。阈值是本轮预注册的工程目标，不是论文承诺。

若池内无空间，停止该学习路线，检查候选是否被满槽和连续性锁死；可以提出更大局部窗口的新方案，但不无限补候选。若规则已达到池内最好，则优先交付非学习方法，不为了保留模型而强加训练。阶段A记录完整B实测时间并推算后续成本；成本超出后续工作台冻结总墙钟预算时不启动完整标签生成。

### B：有限教师标签＋两模型监督训练

沿用Jan08/09的576个合格训练母场景，每母按预先固定的均衡规则从已有训练输入选**1个N/负载组合**，共576景；不根据收益选景。保留原60/90/140/180束不作为训练输入的规则，按N区间/负载报告覆盖。每景至多17次B，生成完整候选标签。

先取按时间与N桶分层的144母（不是看分数挑选），两模型各训练2000次梯度更新；之后只有验证集上学习前3选择优于规则、约束通过且候选改进真实存在，才补齐其余432母。完整预算各8000更新，包含试点2000；2000/4000/6000/8000四个节点验证。主结果取固定8000终点，验证最好节点只作诊断，不能用正式考核挑权重。

其余6个Jan12母组成72景验证集，同样至多17候选B标签，标签只用于模型评估/继续闸门，不进梯度更新。单轮固定候选可复用缓存做节点质量验证，不能据此声称在线算法只花缓存读取时间。

本阶段**不新增SAC/PPO环境交互**；新增成本是标签求解与监督梯度更新，两者单独记账，不能称与既有40万逐束交互等预算。若用户研究目标进一步限定“必须由强化学习决策获得收益”，需在此结果上另定模仿预热＋改进动作PPO的对照，而非把监督学习写成RL。

## 6. 胜出标准：预先写定，不能事后换目标

主比较为L1对B1＋B；L0是预注册结构对照，不因L1失败而事后用L0替换主假设。正式报告保留两者。

| 判据 | 通过条件 |
| --- | --- |
| 全范围最终SI | L1−B1＋B在11档N、两负载等权平均≥0.5百分点，母场景配对95%区间下界>0 |
| 大N最终SI | N≥125六档平均提升≥1.0百分点，N=200方向为正；逐N结果全部列出 |
| 学习贡献 | L1在相同4次完整B上限下对H1平均提升≥0.2百分点且配对区间下界>0；若仅同质量更快，单列提速结论 |
| 小N与其它指标 | 50–100各档最终SI不低于对应B1＋B；SGM/逐束基本服务遵守共同保护，列有效承载与C/D尾部 |
| 可行性 | 无未解释资源超限、身份变化或组内冲突；失败/超时留在分母中并计成本 |
| 直接分配 | 单独比较所选候选SCA前与B1直接结果；只有均值与配对区间同为正才声称直接分配胜出，不能由最终结果推得 |
| 时间 | 报均值/中位/P95、逐景值及等墙钟质量曲线；只在更长时间得到好解则写明质量与时间取舍 |

阈值是希望达到的实用效果，不是已证收益。保护机制使失败时多返回基准，它不算“超过”。若只通过完整方法胜出、未通过学习贡献，结论是非学习修复有效；如果两者都未通过，停止本轮，不追加种子或无界训练。

统计先合并同母下的N/负载与同景重复动作，再按母时刻配对重采样；同日时间相关时补时段分块敏感性分析，两日期分别列结果。区间不能代替多训练种子，也不把880景当880独立来源。SI/SGM均按全体目标束末次动作后重新核算，未服务束计零；同时列未封顶C/D、min(C,D)、严重欠服务比例及近1数值边界，不用严格C/D<1的微小浮点跨越推断业务机制。
