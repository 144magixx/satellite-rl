# 可变波束数量泛化训练方案

日期：2026-10-04。方案标识：S2-P17。**状态：用户已于2026-10-04授权实施和既定实验，并限定只在10.160.17.102:20424运行。**训练/评价预算与方法按本方案执行；候选数据日期仍须核可用性与隔离并冻结。当前开始实现与预检，尚无正式任务ID或冻结新科学版本。

用户希望在“卫星最多产生200束”的假设下，让第二阶段适应不同波束数量，并继续通过第三阶段取得较高需求满足率SI和供需匹配程度SGM。本方案把此前[问答建议](../../../Q&A/算法与训练/可变波束数量的泛化训练.md)落实为可审阅的实现、训练与共同考核安排。

## 1. 研究问题与首轮范围

首轮回答：**在同一总功率和频谱条件下，给模型明确的束数与剩余资源信息，并用不同束数混合训练，能否改善未见束数的分配效果，同时保住100束场景的能力？**

推荐保留T0逐束选择频率槽和初始功率的方式。两个新模型使用完全相同的新状态与网络，只改变训练场景的数量分布及其配套分档采样。两者得到初始分配后，使用同一第三阶段功率细调路线。混合数量与平衡采样作为一个训练方案比较，本轮不能把收益进一步归因到其中某一项。

| 项目 | 本轮建议 |
| --- | --- |
| 接口允许范围 | 实际正需求目标束N为1–200；N=0单独返回无业务状态 |
| 正式训练与效果考核范围 | 50–200束，覆盖当前100束两侧 |
| 1–49束 | 只作工程边界核验，不声称本轮验证了该范围的学习效果 |

| 原模型参照 | G11 T0固定150000步终点，记H0，仅评价不训练 |

选择50–200作为首轮科学范围，是为了控制成本并覆盖“少于和多于100束”两种情况；这不是用户已经确认最低为50束。如果论文要对1–200全部范围作性能结论，需要把1–49纳入正式训练/考核并重算预算后再确认。

## 3. 状态、动作、奖励与资源规则

### 3.1 新210维状态

保留原207维字段的顺序和含义，在全局信息中追加以下3项。基础13令牌不变，全局投影由3维改为6维，仍共14令牌；Actor、双Critic及目标网络统一使用该定义。新旧状态版本不能仅按文件名推断。

| 新字段 | 建议冻结定义 | 实际含义 |
| --- | --- | --- |
| 实际束数 | N/200 | 这次共需服务多少束 |
| 剩余束数 | n_remaining/200，包含当前待分配束 | 后面还需要给多少束分配资源 |
| 每剩余束功率压力 | P_remaining/(P_remaining+30×n_remaining)，正常决策时计算 | 将每剩余束可用功率与30W参照比较，映射到0–1 |

其中P_remaining按3000W减去已实际计入的功率计算，单位W。正常决策前n_remaining≥1；终态保留N/200，其余两项记0，避免0/0。非法负剩余功率应触发资源错误，不能用截断掩盖。新增第三项由“每剩余束功率/30W”经x/(1+x)变换得到，不改物理功率或动作。

原平均需求、进度和剩余需求归一化保持原含义，beta只对真实正需求目标束求均值。摘要网络无需填充200个波束令牌；场景数组按实际N存储。将来若使用逐束集合网络，才另行引入占位掩码，不能把占位计入资源与指标。

### 3.2 动作与可行性

逐束动作头维数保持100×10×10：频率起点、1–10连续槽、5/10/…/50W档位。处理顺序沿用逐场景需求稳定降序，分组沿用处理序号%8；改变N时重新生成并冻结完整身份/顺序/组别。所有方法在同一衍生场景使用完全相同的顺序和分组。

继续使用`joint_feasible`掩码，为后续真实目标束预留最低功率和其组内至少一个槽。200束名义最低功率为1000W，每组最多25束，低于3000W和每组100槽，但这不保证容量足够满足业务。

回合正常完成N次真实分配后结束；提前终止时保存原因，未服务的真实束容量为0并计入最终分母。N=0无业务直接返回独立状态，SI/SGM记不适用，不能以0/0或虚构满分参与平均。

### 3.3 奖励与学习机制

V0/V1共同采用T0的`legacy_repaired`，保持固定α=0.01、gamma=0.99，不在首轮同时更改SI/SGM权重、每步奖励尺度或联合Q结构。回报只用于本组训练诊断，按N分面，不把不同N的累计回报直接排名。

开发时检查长回合的Q尺度、延迟影响和梯度；若必须改变奖励或折扣才能正确学习，应先修订方案并重新明确两组共同设置，不能在运行中只修改V1或自动延长它的预算。首轮目标是评估这个训练方案，失败也形成结论。

## 4. 场景来源与数据划分

### 4.1 生成原则

沿用欧洲航空场景的真实位置、合成业务模型与固定方向图，在同一母快照上用可变N覆盖生成器重新产生中心、归属和逐束需求。该生成器是数据准备工具，不是新增第一阶段PPO训练；以后连接第一阶段实际输出仍须另验。

每个母场景先生成一份固定的每机基础需求，再使用0.75和1.25两个需求倍率形成轻/重两档。两个倍率是本轮候选业务压力设置，均为合成需求，不是实测吞吐。相同母场景同一档在不同N之前的用户和总需求保持一致；N改变导致覆盖变化时，实际覆盖需求可以不同，必须保存未覆盖用户/需求，不能宣称实际输入总需求仍严格相同。

不靠删除或复制100束数据产生正式场景，不人为给空束补正需求。母场景须有至少200个正需求用户且坐标等基础数据有效；该资格条件在算法运行前应用并记录。低覆盖或高难度本身不能作为丢弃条件。N个非空束无法构建时保留生成失败及母场景ID，不看模型成绩换景；若不能满足冻结样本数，停止数据准备并修订清单，不用较小样本冒充完整实验。

束宽继续0.5°，中心代表接收点等现有物理近似保留。50束无法充分覆盖整个欧洲时如实报告；第二阶段SI分母是该布局的全部正需求目标束，另并列母场景用户覆盖率、需求覆盖率和覆盖后业务量，不能把较小的已覆盖集合高SI称作整体业务更好。

440是衍生场景数，独立来源只有20个母快照；同日快照仍可能相关。跨N、负载和重复动作不能当成440或1320个独立母场景。首轮提供有界证据，不宣称多日期、多训练种子的稳定泛化。

V1三个非100档分别为50–99去掉60/90、101–149去掉140、150–200去掉180。每档内均匀抽N，再抽对应母场景和需求档；保留25%的100束回合用于保持原规模能力。回放使用相同四桶采样器：V1每批各取64个真实转移；V0只有100桶，每批取256个。总容量20000，共用一个环形存储与明确桶索引；正式更新开始前须有各有效桶样本，不足64时允许桶内有放回抽样并记录，不把复制采样算作额外交互。预热最初安排V1四桶各至少一个完整回合，仍计入既定2000步。

数量混合、100束锚点比例及回放平衡合称本轮训练方案；不声称只改了一个随机整数。记录每N/数量档的回合、真实交互、更新目标样本、有效学习次数和耗时。V1在100束的暴露量少于V0，100束表现下降需要单独讨论。

两新组从头训练、seed51001、同一初始化状态字典，Transformer宽128、8头、2层、前馈512、dropout0；batch256、总回放20000、预热2000、每步一次更新、gamma0.99、tau0.005、Actor/Critic学习率1e-5/1e-4、梯度裁剪10、固定α0.01。预期各398001次更新，以实际计数为准；异常少更新不能仍报预算内等量学习。模型增加的实际参数数在实现后核验，不填无效参数凑数。

主结果固定取400000步终点，不按最终考核选择权重。完整恢复断点每10000步；验证在0、20000、…、400000共21节点，各144场景×1次动作，两个训练共6048次验证分配。验证仅跑第二阶段，不接功率细调；动作seed53001，验证使用独立环境和RNG，不能改变训练轨迹。最好验证节点可保存作诊断，不能替代主终点。

固定预算到达、非有限数值、无法恢复的来源/数据错误、用户停止均须记录不同状态。失败组不自动加步数重训；工程性中断只能在完整学习状态和唯一任务归属核验后同ID恢复，仍以原400000总预算为上限。

## 6. 统一第三阶段与评价预算

第三阶段沿用[S3-P03报告03](../../第三阶段/实验报告/03_SI优先功率细调与容量近似对照.md)中的B路线：先原A，再从对应A终态追加优先提高SI、守住已找到SI后尽量提高SGM。复用科学`e85a9429461a358ba2e11614a3cce4671d12b68e`所定义的方法及数值守护，仅进行可变N与新初始解入口的必要适配；不改变容量公式或隐藏放宽容差。

每个初始分配都用3000W总预算。功率为任意非负整束功率，仅受总功率限制，空槽束0；原第二阶段档位仍5–50W。A段与B追加段各最多2000次容量调用、30秒、每内部阶段最多300轮；整条细调最多4000次调用和两段60秒求解。保留原固定槽、基本服务与SI保护，SGM可能为提高SI而下降；最终报告同时列严格计数与既定数值容差核验。

H0兼容核验若失败，先报告原因并修订科学比较范围，不能把其缺失项填零，也不能增加另一训练组替代。固定与贪心同样必须保留原规则名称，必要适配不得暗中成为新启发式方法。

## 7. 判定标准、图表与耗时口径

主比较为V1混合训练对V0固定100训练，在相同N、母场景、需求档和动作重复口径下作差；H0与新模型分别15万/40万步，只提供历史参照。第三阶段前后分开比较，不能只看细调后的高分。
