## 1. 当前证据支持什么

G10的J0/J2使用加性Q，J1/J3使用完整联合Q；后两组的固定验证回报回落，TD误差、Q目标和温度同时增大。J0/J2后段温度约0.236，J1/J3约3.85万。完整联合Q是优先排查对象，但参数量、初始化和优化难度同时变化，尚不能把自动温度定为唯一初因。

J2相对J0的独立SI仅提高0.295个百分点，SGM提高0.01251，全100束基本服务比例却由88.00%降到85.33%。因此保留J0作稳健参照，J2作有取舍的候选，不先宣布J2全面替代J0。基本服务仍指最终容量达到各自需求的10%。[正式结果与曲线](../实验报告/11_联合动作四组独立场景对照.md)

## 2. 第一步：用已有快照定位异常，不增加训练

本次仅清点文件及读取保存代码，确认四组各有41份学习快照：步0及每1万步到40万步。它们位于[已归档任务目录](../../../outputs/experiments/europe_joint_action_20261001/remote_archive/outputs/workbench/jobs/)，不是根目录散落的checkpoint，也不是本地旧任务记录。

建议先固定检查1万、3万、5万、8万、10万、15万六个节点，四组共24份。每份格式可保存最多64条终止、64条非终止经验，以及Actor、双Q、目标Q和温度。先核对应SHA和配置，再只读计算：

| 要检查的内容 | 要回答的问题 |
| --- | --- |
| 终止经验的预测Q与即时奖励r | 没有后续价值和熵项时，价值网络本身能否拟合？ |
| 非终止目标拆成r、γE[min Q_target]、γαH_next | 异常主要从价值自举项还是熵项放大？二者何时开始偏离？ |
| 合法动作Q的分位数、极差，已选动作所在位置 | 是否出现极端估值或某些组合异常吸引策略？ |
| 熵与按合法动作数计算的目标熵、Q差值/α | 探索是否过早收缩，以及温度增大后策略仍受多大价值差异影响？ |
| 终止/非终止TD分别统计 | 避免大量非终止状态掩盖最后一束的价值问题。 |

先看各组自身样本，再用预先冻结、来源均衡的共同状态/动作样本比较同一输入；两种口径分开保存。快照样本不是全部经验池，也不是当时那次更新的原始minibatch，能重算的是该快照网络对这些样本的目标，不能宣称逐次重现历史梯度或证明某动作从未被访问。学习快照也缺优化器和完整经验池，**不能用于恢复训练**。

如果发现掩码、终止处理、温度符号或目标计算错误，先保存并修复该具体问题，重新制定对照；不能一边修公式，一边声称只测固定温度。若没有正确性错误，再进入下一步。

## 3. 第二步：只新增两组固定温度诊断

温度α是SAC内部控制动作多样性的系数，也会进入价值学习目标。固定它可以切断自动调节这一条反馈路径；这不改变环境旧奖励，却会改变算法的探索和学习目标，属于学习实验。[SAC方法说明](https://spinningup.openai.com/en/latest/algorithms/sac.html)同时介绍固定和自动调节温度，[离散SAC](https://arxiv.org/abs/1910.07207)提供离散动作期望的依据；两者都不证明本项目的失稳根因。

| --- | --- | --- | --- | ---: |
| 历史J0前15万步 | 原分头策略 | 加性Q | 初值0.01，自动调节 | 0 |
| 历史J1前15万步 | 原分头策略 | 完整联合Q | 初值0.01，自动调节 | 0 |

**最小新增预算30万交互步；每组1500回合、预期148001次参数更新，只有训练seed51001。** 不重训J2/J3，不顺带加入条件策略。T0用于判断固定温度是否普遍损伤学习，T1用于判断完整联合Q在切断温度反馈后是否仍失稳。

固定值选择原初值0.01，是为了保持起点一致并只移除自动温度更新，不是声称它最优。J0/J2最终约0.236也不是可以直接套用的最佳常数。固定0.01可能探索不足；若结果不好，只能否定这项具体设置，不能否定全部固定温度方法。不预设追加0.05/0.1/0.2等搜索，避免一轮变成无边界调参。

## 4. 怎样判断诊断结果，何时继续

所有短组预定停在15万步；出现非有限学习错误则保存现场退出，不盲恢复。不会因某组表现差就单独延长，也不会改图把失败隐藏。

| 观察结果 | 能得到的结论 | 建议动作 |
| --- | --- | --- |
| T1不再出现价值/TD大幅漂移，且相对同期J1验证改善 | 自动温度反馈参与了本设置的失稳；不等于已证明最初诱因 | 检查是否仍落后T0；达标才考虑更长的匹配对照 |
| T1数值稳定但业务指标仍差 | 消除了发散表现，尚未改善资源分配 | 不把“loss小”当成功；优先查组合共享和探索不足 |
| T1仍失稳，T0正常 | 单纯固定该温度不足以解决完整联合Q问题 | 转向结构化价值，不直接增加完整动作表预算 |
| T0/T1都明显退步 | 该固定值或失去温度自适应不合适 | 保留负结果；不能据此宣称温度机制无关 |

判断看两层。第一层是计算和学习诊断：有限数值、合法动作、终止目标正确、TD相对目标尺度以及Q差值的变化；温度固定本身不算“学稳”。第二层是同一Jan12验证节点的旧奖励回报、终态SI、SGM、平均基本服务束数、全100束基本服务比例、功率/槽数与请求裁剪。

以11万–15万最后5个验证节点的均值、范围和各原始点作为筛查窗口，同时展示全程，比较T1−J1、T0−J0、T1−T0及两种Q受固定温度影响的差值。只有数值改善，不能认定策略改善；若不同业务指标有升有降，明确取舍。不同α下的软Q和内部loss不是统一业务得分。

15万步只作筛查，不能证明40万步稳定或数学收敛。未来若做正式长对照，须在执行前另定共同40万步预算及模型规则；可以预先设计完整断点延续，但不能从学习快照拼接，不能把续到40万写成额外再训40万。

## 5. 真正的结构改进：在加性Q上只学习必要的交互

后续优先候选是**加性Q＋槽数—功率交互项**。直观说，保留“一条经验能帮助许多资源组合”的优点，再学习“几个槽搭配多少功率更合适”。首版表达式为：

`Q(s,f,l,p) = q_f(s,f) + q_l(s,l) + q_p(s,p) + c_lp(s,l,p)`。

原三分量输出100＋10＋10＝120项，新增10×10槽数—功率交互100项，共220项，仍对同一最多10000个动作组合评分。交互表可做行列居中以分离单因素部分，最后一层从零开始，使初始Q保留原加性值；既有权重复制和初始化随机性须显式核验。两个Critic各有独立交互项，先合成各自完整Q，再逐组合取双Q最小值，不能把不同分量的最小值相加。

选择槽数与功率，是因为容量同时依赖带宽和功率，两者的搭配有物理意义。该结构比完整动作表约束更强，**不等于已经证明更好**；它也不能显式表示全部起始频率—槽数—功率三阶关系。若此项有效，再独立研究频率—槽数交互，而不是首轮把所有项加满。参数量、显存和耗时按实际网络报告，不用输出数量直接推算加速倍数。

验证这个创新时，固定策略结构与温度规则，只比较加性Q和增加交互项的Q；不要同时引入条件Actor、改学习率、换损失或改奖励。条件策略、GRU/Transformer跨步记忆、干扰图依旧是后续独立问题。当前207维Transformer只处理同一步观测，跨步记忆需要新的状态、回放和恢复设计，不是简单把输出拼进去即可。

**这一结构实验尚未列入本轮30万步预算，也未获运行授权。** 它是温度诊断之后的候选方向；其完整组数、预算和比较规则应根据诊断结果另定。结构受资源分配关系启发，不能仅凭该公式就宣称论文方法新颖性。
