## 这轮先解决什么

W26已经说明，在共同可变布局上，四个SAC终点的平均SI与SGM都超过随机、固定和T0式贪心。当前值得研究的不是再换一批弱基线，而是能否在S10已有表现上改善供需匹配。S10的确认SI为95.5952%、SGM为0.621518，相对S00提高0.6360个SI百分点和0.012886 SGM；相对贪心的平均功率却高16.12%。S10与同时加入关系的S11没有清楚的双指标差距，不能把“输入更多”当成必然改进。

本轮保留真实legacy_repaired奖励、Transformer主体、频率/槽数/5—50 W离散功率动作、共享物理及统一21.6 Mbps/机。在208维S10状态上比较两种有界改变：降低SAC熵系数；让价值和策略都能显式表示槽数与功率的组合。第三张卡用于重新执行共同对照，避免只拿历史曲线对比新实现。每臂先训练50000步；候选通过开发门槛后才接续至150000步，先导计入上限，不另加一轮训练预算。

这两条路线是待检验假设。W26没有记录足够完整的策略熵诊断，不能宣称已经证明过度探索；降低温度可能改善终态贴合，也可能降低探索而退步。原加性Q将槽数和功率价值相加，而链路的每槽功率、带宽及供需偏差共同依赖二者，因而小型联合块有机制动机；它仍不保证更容易学习。保持原奖励是用户约束，本轮不会把未改善的原因一概归咎于奖励，也不另改奖励补救。

## LP怎样表达槽数与功率，而不扩成完整联合Q

令f为100个频率起点，l为1—10槽，p为10个合法离散功率档。共同合法域是M(f,l,p)=M_FL(f,l)M_P(p)。LP Actor输出z_F(s,f)与z_LP(s,l,p)，只有100＋100个输出；在完整合法域定义

`π(f,l,p|s) = M(f,l,p) exp[z_F(s,f)+z_LP(s,l,p)] / Z(s)`。

归一化必须对合法三维组合一次完成，不能先独立归一化LP再乘一个旧FL分布而遗漏合法槽数组合的质量变化。数值实现可用logsumexp及等价分解，必须与小型穷举结果一致。采样仍先抽FL边缘`π_FL=Σp π`，再从该l的条件功率`π(p|f,l)=π/π_FL`抽P；均用真实概率而不是argmax。因为M_P与f/l无关，这一条件仅依赖l，但FL边缘包含合法功率求和后的LP权重。不能把未归一化的LP logit当概率。

两个Critic各为`Q_k(s,f,l,p)=Q_F,k(s,f)+Q_LP,k(s,l,p)`。TD目标先形成完整动作Q，再求两Critic逐动作最小值：

`y = r + gamma*(1-done)*Σ_a π(a|s') [min(Q_target1,Q_target2)(s',a) - alpha logπ(a|s')]`。

Actor目标为`Eπ[alpha logπ−min(Q1,Q2)]`，Critic取实际执行完整动作的Q做原MSE回归；target更新及其余训练语义不变。熵必须是联合熵`−Σπ logπ`，分项报告使用条件熵链式分解，不能把LP的两个边缘熵相加。非法项概率为0，安全log项明确置0以避免0×负无穷；非终态合法域为空直接拒绝。终态不求下一个合法分布、不把工程占位掩码当真实动作。

这不是10000自由输出的完整联合Q，也不是此前方案25。输出头数量改变，环境仍收到同样三个动作分量，不能误写“仍为原三独立头”。两部分共享原Transformer读出，LP输出采用原头同型Linear，矩阵索引l优先、p次序固定。初始化从B的共同随机参数派生：LP每行权重与bias等于原L行加原P行，F头原样复制；两个Critic分别同样处理。于是训练前LP完整Q与B相同，合法动作分布也数学等同B。额外参数不以零填隐藏，不添加未经冻结的随机扰动破坏这一配对。实际参数量由实现脚本逐网络统计，含target单列；按128维读出计算，每网络比原三头多80×129=10320在线参数，Actor加双Critic多30960，最终以代码核值为准。

原纯加性Critic下只改条件Actor，通常不足以支持“学到槽功率价值耦合”的解释；双Q逐动作min虽可能引入非可分影响，亦不能替代明确联合块。LP同时改变策略与价值的匹配分解，若有效，未来再另设有界拆分实验；本轮不预支这些预算。

已逐行核继承的`workbench_algorithms.py`原masked SAC：下一状态先用`torch.minimum(_joint_q(target1),_joint_q(target2))`，再用FL概率、P概率与完整min-Q求期望；Actor亦对完整动作min-Q求期望。故上述min位置是保持原B数学，而非本轮另改目标。LP初始值等价还须在共同合法掩码上核联合概率、联合熵及同一输入/奖励/终态标志的soft TD target。新增Linear构造、参数复制与任何组件初始化须fork/恢复CPU及全部实际使用CUDA随机流，前后SHA核不变；不能仅在最后重新seed而掩盖别的流被消费。初始化的前向/目标相等不意味着LP之后参数梯度、Adam轨迹或实际策略仍相同，不作此过强声明。

## 事前继续门槛与选择规则

开发评价沿用W26的母与动作种子映射，每节点20母×3动作重复。先在母内平均，再对20母等权。固定节点为0、2000、5000、10000至150000每10000步；30k与40k只诊断，**50k是首轮唯一科学继续门**，不用事后挑最好三节点或更改阈值。

对候选C∈{E,LP}，在50k相对同轮B50k计算ΔSI与ΔSGM，SI采用0—1原值。必须同时满足：

1. 训练/恢复来源、有限数值、全部开发回合完整处理、合法资源与零执行裁剪全部通过。
2. `ΔSI >= -0.002`且`ΔSGM >= -0.005`：允许筛选噪声下的小幅取舍，不接受明显退步。
3. `ΔSI >= +0.003`或`ΔSGM >= +0.005`：至少一项达到登记的实际改进尺度。
4. 平均总功率不超过同节点B的110%，且每例仍满足3000 W；这是此次探索的成本护栏，不修改奖励或物理。

这些门槛是有限预算的开发筛选规则，不是统计显著性、非劣性或最终成功证明。候选未通过则在50000停止，不追加种子、换alpha或延长到“可能变好”为止；报告实际退步与可能的迟发收益局限。任一候选通过，B与所有通过者各接续至150000；没有候选通过，三臂均在50k结案。B的150k预算服务匹配对照，不在两候选均失败后单独把它跑满。暂停发生在50k判门之前则保存现有进度，时间截止不能代替科学失败。
