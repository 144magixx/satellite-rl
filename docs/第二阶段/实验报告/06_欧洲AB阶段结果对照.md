# 欧洲A/B阶段结果：关闭dropout与打乱场景顺序

日期：2026-09-29。**在已经完成的原100场景考核中，A改善更明显，B也有改善。** A主要表现为更好的需求满足率、供需匹配程度和更低的分配功率，价值拟合异常也明显缓解；B对场景顺序的处理有收益，使用频率槽更少，但训练中仍有较明显波动。

本报告只分析已保存的G07、A、B结果和曲线，没有新增训练或重新评价。C组仍按原计划运行；01-18新日期的共同独立考核尚未执行，因此这里是**原考核集上的阶段性结论**，不代表已证明泛化能力提高。

## 2. 终点评价：A的整体改善更明显

以下为100个相同场景、每场景3次动作的平均值。SGM为0–1评分；“基本服务”指最终容量达到本束需求的10%，不同于完全满足全部需求。

| 指标 | G07原模型 | A：关闭dropout | B：打乱场景顺序 |
| --- | ---: | ---: | ---: |
| 最终需求满足率SI | 88.93% | **90.55%** | 89.50% |
| 相对G07的SI变化 | — | **+1.62个百分点** | +0.57个百分点 |
| 供需匹配评分SGM | 0.4149 | **0.5799** | 0.5343 |
| 平均达到基本服务的束数/100 | 99.24 | 99.49 | 99.48 |
| 全部100束达到基本服务的分配比例 | 54.00%（162/300） | **63.33%（190/300）** | 59.33%（178/300） |
| 平均波束总发射功率/W | 2942.97 | **1726.25** | 2209.17 |
| 相对G07的分配功率变化 | — | **−41.34%** | −24.93% |
| 平均实际频率槽数 | 458.05 | 353.53 | **324.54** |
| 需求满足率的Jain公平性 | 0.9387 | **0.9519** | 0.9450 |

三组在各自300次分配中均处理全部100束，超功率、频率越界、占用冲突、动作裁剪、零槽和零容量均为0。较好的平均成绩仍不意味着每次都让全部波束达到基本服务：A仍有110/300次至少一束低于10%需求。

先将同场景的3次动作取平均，再对100个场景配对，结果如下。这里的100个场景不是100个训练种子，300次动作也不是300个独立场景。

| 相对G07 | A改善/下降的场景数 | B改善/下降的场景数 |
| --- | ---: | ---: |
| SI | **81/19** | 65/35 |
| SGM | **100/0** | 99/1 |
| 按需求封顶的有效承载 | **90/10** | 66/34 |

A在主服务指标、SGM和功率上更有优势，但不是所有指标、所有场景都胜过其他模型：B使用的频率槽更少，A相对G07仍有19个场景SI下降。

## 3. 总容量下降，为何仍认为有所改善

原日志中的`throughput_bps`累加各波束可提供的容量，包含超过该束业务需求的部分。为了判断是否牺牲业务，额外把每束容量按需求封顶后求和，并分别计算超过需求的容量与未满足需求量。这些是仿真结果的派生统计，不是实测航空业务吞吐。

| 平均量（Gbps） | G07原模型 | A | B |
| --- | ---: | ---: | ---: |
| 全部波束业务需求 | 22.8085 | 22.8085 | 22.8085 |
| 总分配容量（日志总吞吐） | 38.3263 | 26.0479 | 27.6590 |
| 有效承载：逐束`min(容量,需求)`之和 | 16.0243 | **16.9897** | 16.9561 |
| 超需求容量：逐束`max(容量−需求,0)`之和 | 22.3021 | **9.0582** | 10.7030 |
| 未满足需求：逐束`max(需求−容量,0)`之和 | 6.7842 | **5.8188** | 5.8524 |

A/B的总容量分别减少12.2784/10.6673 Gbps，但有效承载分别增加0.9654/0.9318 Gbps，未满足需求相应减少。总量上同时呈现超需求容量减少和欠供改善；本次没有逐束分解动作变化、干扰变化的因果贡献。因此不能把总吞吐下降直接说成业务更差，也不能忽略这个下降。

将全部场景的有效承载总量除以总需求，总体需求加权满足比例为70.26%→74.49%/74.34%。这与表中的SI不同：SI先按每束需求归一化再平均；此处按业务量加权。它也不同于先求每个场景的比率再等权平均，三种口径不能混用。

## 4. loss与训练曲线：A缓解最明显，B仍有波动

下表取训练350000–400000步区间内的1000个学习日志采样点中位数。学习指标约每50步记录一次，不是全部398001次更新的统计，也没有只选末尾一个低损失点。

| 尾5万步学习指标中位数 | G07原模型 | A | B |
| --- | ---: | ---: | ---: |
| Critic 1损失 | 756.96 | **0.989** | 10.44 |
| Critic 2损失 | 712.30 | **0.992** | 10.64 |
| 平均绝对TD误差 | 13.825 | **0.728** | 1.944 |
| 目标值标准差 | 156.96 | 45.43 | 25.71 |
| 每采样点`TD绝对误差/目标值标准差`的中位数 | 0.0876 | **0.0158** | 0.0806 |

TD误差可理解为“价值网络预测与本次学习目标的差距”。A的绝对误差及考虑目标值尺度后的误差都明显减小，固定验证曲线也较平稳；这支持关闭dropout确实缓解了当前价值拟合异常。B的绝对损失和TD误差也降低，但目标值尺度同时缩小，归一化后的误差与G07更接近，因此不能仅凭绝对loss下降两个数量级就宣称同程度地解决了问题。

B打乱场景顺序后，训练曲线中按原场景次序反复出现的周期波动减弱；仍可看到中段明显的loss、Q和温度变化。A保留原顺序，所以训练回报和SI仍有场景周期，不能要求每个回合单调改善。不同顺序在同一训练步见到的场景难度不同，不宜拿两组末尾若干训练回合的回报直接排名。

最后一次固定验证（20场景×3动作）SI为G07 88.69%、A 89.99%、B 89.31%；SGM为0.4247、0.5864、0.5416。方向与终点评价一致，但A/B的提升幅度不同。

## 5. 结论与后续范围

- **A是当前更有希望的改动。** 原考核集的服务、匹配、功率和价值拟合几方面同时改善，优先保留为后续候选有依据；不等于已证明严格收敛。
- **B也有收益。** 场景顺序影响训练表现，B提升了原考核集的匹配程度和资源使用效率；SI增益较小、部分场景下降，学习曲线仍有波动。
- **不能直接推断A+B组合收益。** A与B之间同时存在dropout和顺序两项差异；本次没有训练二者叠加的模型，也不因本报告自动增加新实验。
- **泛化与六组最终结论仍待验证。** 本次只有一个训练种子51001；原100考核场景曾用于G07诊断，是已有开发比较数据。按已授权计划继续C组，再以未用于本轮诊断的01-18共同100场景统一考核；不更改在训配置，不增加种子或预算。
