# 可变波束数量训练与SCA前后共同场景对照

实验编号：S2-P17；训练与考核：2026-10-04至2026-10-05；报告日期：2026-10-05。

**本报告同时展示第二阶段直接分配与第三阶段最终B结果。** 两组训练、三项初解评价、五来源SCA和全量终态物理审计已完成。原始日志保留一次失败B回退及一次用户主动暂停；两次原始尝试的精确成本无法恢复，分别以缺失值和下界记录，不能称全部计时完整。

## 1. 主要结论

1. **混合束数训练对较大束数有收益，但不是全范围改进。** 对训练和验证均未出现的60/90/140/180束，V1相对V0的等权平均SI提高：第二阶段直接结果 **0.722个百分点**，最终B **0.279个百分点**。140–200束的直接SI提高1.535–2.673个百分点，最终B提高0.732–1.380个百分点；60、90束的最终SI分别下降0.459和0.186个百分点。
2. **预定的100束最终保留门槛通过，原始SGM仍有明显取舍。** 100束最终SI提高0.192个百分点、SGM提高0.001322；第二阶段直接SI基本相当（+0.022个百分点），但直接SGM下降0.032634。方案的保留门槛针对最终结果，不能把对直接SGM套同一阈值的事后诊断写成预定门槛失败，也不能只报细调后结果而掩盖这一下降。
3. **贪心＋SCA仍是强基线。** 在11个N和两档负载等权汇总下，B1最终SI为93.335%、SGM为0.930858，高于V1的91.850%、0.917824；在125–200束各档，B1最终SI和SGM均高于V0/V1。B1平均使用更多槽，但有效承载估计低于V1，不能把平均SI与总业务量互相替代。本轮支持V1相对固定100束训练的部分泛化改善，不支持“学习模型已全面超过规则初解＋SCA”。
4. **改善并非每个母场景都成立。** 将同母的22个衍生场景先聚合后，V1相对V0的直接SI在16/20母景提高、4/20下降；最终SI在17/20提高、3/20下降。直接SGM仅4/20母景提高，最终SGM为17/20。这里只作描述性配对，不把440个衍生景当440个独立来源。
5. **速度与服务指标分别报告。** 五方法共同完整的438个场景上，V0/V1单次完整路线均时约6.586/6.528秒，差别很小；V1的P95并未更低。严格10%基本服务比例有少量下降，来源与A段边界容差见第5节，不能称所有服务指标单调改善。

## 5. 基本服务、覆盖和资源

**基本服务比例有轻微真实下降。** A段的基础容量下限为min(C原始,0.1D)，优化比值允许1e-8，末端容量核验容差为max(1e-3bps,D×1e-8)。A可以把原本远高于门槛的束重新分配到门槛附近，并在数值容差内略微跨下，不能解释为只有原始本就贴边的束受影响。B段以A为参考严格保护A的已达标集合；本轮完整转换核验和实际幅度见[基本服务转换核验](../../../outputs/experiments/variable_beams_20261004/analysis/basic_service_ef62040e88f1/basic_service_transitions.json)。这项取舍与功率/频谱资源合法性分开报告，不将“数值可行”写成“基本服务全程不下降”。

## 10. 结论适用范围

本轮达到预定的“留出N平均SI在直接与最终两阶段均提高”和“100束最终保留”门槛，适合作为可变束数训练的初轮正向证据。改进集中在较大N，直接SGM在小N退步，贪心＋SCA依然是强参照，基本服务边界和缺时也必须保留。

结论仅适用于单训练种子、单考核日期、20个母快照和50–200束内的插值条件。接口1–200不等于1–49学习效果已验证，更不代表超过200束的外推能力。不同N覆盖集合和需求分布变化，H0训练预算不同，混合抽样与回放配套未分开消融，SCA包含连续功率可行域放宽，且使用了两版候选实现。全部A/B均未证明全局最优或严格驻点；两处精确原始成本缺失不能由后处理补齐。本报告不据此追加训练或替换其它实验结论。
