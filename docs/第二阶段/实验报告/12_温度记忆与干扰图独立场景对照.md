# G11温度、分配记忆与干扰图独立场景对照

训练启动：2026-10-01；结果与独立审计核验：2026-10-02。九个新模型均按各自固定预算训练，另有J0/J1旧学习快照15万步权重参照；Jan24共同100场景共3500次分配、350000条终态波束由独立脚本逐条重算。

训练均为单种子51001。T组每组15万步，M/G每组40万步；两种预算的回报与业务指标分开呈现，不同组之间不排统一名次。历史J0/J1参照不计作G11新训练。


**交付状态：**九训练、十一模型共同评价、两基线、逐束独立审计、中文曲线报告，以及62万条补充供需日志的本地归档均已完成核验。原始训练断点、全部历史日志与代码等大文件仍由后台逐SHA同步，尚不宣告全部实验资产归档完成；实际进度见[总归档状态](../../../outputs/verification/g11_remote_launch_20261001/archive_mirror_status.json)。

## 本轮结论

1. **固定温度带来取舍，不能笼统称为全面提升。** T0相对同15万步J0参照，SGM增加0.1315，100/100场景的SGM都提高，平均少用362.48W和57.65个槽，但SI下降0.963个百分点，全100束达到基本服务门槛的比例下降5.33个百分点。T1相对J1的SI提高2.678个百分点、SGM增加0.1369，但SI仍只有87.50%，未超过原加性Q参照。固定α=0.01是可复用的诊断结果，不能据此认定完整联合Q已优于加性Q。
2. **上一实际动作的简单记忆较实用，长窗口记忆没有带来更高SI。** M1与M0的SI差仅−0.069个百分点，SGM略升0.0038，平均功率少153.03W（99/100场景减少）。M2相对M1的SI下降0.385个百分点、SGM下降0.0258，功率反而增加180.72W；M3虽然比M2节省功率并改善SGM，但其SI再下降0.225个百分点。本轮不支持为了更高需求满足率直接换用GRU或因果Transformer。
3. **干扰图的物理关系有正向证据，但伴随资源取舍。** G2相对相同122令牌的G1，SI提高0.615个百分点，SGM略升0.0041，基本服务增加0.103束，全100束基本服务达标比例提高7.67个百分点；平均功率增加107.75W，槽数减少12.29。G1相对G0的SI提升较小且SGM略降，因此要把逐束编码与物理边的作用分别看待。
4. **曲线已呈现初期上升后进入平台，但不能保证单调或严格收敛。** 原始回报仍随场景波动；100回合均值显示主要提升发生在前几万步，后期更接近平台。M2后期有一次明显回落，G组仍有缓慢变化；固定验证SI与SGM比单条训练回报更适合判断服务表现。T组固定温度下Q/损失没有出现该15万步区间内持续数量级扩张的形态，但这不是长预算稳定性证明。

以上结论限于单训练种子51001与一个预先固定的Jan24留出日期。100场景配对减少了场景难度差异，不能替代多个独立训练种子；没有据考核结果挑选中间权重或另加训练。

## 口径与限制

独立结果按每个场景内3次模型动作先平均，再在100个场景上配对；固定/贪心基线各场景仅1次，不把300次动作当300个独立场景或三个训练种子。SI来自全部100束最终速率，包含后续干扰及零服务束；SGM单列，基本服务门槛为本束需求的10%。

训练内部Jan15终点测试仅作开发结果，已与Jan24独立考核分开保存；各组逐项入口见[原始汇总](../../../outputs/experiments/europe_tmg_20261001/verified_report_20261002/summary.json)和[独立审计](../../../outputs/experiments/europe_tmg_20261001/verified_report_20261002/independent_raw_audit.json)。T/M/G参数量与输入不同，单种子和单日期不能证明稳定性或泛化结论。

## 后处理修复与归档边界

首个报告attempt保留了失败现场。审计原先从冻结guard副本的目录寻找shared_data，另把上游CSV、暂存NPZ和工作台重封装NPZ的文件SHA混用。修复后从guard的双实例绝对archive路径定位原数据根；分别验证选择合同、原NPZ清单、CSV来源记录、两端导入SHA/重导入来源，并逐一核100×2个场景内全部7个NPY成员的未压缩字节一致。文件重新封装可以改变容器SHA，数组字节必须相等。统计公式、容差、场景日期、100时刻与权重均未改变，没有重跑评价。

修复脚本通过7项回归、正式报告前350000束独立预审计及正式报告后的再次独立审计；报告原脚本SHA仍为6c59b3f1…，只有运维路径/来源核验修复。旧collector按本轮回迁回执39184而非历史PID核实退出，新collector43290完成报告后正常退出。本地完整归档器按同脚本幂等接续，61,144个文件约20.92GB仍在逐SHA同步；它与已完成的62万行补充日志归档是两个完成条件。

代码与运行核验通过、短窗口吞吐改善、模型效果改善是三个结论。此次报告证实上述分模块业务取舍，不把迁移提速记作模型性能提升，也不宣称已证明多种子稳定性或跨日期泛化。后续候选方案须另行明确范围；本轮不启动额外组、种子或预算。
