# S3-P02 七路线功率细调与逐场景耗时对照

**正式结论（2026-10-03）：**双端任务均已完成，4200条方法结果、42万条终态束记录经逐SHA归档和独立物理、指标、计时审计。Jan26共同100景中，六种细调相对原T0分配的SI、SGM在100景总体均值均提高；WMMSE各有4景持平，其余方法两指标均为100景改善。SCA的两指标均值略高于SLSQP，单次分段实测总时约为其三分之一，但功率较高，严格基本服务束数仍下降；多数SCA以2000次容量调用上限停止，不能称为已收敛或对每景支配。

## 实验范围与比较口径

冻结科学源码为 `b3c94c993457919bd17e30c71f22f87e5349f012`；初始解是G11 T0 150000步终点，训练seed 51001、固定α=0.01，权重SHA256为 `ae095e8246d22b2716ba154315cee18584917d215580821cb53f9aeba78eb824`。本轮新增训练交互**0**。考核是预先固定的ADS-B 2024-01-26共100景，每景3次动作，动作seed 53001–53003；DE/PSO另有固定优化器随机源，这不是新增训练种子。每预算100×3×7=2100条方法结果，双端合计42万条逐束终值。两预算分别分析，不与Jan25的S3-P01拼榜。

七路线为原分配none、原5 W档位局部调整discrete、含需求匹配初始化的SLSQP、真实容量回溯验收的SCA、差分进化DE、粒子群PSO、速率提议加真实SI/SGM守门的WMMSE。T0产生频率槽和初始功率，之后固定槽。discrete仍受5–50 W及5 W档位限制；连续路线允许非负整束功率、空槽束0，受总功率上限约束。SLSQP收益混有需求匹配初始化及可行域放宽，3000 W组还可能动用额外总功率。SCA一阶模型不是全局界，WMMSE速率候选不等价于原SGM；两者均未认证原目标驻点。分式规划只作数学参考，没有单独的第八FP路线。

场景均值先将同景3次动作平均，再在100景上平均。SI为全部目标束最终需求满足率，SGM另列；基本服务按原值 `C >= 0.1D` 严格判断，包含最后动作后的干扰与未服务束。有效承载是模型计算的各束 `min(C,D)` 总和，不是实际观测流量。

## 两预算的功率与效果取舍

同一Jan26场景和动作下，SCA在3000 W预算相对初始总功率预算，场景平均用功率增加723.299 W，SI增加0.0780个百分点，SGM增加0.000699。SLSQP相应多用659.786 W，SI增加0.0762个百分点，但SGM**下降0.001648**。这两个跨预算差值只描述各方法自身的预算变化；额外总功率并不保证供需匹配程度更高，不能把预算差别当作算法优势。
