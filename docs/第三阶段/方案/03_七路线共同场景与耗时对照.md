## 范围与共同条件

沿用G11 T0固定150000步终点（seed51001、固定α=0.01，policy SHA256 `ae095e8246d22b2716ba154315cee18584917d215580821cb53f9aeba78eb824`）产生初始频率槽与功率分配。波束身份、需求、顺序、分组/极化、频率起点与实际槽数固定。每种方法从同一p0出发，不把上一方法的最优解传给下一方法。空槽束为零，连续功率非负且仅受总功率预算约束；原档位参照保留5–50 W、5 W步长。

两预算口径分别为原3000 W预算（20418）及不超过该初始解总功率（20424）。首轮S3-P01与Jan25原始记录保持不变，不把不同日期的成绩拼成统一排行榜。

| 方法ID | 实际算法路线 | 目标与解释边界 |
| --- | --- | --- |
| none | 原T0分配 | 不细调；包含实际生成初始解的时间 |
| discrete | 原5 W档位坐标调整与两束交换 | 保留原离散可行域，作为局部调整参照 |
| slsqp | 原SLSQP含需求匹配初始化 | 先SI后SGM，保留已有路线作同场景对照 |
| sca | 信赖域顺序线性凸近似 | 以原容量/SGM一阶模型构造LP，真实容量回溯验收；线性模型不是全局下界，不套用其它论文的收敛证明 |
| de | DE/rand/1/bin差分进化 | 显式种群与变异/交叉，预算内可行优先搜索，无隐藏SLSQP抛光 |
| pso | 粒子群 | 惯性、个体最优及群体最优更新，无隐藏梯度抛光 |
| wmmse | 按需求加权的WMMSE速率提议 | 每槽接收器/MSE权重与共用整束功率二次子问题更新，最终依原SI/SGM验收；加权速率不等价于原双指标 |

分式规划在本轮作为WMMSE数学关系的参考，不额外把同一实现命名成第八个算法。上述七路线覆盖原方案中的已执行参照、SCA、差分进化、粒子群和WMMSE参考方向。SCA和WMMSE结果明确标记未认证原问题驻点，`converged=False`不能统一解读成程序失败；各方法的阶段停止、硬预算、回退和可行性分别报告。

数学推导与适用边界见[只读推导记录](../../../outputs/experiments/stage3_all_routes_20261003/derivation_sca_wmmse.md)。其中WMMSE的非负速率权重在SI阶段取尚欠需求束的1/D，在SGM阶段取容量导数正部，只定义候选方向；过供时SGM可能随容量增加而下降，因此不声称其与原SGM有严格等价关系。SCA所有候选也必须经过原非线性物理与约束复算。

## 每场景耗时必须与终态结果同表

每个场景/动作记录：T0生成初始解时间（含环境交互及逐步日志）、公共物理模型准备时间、方法调用墙钟、其中日志回调时间、扣除回调的参考时间、最终终态与约束核验时间，以及这些阶段的实测合计。CUDA初始解计时前后同步；一次性权重加载、输入文件导入、最终CSV导出、绘图和归档不进入算法阶段时间。

实验中共享初始解仅计算一次。为了比较独立部署各方法，每个方法的总耗时按同一初始解实测时间加该方法自身各阶段时间构成，明确称为“分段实测合计”，不伪称把完整流水线重跑了七次。已保存初始化和公共准备时间在恢复时保留，不把恢复等待时间计入。历史任务缺失的新计时字段标记未记录，不补零。

原始`power_results.csv`提供单次动作的所有阶段时间；`power_scene_times.csv`把同一场景的3次动作分方法求和，同时列单次均值及SI/SGM/功率。报告同时展示单次分配与每景3次合计的均值、中位数、95分位（NumPy线性插值），并给逐场景图。原分配也包含T0生成初始解时间，不能用几乎为零的“不调整”函数耗时冒充整个算法所需时间。

记录DQN/Python/PyTorch/SciPy、CUDA、GPU/CPU身份与线程设置、实际包路径和同机作业情况。各任务内方法顺序执行，仍须说明两远端的宿主资源差异；这些是本实现和设备下的实测，不外推普遍速度优势。
